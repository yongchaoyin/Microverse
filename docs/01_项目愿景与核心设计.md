## 🎯 项目愿景

### 游戏定位

**Microverse In Box** 是一款**AI驱动的开放世界社交模拟游戏**，玩家作为"观察者"或"上帝视角"，见证并影响一个由真实AI角色构成的虚拟小镇。

### 核心体验

- 🤖 **真实AI社会**: 每个AI都是独立个体，拥有真实的思考、记忆、情感和目标
- 🏘️ **自主演化社区**: AI角色自主生活、工作、社交、创业，形成复杂的社会网络
- 🎭 **涌现叙事**: 故事不是预设的，而是从AI角色的自主互动中自然涌现
- 👁️ **观察与影响**: 玩家可以观察AI世界的发展，也可以通过特定方式影响社会走向

### 设计目标

1. **短期目标** (3-6个月)
   - 构建完整的时间系统和日夜循环
   - 实现AI自主行为系统（工作、社交、娱乐）
   - 完善社交关系和情感系统
   - 实现基础经济系统（AI自主交易、消费）

2. **中期目标** (6-12个月)
   - 扩展小镇地图（住宅区、商业区、娱乐区）
   - 丰富AI职业和工作生态系统
   - 实现动态事件系统（AI自主触发事件）
   - AI角色自主决策系统（跳槽、创业、搬家）

3. **长期目标** (12个月+)
   - AI角色可以自主创业、雇佣其他AI
   - AI可以自主结婚、生子、建立家庭
   - 小镇社会自主演化（阶级、派系、政治）
   - 玩家可以自定义AI角色并投放到世界中
   - 多观察者模式（多玩家可同时观察影响同一世界）

## 💡 核心设计理念

### 1. AI优先 (AI-First)

**传统游戏**: NPC是脚本化的，行为固定
**我们的游戏**: AI是游戏的核心驱动力

```
设计原则：
✓ 每个AI决策都应该有意义
✓ AI的记忆系统是叙事的基础
✓ 玩家的互动应该影响AI的长期发展
✓ AI之间的关系应该是动态的、可演化的
```

### 2. 涌现叙事 (Emergent Storytelling)

**不要**: 预设剧情 → 玩家触发 → 看过场动画
**而是**: AI互动 → 产生矛盾/友谊 → 玩家见证结果

**示例场景**:
```
传统RPG:
  NPC A: "我需要5个苹果，请帮我收集"
  玩家: 收集后交付
  NPC A: "谢谢你！这是奖励"

AI驱动的涌现叙事:
  第1天: Alice抱怨工作太累，想要辞职
  第5天: Tom(老板秘书)听说了，向Stephen(老板)汇报
  第7天: Stephen提出给Alice加薪，但要求996
  第10天: Alice在咖啡店向Joe吐槽老板PUA
  第15天: Joe写了一个自动化工具送给Alice，减轻她的工作
  第20天: Alice和Joe的好感度提升，开始约会
  第30天: Stephen发现工作效率提升，询问原因
  结局A: 如果玩家支持Joe，Stephen可能会雇佣Joe做技术顾问
  结局B: 如果玩家不干预，Alice可能会因为工作平衡跳槽
```

### 3. 观察者与上帝视角

**玩家不是传统的"主角"，而是小镇的"观察者/上帝"**

| 传统模拟游戏 | Microverse设计 |
|------------|---------------|
| 玩家控制一切 | 玩家观察和影响 |
| NPC被动响应 | AI完全自主决策 |
| 剧情线性展开 | 社会自主演化 |
| 玩家是英雄 | 玩家是见证者 |

**玩家的角色定位**:
- 👁️ **主要角色：观察者**
  - 观察AI的生活、工作、社交
  - 见证AI关系的发展和破裂
  - 记录AI社会的演化历程

- 🎯 **次要角色：影响者**（可选）
  - 通过特殊事件影响小镇
  - 可以创建新的AI角色投放到世界
  - 可以设置环境参数（经济政策、事件概率）
  - 但**不能直接控制AI的决策**

**玩家的互动方式**:
- 📊 **观察系统**:
  - AI关系网络图谱
  - 情绪和记忆日志
  - 职业和财富统计
  - 社会事件时间线
- 💬 **有限互动**:
  - 可以与AI对话（作为"神秘访客"）
  - 但不能强制AI做任何事
- 🎮 **世界管理**:
  - 调整时间流速
  - 设置随机事件概率
  - 投放新的AI角色

## 🔄 游戏循环设计

### 核心循环（AI驱动，不是玩家驱动）

```
每日循环（AI自主生活）:
  早晨 (6:00-9:00)
    → AI角色起床、洗漱、吃早餐
    → AI根据性格和职业选择今日活动
    → 玩家观察AI的晨间行为

  工作时间 (9:00-17:00)
    → AI在各自工作场所工作
    → AI之间有工作相关的互动
    → 可能发生职场事件（会议、冲突、合作）
    → 玩家可以旁观或查看统计数据

  傍晚 (17:00-21:00)
    → AI下班，自主选择活动（社交/娱乐/学习/约会）
    → 咖啡馆、酒馆成为社交热点
    → 可能触发重要社交事件
    → 玩家观察AI的社交网络变化

  夜晚 (21:00-6:00)
    → AI回家休息、睡觉
    → 玩家查看当日事件日志
    → 系统生成当日社会报告
```

### 周循环（AI自主节奏）

```
周一至周五: 工作日
  - AI按照职业正常工作
  - AI可能在工作中产生新想法（跳槽、创业）

周六: 社交日
  - 小镇广场举办集市
  - AI自主选择参加社交活动
  - 可能产生新的关系或约会

周日: 自由日
  - AI根据个人喜好自由活动
  - 可能去教堂、图书馆、公园
  - 可能有AI组织聚会、派对
```

### 季节循环（影响AI情绪和行为）

| 季节 | 持续时间 | 环境特征 | AI行为倾向 |
|-----|---------|---------|-----------|
| **春季** | 28天 | 樱花盛开、温暖 | 情绪高涨，易产生恋情，创业欲望增强 |
| **夏季** | 28天 | 阳光明媚、活力 | 社交频繁，组织户外活动，消费增加 |
| **秋季** | 28天 | 金秋时节、凉爽 | 工作努力，赚钱欲望强，保守倾向 |
| **冬季** | 28天 | 寒冷、节日氛围 | 室内社交多，易产生矛盾，也易和解 |

### 长期演化（社会自主发展）

```
第1年: 社会建立期
  - AI角色建立基础社交网络
  - 形成初步的职场关系
  - 可能有1-2对AI开始恋爱
  - 小镇社会结构初步形成

第2年: 社会发展期
  - AI开始跳槽、创业
  - 有AI结婚、组建家庭
  - 可能出现社会分层（富人、穷人）
  - 可能形成小团体、派系

第3年+: 社会成熟期
  - AI社会完全自主演化
  - 可能出现政治活动（竞选市长）
  - 可能出现代际传承（AI的子女长大）
  - 社会结构复杂化（阶级、利益集团）
  - 玩家主要是观察和记录
```

## 👤 玩家角色定位

### 身份设定

**名称**: "观察者" / "The Observer" / "上帝视角"

**背景故事** (可选，不强制):
```
你发现了一个神秘的虚拟世界——Microverse小镇。
这个小镇里的居民都是由AI驱动的虚拟生命，拥有真实的思考和情感。
他们不知道你的存在，他们按照自己的意志生活。
你可以观察他们的生活，见证他们的故事。
你也可以偶尔影响这个世界，但无法控制AI的灵魂。
```

### 玩家能力

**✅ 可以做的**:
- **观察**:
  - 查看任何AI的记忆、情绪、关系
  - 查看小镇的统计数据（经济、社交、事件）
  - 回放历史事件
- **有限互动**:
  - 以"神秘访客"身份与AI对话
  - 但AI会根据自己的意愿决定是否理你
- **世界管理**:
  - 调整时间流速（1x、2x、5x、暂停）
  - 创建新的AI角色投放到世界
  - 触发特定随机事件（经济危机、节日等）

**❌ 绝对不能做的**:
- ❌ 直接控制任何AI的决策
- ❌ 强制AI去做任何事
- ❌ 直接修改AI的记忆、情感、关系
- ❌ 预知AI未来的行为

### 玩家目标

**核心目标**: 观察和记录一个AI社会的演化

**具体目标** (成就系统):
- 📖 **故事收集**:
  - 见证AI的恋爱故事
  - 见证AI的友谊破裂与和解
  - 见证AI的职业成功与失败
  - 见证AI的家庭建立

- 📊 **社会观察**:
  - 记录小镇的经济变化
  - 记录社会阶层的形成
  - 记录派系和团体的出现
  - 记录重大历史事件

- 🎭 **特殊事件**:
  - 见证AI自主创业
  - 见证AI结婚生子
  - 见证AI之间的冲突与和解
  - 见证小镇政治活动（市长竞选）

**没有"通关"概念，这是一个无限演化的世界**

## 🚀 差异化竞争优势

### vs 星露谷物语

| 星露谷物语 | Microverse优势 |
|----------|---------------|
| NPC行为固定 | AI自主决策，每次游玩都不同 |
| 好感度系统单向 | AI会主动与玩家/其他AI互动 |
| 剧情线性 | 涌现叙事，故事不可预测 |
| 单人游戏 | 可扩展多观察者模式 |

### vs 斯坦福AI小镇

| 斯坦福AI小镇 | Microverse优势 |
|------------|---------------|
| 纯观察，无互动 | 玩家可深度参与 |
| 无游戏目标 | 完整的游戏循环和目标系统 |
| 纯研究项目 | 商业化游戏产品 |
| 单一场景 | 多场景、多玩法 |

### vs 模拟人生

| 模拟人生 | Microverse优势 |
|---------|---------------|
| 玩家控制小人 | AI有真正的自主意识 |
| 需求驱动 | 记忆和情感驱动 |
| 关系浅层 | AI关系深度且动态演化 |
| 无真实对话 | 基于LLM的真实对话 |

## 🎨 美术风格方向

### 场景风格定位

**核心理念**: 西方小镇的温馨氛围 × AI驱动的现代生活

**设计参考**: 斯坦福AI小镇 + 星露谷物语
- 🏡 **经典西方小镇风格**：石砖建筑、尖顶教堂、鹅卵石路、广场喷泉
- 🌸 **四季分明的景观**：春天樱花、夏天向日葵、秋天枫叶、冬天雪景
- 🏘️ **完整的社区配套**：市政府、教堂、图书馆、咖啡馆、酒馆、办公区
- 🌳 **自然景观丰富**：森林、湖泊、公园、河流、海滩
- 🏙️ **现代生活气息**：商业区、办公楼、餐厅、银行、邮局

**西方小镇元素**:
- 建筑风格：砖石结构、木质屋顶、烟囱、窗台花盆
- 公共设施：路灯、长椅、邮筒、公告栏
- 自然景观：橡树、松树、草地、花园
- 节日装饰：圣诞彩灯、万圣节南瓜、复活节彩蛋

**重要**: 不是复制星露谷的农场布局，而是创造一个有AI生活气息的**西方小镇**

### 场景规划（西方小镇风格）

```
小镇中心区（Town Center）:
  - 市政厅（Town Hall）- AI政府办公、公告栏、小镇会议
  - 教堂（Church）- AI节日活动、婚礼场所、心灵聚会
  - 广场（Plaza）- 喷泉、长椅、AI社交热点
  - 杂货店（General Store）- AI日常购物、商业互动
  - 图书馆（Library）- AI角色学习、阅读、知识交流
  - 咖啡馆（Cafe）- 白天AI社交场所
  - 酒馆（Saloon）- 晚上AI社交场所
  - 诊所（Clinic）- AI医疗服务
  - 邮局（Post Office）- AI通信、包裹往来

商业区（Commercial District）:
  - 办公楼（Office Building）- AI角色工作场所
  - 银行（Bank）- AI金融活动、贷款、储蓄
  - 餐厅（Restaurant）- AI聚餐、约会场所
  - 书店（Bookstore）- AI购买书籍、文化交流
  - 服装店（Boutique）- AI购买衣物、展示个性

AI居住区（Residential Area）:
  - 8-12个AI角色的家（西方小屋）
  - 每家有不同风格：
    - 小木屋（Cottage）- 温馨单身住所
    - 两层小楼（House）- 家庭居所
    - 公寓（Apartment）- 城市生活风格
  - 带有小花园、栅栏、信箱
  - AI在家做日常活动（烹饪、阅读、园艺、娱乐）
  - 玩家可透过窗户观察AI的居家生活

自然休闲区（Recreational Area）:
  - 公园（Park）- AI散步、约会、运动
  - 湖泊（Lake）- AI钓鱼、野餐
  - 海滩（Beach）- AI度假、游泳、聚会
  - 森林（Forest）- AI徒步、探险
  - 河流（River）- 连接各区域，景观带

观察者专用区（Observer Zone）:
  - 观察塔（Observation Tower）- 俯瞰小镇全景
  - 数据中心（Data Center）- 查看AI统计数据、关系图谱
  - 时光回廊（Time Corridor）- 回放历史事件
  - 创造实验室（Creation Lab）- 设计新的AI角色
```

### 美术风格细节

**像素艺术风格**:
- **分辨率**: 16x16 或 32x32 tile（与星露谷一致）
- **色调**: 温暖、明亮、饱和度适中
- **细节度**: 精致但不过分复杂
- **动画**: 流畅的角色动作、植物生长动画

**场景氛围（四季）**:
- 🌸 **春（Spring）**: 樱花盛开、嫩绿草地、温暖阳光、花朵绽放
- ☀️ **夏（Summer）**: 蓝天白云、向日葵、蝴蝶飞舞、海滩活动
- 🍂 **秋（Autumn）**: 枫叶飘落、金色麦田、丰收喜悦、南瓜装饰
- ❄️ **冬（Winter）**: 白雪覆盖、圣诞装饰、壁炉温暖、冰钓活动

**西方小镇元素（必备）**:
- **建筑风格**: 石砖墙、木质屋顶、烟囱、窗台花盆、栅栏
- **公共建筑**:
  - 市政厅：钟楼、石柱、公告栏
  - 教堂：尖顶、彩色玻璃窗、钟声
  - 图书馆：书架、阅读区、壁炉
- **街道元素**: 鹅卵石路、路灯、长椅、邮筒、垃圾桶
- **装饰元素**: 花坛、喷泉、旗帜、花环
- **自然景观**: 橡树、松树、灌木、花朵、草地
- **节日装饰**:
  - 圣诞节：彩灯、圣诞树、礼物
  - 万圣节：南瓜灯、蜘蛛网、幽灵装饰
  - 复活节：彩蛋、兔子、花环

**建筑风格参考**:
- 欧式小镇：石砖建筑、坡屋顶、烟囱
- 美式农舍：木质结构、前廊、摇椅
- 现代混搭：传统外观 + 现代便利（路灯、邮筒、电线）

### UI/UX设计（完全参考星露谷物语）

**设计原则**:
- ✅ **直接借鉴星露谷的UI框架和交互逻辑**

## 🛡️ 内容规范铁律

### 设计哲学

> **"在Microverse，AI不是工具人，而是虚拟生命。**
> **玩家不是主角，而是见证者和引导者。**

### 内容底线（不可触碰）

**本游戏严格遵守以下内容规范，任何违反者将立即从游戏中移除：**

#### ❌ 绝对禁止的内容

1. **黄色内容**
   - ❌ 任何色情、性暗示内容
   - ❌ 裸露、性行为描写
   - ❌ 不适当的暧昧对话或画面
   - ✅ **允许**：纯洁的恋爱、牵手、拥抱、结婚（温馨向）

2. **赌博内容**
   - ❌ 任何形式的赌博玩法
   - ❌ 开箱、抽卡、转盘等带有博彩性质的机制
   - ❌ 鼓励玩家用真实货币进行运气游戏
   - ✅ **允许**：小镇集市的游戏摊位（确定性奖励，非运气驱动）

3. **毒品内容**
   - ❌ 任何毒品、违禁药物的描写
   - ❌ 鼓励或美化吸毒行为
   - ❌ 含有药物滥用的暗示
   - ✅ **允许**：正常的医疗用药、草药治疗（基于现实医学）

4. **暴力内容**
   - ❌ 血腥、残忍的暴力场景
   - ❌ 虐待动物或角色
   - ❌ 鼓励暴力解决问题
   - ❌ 含有恐怖、惊悚元素
   - ✅ **允许**：观察AI的日常工作（无暴力、血腥内容）

#### ✅ 提倡的核心价值观

1. **温馨治愈**
   - 小镇生活的温暖日常
   - 友谊、爱情的美好发展
   - 邻里互助、社区和谐

2. **积极向上**
   - 通过努力获得成长和成就
   - AI角色追求梦想、实现价值
   - 传递正能量和希望

3. **健康生活**
   - 农耕、钓鱼等健康休闲活动
   - 规律作息、均衡饮食
   - 亲近自然、热爱生活

4. **人际关系**
   - 真诚沟通、相互理解
   - 化解矛盾、包容差异
   - 建立深厚的友谊和爱情
