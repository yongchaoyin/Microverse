## 📊 使用示例

### 示例1: 实时监控

```gdscript
# 在DebugConsole或UI中显示
func _process(delta):
    var fps = PerformanceMonitor.get_current_fps()
    var memory = PerformanceMonitor.get_current_memory_mb()

    fps_label.text = "FPS: %.1f" % fps
    memory_label.text = "Memory: %.2f MB" % memory
```

### 示例2: LLM调用监控

```gdscript
# 在APIManager中集成(示例)
func _on_api_request_completed(success, response_time, character_name):

    PerformanceMonitor.record_llm_call(
        character_name,
        success,
        response_time,
        tokens
    )
```

### 示例3: 性能警告处理

```gdscript

PerformanceMonitor.memory_warning.connect(_on_memory_warning)

    print("警告: FPS严重下降至%.1f" % fps)
    # 降低画质或禁用特效

func _on_memory_warning(memory_mb):
    print("警告: 内存使用%.2fMB" % memory_mb)
    # 清理缓存或释放资源
```

### 示例4: 按角色统计

```gdscript
var stats = PerformanceMonitor.get_llm_stats_by_character()

for character_name in stats.keys():
    var char_stat = stats[character_name]
    print("%s: 调用%d次, 成功率%.1f%%, 耗时%.2fs, Token%d" % [
        character_name,
        char_stat.total,
        float(char_stat.success) / char_stat.total * 100,
        char_stat.total_time,
        char_stat.tokens
    ])
```
