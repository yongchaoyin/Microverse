## 🔍 关键技术亮点

### 1. 信号驱动架构

整个项目大量使用Godot信号系统实现解耦:

```gdscript
# 时间系统信号
TimeSystem.hour_changed → DayNightCycle → WindowLights/StreetLights

# 对话系统信号
DialogManager.conversation_started → AIAgent → DialogBubble

# 交互系统信号
InteractionZone.interaction_triggered → AIAgent → 角色行为变化

# 项目系统信号
ProjectSystem.project_created → UI更新
ProjectSystem.epic_completed → 经济结算
```

### 2. 元数据存储模式

角色状态使用Node元数据存储,避免复杂的数据结构:

```gdscript
# 读取
var character_data = character.get_meta("character_data", {})
var memories = character_data.get("memories", [])

# 写入
character_data["memories"] = new_memories
character.set_meta("character_data", character_data)
```

### 3. Autoload单例模式

17个全局管理器提供全局访问:

```gdscript
var dialog_manager = get_node("/root/DialogManager")
var memory_manager = get_node("/root/MemoryManager")
```

### 4. 每角色AI配置

支持每个角色使用不同的AI提供商和模型:

```gdscript
SettingsManager.has_character_ai_settings("Alice")
SettingsManager.get_character_ai_settings("Alice")
# 返回: {api_type: "Claude", model: "claude-3-5-sonnet", api_key: "..."}
```

### 5. LLM集成架构

统一的API抽象层支持8种AI提供商:

```gdscript
APIConfig.get_api_types() → ["Ollama", "OpenAI", "Claude", ...]
APIConfig.build_request_data(api_type, model, prompt)
APIConfig.parse_response(api_type, response)
```

### 6. 非破坏性场景集成

OfficeMapSetup.gd展示了如何在不修改原场景的情况下添加功能:

```gdscript
# 运行时动态创建节点
var day_night_cycle = CanvasModulate.new()
day_night_cycle.set_script(load("res://script/world/DayNightCycle.gd"))
add_child(day_night_cycle)
day_night_cycle.owner = get_tree().edited_scene_root
# 保存场景时节点会持久化
```
