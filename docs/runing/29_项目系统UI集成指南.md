## 二、UI集成到主界面的方法

### 2.1 方法一：集成到GodUI（推荐）

GodUI是游戏中的上帝模式UI面板，位于 `scene/ui/GodUI.tscn` 和 `script/ui/GodUI.gd`。

#### 步骤1：在GodUI场景中添加按钮

打开 `scene/ui/GodUI.tscn`，在合适的位置添加一个按钮：

```gdscript
# 在GodUI.tscn的某个容器（如VBoxContainer）中添加：
[node name="CreateProjectButton" type="Button" parent="..."]
text = "创建项目"
custom_minimum_size = Vector2(120, 35)
```

#### 步骤2：在GodUI脚本中添加逻辑

打开 `script/ui/GodUI.gd`，添加以下代码：

```gdscript
# 在类顶部添加场景引用
const PROJECT_CREATION_UI_SCENE = preload("res://scene/ui/project/ProjectCreationUI.tscn")
const PROJECT_MONITOR_UI_SCENE = preload("res://scene/ui/project/ProjectMonitorUI.tscn")

var _project_creation_ui: Control = null
var _project_monitor_ui: Control = null

# 在_ready()函数中连接信号
func _ready() -> void:
	# ... 现有代码 ...

	# 连接创建项目按钮
	var create_project_button = $...CreateProjectButton  # 根据实际节点路径调整
	if create_project_button:
		create_project_button.pressed.connect(_on_create_project_button_pressed)

	# 连接ProjectSystem信号
	var project_system = get_node_or_null("/root/ProjectSystem")
	if project_system:
		project_system.project_started.connect(_on_project_started)
		project_system.project_completed.connect(_on_project_ended)
		project_system.project_failed.connect(_on_project_ended)
		project_system.project_cancelled.connect(_on_project_ended)

# 创建项目按钮点击处理
func _on_create_project_button_pressed() -> void:
	if _project_creation_ui:
		_project_creation_ui.queue_free()

	_project_creation_ui = PROJECT_CREATION_UI_SCENE.instantiate()
	get_tree().root.add_child(_project_creation_ui)

	print("[GodUI] 打开项目创建界面")

# 项目启动回调 - 显示监控UI
func _on_project_started(project: ProjectData) -> void:
	if not _project_monitor_ui:
		_project_monitor_ui = PROJECT_MONITOR_UI_SCENE.instantiate()
		add_child(_project_monitor_ui)

	print("[GodUI] 项目已启动: %s" % project.title)

# 项目结束回调 - 隐藏监控UI
func _on_project_ended(project: ProjectData, _reason: String = "") -> void:
	if _project_monitor_ui:
		_project_monitor_ui.queue_free()
		_project_monitor_ui = null

	print("[GodUI] 项目已结束: %s" % project.title)
```

### 2.2 方法二：快捷键触发

在主场景或游戏管理器中添加快捷键支持：

#### 在Office.tscn的脚本中添加

```gdscript
# 在Office场景脚本或专门的输入管理器中
const PROJECT_CREATION_UI_SCENE = preload("res://scene/ui/project/ProjectCreationUI.tscn")

func _input(event: InputEvent) -> void:
	# P键打开项目创建界面
	if event is InputEventKey and event.pressed and not event.echo:
		if event.keycode == KEY_P:
			_open_project_creation_ui()

func _open_project_creation_ui() -> void:
	var existing_ui = get_tree().root.get_node_or_null("ProjectCreationUI")
	if existing_ui:
		existing_ui.queue_free()

	var creation_ui = PROJECT_CREATION_UI_SCENE.instantiate()
	get_tree().root.add_child(creation_ui)
```

```gdscript
		get_tree().root.add_child(creation_ui)
```

## 三、UI工作流程详解

### 3.1 完整的项目创建流程

```
用户操作                        系统响应                        UI状态
───────────────────────────────────────────────────────────────────────
1. 点击"创建项目"按钮    →   实例化ProjectCreationUI      →   显示创建界面
2. 填写项目信息          →   UI实时更新预览               →   滑块/下拉框交互
3. 点击"创建项目"        →   调用ProjectSystem.create()   →   创建ProjectData
4. ProjectSystem处理     →   调用start_project()          →   自动启动项目
5. 项目启动成功          →   发出project_started信号      →   关闭创建UI
6. 自动显示监控UI        →   实例化ProjectMonitorUI       →   显示进度面板
7. 项目进行中            →   每秒刷新显示                 →   实时更新进度条
8. Epic完成/任务完成     →   更新Epic列表                 →   动态更新UI
9. 项目完成              →   触发LLM评估                  →   显示评估中提示
10. 评估完成             →   发出project_evaluated信号    →   自动弹出ReviewUI
11. 显示评估结果         →   显示完成度/质量/奖金         →   用户确认结果
12. 点击"确认"           →   关闭ReviewUI                 →   返回正常游戏
```

### 3.2 UI生命周期管理

#### ProjectCreationUI
```gdscript
# 生命周期:
创建 → 用户填写 → 提交创建 → 自动销毁(queue_free)

# 触发条件:
- 用户主动打开
- 没有活跃项目时

# 销毁条件:
- 点击"创建项目"后
- 点击"取消"按钮
```

#### ProjectMonitorUI
```gdscript
# 生命周期:
创建 → 每秒刷新 → 项目结束时销毁

# 触发条件:
- project_started信号
- 用户手动打开时有活跃项目

# 刷新机制:
- Timer每1秒调用_refresh_display()
- 监听Epic相关信号实时更新

# 销毁条件:
- 项目完成/失败/取消
- _refresh_timer.stop()后queue_free()
```

#### ProjectReviewUI
```gdscript
# 生命周期:
创建 → 显示结果 → 用户确认 → 销毁

# 触发条件:
- project_evaluated信号(自动)
- 用户查看历史项目(手动)

# 显示内容:
- 成功/失败标题
- 完成度星级
- 质量评分
- 优缺点列表
- 奖金分配明细

# 销毁条件:
- 点击"确认"按钮
```

### 6.2 监控UI刷新优化

```gdscript
# 在ProjectMonitorUI.gd中
var _last_refresh_data: Dictionary = {}

func _refresh_display() -> void:
	if not _project:
		return

	# 只在数据变化时更新UI
	var current_data = {
		"progress": _project.get_progress_percentage(),
		"status": _project.status,
		"current_epic_id": _project.get_current_epic().id if _project.get_current_epic() else ""
	}

	if current_data != _last_refresh_data:
		_update_ui(current_data)
		_last_refresh_data = current_data
```

### 6.3 动态列表优化

```gdscript
# 使用对象池避免频繁创建/销毁Label
class_name LabelPool extends Node

var _pool: Array[Label] = []
var _active: Array[Label] = []

func get_label() -> Label:
	if _pool.is_empty():
		return Label.new()
	else:
		return _pool.pop_back()

func return_label(label: Label) -> void:
	label.visible = false
	_pool.append(label)
```

## 八、常见问题解决

### 8.1 UI不显示

**问题**: 创建UI后看不到界面

**解决**:
1. 检查UI是否被添加到场景树: `get_tree().root.add_child(ui)`
2. 检查UI的visible属性是否为true
3. 检查UI的z_index和layer，确保不被其他UI遮挡
4. 检查Panel的size和position是否在屏幕范围内

### 8.2 @onready节点为null

**问题**: 脚本中的@onready变量为null，导致空指针错误

**解决**:
1. 确认.tscn文件中节点名称与脚本中的路径完全一致（区分大小写）
2. 确认脚本已正确附加到场景的根节点
3. 在Godot编辑器中打开.tscn文件，检查节点路径是否存在
4. 使用`get_node_or_null()`替代直接访问，添加空值检查

### 8.3 信号连接失败

**问题**: ProjectSystem的信号无法连接

**解决**:
1. 确认ProjectSystem已在project.godot中注册为Autoload
2. 使用正确的信号连接语法: `signal_name.connect(callable)`
3. 检查信号参数数量和类型是否匹配
4. 在连接前添加检查: `if project_system and project_system.has_signal("signal_name")`

### 8.4 UI刷新不及时

**问题**: 监控UI显示的数据滞后

**解决**:
1. 检查Timer的wait_time是否过长（建议1.0秒）
2. 确认Timer的timeout信号已正确连接
3. 手动监听ProjectSystem的Epic信号，立即触发刷新
4. 使用`call_deferred()`确保UI更新在渲染帧执行

### 8.5 内存泄漏

**问题**: 多次打开/关闭UI后内存持续增长

**解决**:
1. 确保UI关闭时调用`queue_free()`而不是只设置`visible = false`
2. 断开所有信号连接: `signal.disconnect(callable)`
3. 手动清理动态创建的子节点
4. 使用Godot的内存分析工具检查是否有未释放的对象

## 十一、完整集成示例代码

### 11.1 在GodUI中完整集成

```gdscript
# script/ui/GodUI.gd
extends Control

# ========================================
# 项目系统UI场景引用
# ========================================

const PROJECT_CREATION_UI_SCENE = preload("res://scene/ui/project/ProjectCreationUI.tscn")
const PROJECT_MONITOR_UI_SCENE = preload("res://scene/ui/project/ProjectMonitorUI.tscn")

var _project_creation_ui: Control = null
var _project_monitor_ui: Control = null

# ========================================
# 初始化
# ========================================

func _ready() -> void:
	# ... 现有的GodUI初始化代码 ...

	_setup_project_system_integration()

func _setup_project_system_integration() -> void:
	"""设置项目系统集成"""
	var project_system = get_node_or_null("/root/ProjectSystem")
	if not project_system:
		push_warning("[GodUI] ProjectSystem未找到，项目功能不可用")
		return

	# 连接信号
	project_system.project_started.connect(_on_project_started)
	project_system.project_completed.connect(_on_project_ended)
	project_system.project_failed.connect(_on_project_ended)
	project_system.project_cancelled.connect(_on_project_ended)

	# 如果已有活跃项目，立即显示监控UI
	var active_project = project_system.get_active_project()
	if active_project:
		_show_project_monitor_ui()

	print("[GodUI] 项目系统集成完成")

# ========================================
# 项目创建UI
# ========================================

func open_project_creation_ui() -> void:
	"""打开项目创建界面"""
	var project_system = get_node_or_null("/root/ProjectSystem")
	if not project_system:
		return

	# 检查是否已有活跃项目
	var active_project = project_system.get_active_project()
	if active_project:
		print("[GodUI] 已有活跃项目: %s，无法创建新项目" % active_project.title)
		# 可以在这里显示提示对话框
		return

	# 关闭现有的创建UI
	if _project_creation_ui:
		_project_creation_ui.queue_free()

	# 创建新的UI实例
	_project_creation_ui = PROJECT_CREATION_UI_SCENE.instantiate()
	get_tree().root.add_child(_project_creation_ui)

	print("[GodUI] 打开项目创建界面")

# ========================================
# 项目监控UI
# ========================================

func _show_project_monitor_ui() -> void:
	"""显示项目监控界面"""
	if _project_monitor_ui:
		return  # 已经显示

	_project_monitor_ui = PROJECT_MONITOR_UI_SCENE.instantiate()
	add_child(_project_monitor_ui)

	print("[GodUI] 显示项目监控界面")

func _hide_project_monitor_ui() -> void:
	"""隐藏项目监控界面"""
	if not _project_monitor_ui:
		return

	_project_monitor_ui.queue_free()
	_project_monitor_ui = null

	print("[GodUI] 隐藏项目监控界面")

# ========================================
# 信号回调
# ========================================

func _on_project_started(project: ProjectData) -> void:
	"""项目启动回调"""
	print("[GodUI] 项目已启动: %s" % project.title)

	# 关闭创建UI
	if _project_creation_ui:
		_project_creation_ui.queue_free()
		_project_creation_ui = null

	# 显示监控UI
	_show_project_monitor_ui()

func _on_project_ended(project: ProjectData, reason: String = "") -> void:
	"""项目结束回调"""
	var end_reason = "完成" if reason.is_empty() else reason
	print("[GodUI] 项目已结束: %s (%s)" % [project.title, end_reason])

	# 隐藏监控UI
	_hide_project_monitor_ui()

# ========================================
# 输入处理（可选）
# ========================================

func _input(event: InputEvent) -> void:
	if event is InputEventKey and event.pressed and not event.echo:
		# P键打开项目创建界面
		if event.keycode == KEY_P and event.ctrl_pressed:
			open_project_creation_ui()
```
