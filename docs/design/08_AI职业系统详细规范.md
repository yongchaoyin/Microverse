# AI职业系统详细规范 (Career System)

## 📋 系统概述

AI职业系统定义了每个AI的**工作内容、作息时间、社交圈子、收入来源**。职业是AI日常生活的核心，决定了Ta大部分时间在哪里、和谁在一起、做什么事情。

**设计原则**:
- 职业要**有差异性**（不同职业有独特的时间表和社交网络）
- 职业要**影响生活**（工作时间、压力、收入直接塑造AI的生活方式）
- 职业要**创造故事**（同事关系、工作压力、职业倦怠是重要叙事来源）
- 职业要**可扩展**（易于添加新职业）

---

## 👔 职业分类

### 两大类职业

```yaml
办公室职业（5天工作制）:
  特点:
    - 周一至周五工作
    - 周末完全休息
    - 朝九晚五（可能加班）
    - 固定同事圈
    - 压力较高

  职业: 前端工程师、后端工程师、产品经理、UI设计师、运营专员

服务业职业（7天工作制）:
  特点:
    - 全周工作
    - 无固定周末
    - 轮班制
    - 接触所有AI（顾客）
    - 社交优势
    - 月薪与办公室职业相当

  职业: 咖啡师、服务员、图书管理员
```

## 💼 8种核心职业详细规范

### 1. 前端工程师 (Frontend Engineer)

```yaml
职业代码: "frontend_engineer"

基础信息:
  名称: 前端工程师
  工作地点: 科技公司办公室
  工作日: 周一至周五
  工作时间: 9:00-18:00
  压力等级: 40/100
  社交性: 中等

薪资:
  日薪: 150G
  周薪: 750G (5天)
  月薪: 3,000G
  年薪: 36,000G
  成长率: 5%/年

工作日程模板:
  8:30-9:00:   通勤到办公室
  9:00-9:30:   站会 (Daily Standup)
  9:30-12:00:  编码开发
  12:00-13:00: 午餐（可能和同事一起）
  13:00-15:00: 继续编码
  15:00-15:30: 下午茶休息
  15:30-17:00: 编码/调试
  17:00-18:00: Code Review / 文档
  18:00-18:30: 下班回家

加班:
  概率: 30% (基础)
  受性格影响: × (尽责性/50)
  加班时长: 1-3小时
  加班内容: 赶项目进度、修复Bug

同事关系:
  办公室内同事:
    - 其他前端工程师（密切合作）
    - 后端工程师（频繁沟通）
    - UI设计师（工作配合）
    - 产品经理（需求对接）

  初始熟悉度: 20/100
  工作互动频率: 每天2-3次

压力来源:
  - 项目截止日期
  - Bug修复压力
  - 技术债务
  - 需求变更
```

### 6. 咖啡师 (Barista)

```yaml
职业代码: "barista"

基础信息:
  名称: 咖啡师
  工作地点: 咖啡馆
  工作日: 全周7天（轮班）
  工作时间: 7:00-15:00 (早班) 或 14:00-22:00 (晚班)
  压力等级: 30/100
  社交性: 极高

薪资:
  日薪: 110G
  周薪: 770G (7天)
  月薪: 3,080G
  年薪: 36,960G
  成长率: 3%/年

工作日程模板（早班）:
  6:30-7:00:   通勤
  7:00-8:00:   开店准备（清洁、备货）
  8:00-10:00:  早高峰服务
  10:00-12:00: 服务顾客、制作咖啡
  12:00-14:00: 午餐时段高峰
  14:00-15:00: 交接班、清理
  15:00-15:30: 回家

加班:
  概率: 10%
  原因: 人手不足、特殊活动

社交优势:
  - 认识小镇上几乎所有AI
  - 是信息枢纽和"树洞"
  - 了解各种八卦和故事
  - 调解关系的能力

同事关系:
  - 其他咖啡师（同事）
  - 所有常客（熟悉度自然增长）

工作特点:
  - 无固定周末
  - 体力消耗较大
  - 但社交满足感高
  - 月收入与办公室职业相当

压力来源:
  - 长时间站立
  - 顾客服务压力
  - 重复性工作
  - 无周末休息
```

## 📊 职业对AI生活的影响

```yaml
职业影响维度:

1. 时间结构:
   - 办公室职业: 固定朝九晚五，周末自由
   - 服务业: 全周工作，无固定周末

2. 社交圈子:
   - 产品经理: 认识所有同事
   - 咖啡师: 认识所有AI
   - 图书管理员: 社交圈小

3. 压力水平:
   - 产品经理: 高压 (50/100)
   - 图书管理员: 低压 (20/100)

4. 收入水平:
   - 产品经理: 最高 (3,600G/月)
   - 图书管理员: 最低 (2,400G/月)

5. 生活方式:
   - 高压职业 → 更多加班 → 更少社交 → 更高压力 → 可能生病
   - 低压职业 → 规律作息 → 更多社交 → 生活满意度高
```

1. **职业差异明显**

   - 程序员加班多，压力大

   - 高压职业薪资更高
