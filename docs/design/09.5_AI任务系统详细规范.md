# 09.5 AI任务系统详细规范 (AI Task System Specification)

## 📋 系统概述

AI任务系统是连接**职业**、**日程**、**经济**与**AI行为**的核心引擎。任务是AI日常生活的具体行为单元,定义了"工作"的具体内容、"社交"的具体形式、"学习"的具体目标。

**设计哲学:**
- 任务是**涌现式而非脚本化** - 任务类型固定,但具体执行由LLM决策生成
- 任务创造**叙事素材** - 任务完成/失败是关系、冲突、记忆的来源
- 任务驱动**性格展现** - 不同性格AI用不同方式完成同样任务
- 任务带来**生活节奏** - 任务deadline创造压力,任务完成带来成就感

**关键特性:**
- 4大任务域 (工作/日常/社交/成长)
- 任务状态机 (创建→进行中→完成/失败)
- 任务优先级系统 (紧急重要矩阵)
- 任务完成度评估 (LLM判定)
- 任务奖惩机制 (工资、经验、关系)

---

## 📊 任务分类体系

### 四大任务域

```yaml
任务域分类:
  1. 工作任务 (Work Tasks):
     - 来源: 职业系统
     - 占用时间: 工作日80%
     - 奖励: 工资、绩效
     - 失败惩罚: 降低绩效、压力增加
     - 示例: 编码模块、设计UI、写PRD

  2. 日常任务 (Daily Tasks):
     - 来源: 生理需求、生活维护
     - 占用时间: 全天20%
     - 奖励: 健康、情绪恢复
     - 失败惩罚: 健康下降、情绪降低
     - 示例: 吃饭、睡觉、洗澡、打扫

  3. 社交任务 (Social Tasks):
     - 来源: 关系系统、AI主动邀约
     - 占用时间: 非工作时间
     - 奖励: 关系提升、情绪恢复
     - 失败惩罚: 关系下降、负面记忆
     - 示例: 约会、聚会、帮助朋友

  4. 成长任务 (Growth Tasks):
     - 来源: AI自主目标
     - 占用时间: 自由时间
     - 奖励: 技能提升、成就感
     - 失败惩罚: 无惩罚(但有遗憾)
     - 示例: 学习新技能、健身、阅读
```

### 1.2 工作时间边界定义 ⏰

**设计原则**: 明确定义工作时间结束点,为加班系统提供基准

```yaml
标准工作时间:
  工作开始: 9:00
  午休时间: 12:00-13:00
  工作结束: 18:00 (硬性边界)

  计算依据:
    - 标准工作时长: 8小时/天 (不含午休)
    - 实际在岗时间: 9:00-18:00 (9小时,含午休1小时)
    - 18:00后为个人时间 (除非加班)

工作时间判定:
  is_work_time(hour: int) -> bool:
    if TimeSystem.is_weekend():
        return false  # 周末默认不工作 (特殊职业除外)

    if hour >= 9 and hour < 12:
        return true  # 上午工作时间
    elif hour >= 13 and hour < 18:
        return true  # 下午工作时间
    else:
        return false  # 非工作时间

工作结束触发:
  时间点: 18:00 整点
  触发事件: TimeSystem.work_day_ended 信号

  AIAgent响应:
    1. 检查是否有未完成工作任务
    2. 如果有紧急任务 (deadline今天) → 决定是否加班
    3. 如果无紧急任务 → 下班离开办公室
    4. 记录今日工作时长到work_data

加班系统:
  加班触发条件:
    1. 紧急任务 (is_urgent=true 且 deadline<=today)
    2. 任务积压 (pending_tasks.count > 5)
    3. 性格因素 (尽责性>80 或 神经质>70)
    4. 老板压力 (boss_pressure_level)

  加班时长限制:
    - 最长加班: 22:00 (加班4小时)
    - 极限加班: 23:00 (加班5小时,仅紧急情况)
    - 周加班上限: 15小时 (劳动法保护)

  加班决策 (LLM驱动):
    Prompt:
      你是{character_name},现在是18:00下班时间。

      你今天的工作情况:
      - 已完成任务: {completed_count}
      - 未完成任务: {pending_count}
      - 紧急任务: {urgent_tasks}  # 列表

      你的状态:
      - 疲劳度: {fatigue}/100
      - 本周已加班: {overtime_this_week}小时
      - 心情: {mood}/100

      你的性格:
      - 尽责性: {conscientiousness}/100
      - 神经质: {neuroticism}/100

      老板态度: {boss_pressure}  # "要求加班" / "无特别要求"

      请决定是否加班,以及加班多久。
      返回JSON: {
        "work_overtime": true/false,
        "overtime_hours": 0-4,  # 加班小时数
        "reason": "加班理由" 或 "不加班理由"
      }

  加班效果:
    正面:
      - 完成更多任务 → 绩效+10~20
      - 老板好感度+5
      - 尽责性>70的AI: 心情+5 (成就感)

    负面:
      - 疲劳度+15/小时
      - 压力+10/小时
      - 个人时间减少 → 社交/成长任务无法完成
      - 长期加班 → 健康-5/周, 职业倦怠风险

特殊职业工作时间:
  咖啡师/服务员:
    工作时间: 8:00-20:00 (分早晚班)
    早班: 8:00-14:00
    晚班: 14:00-20:00
    无标准"下班时间",按班次结束

  自由职业者:
    无固定工作时间
    任务驱动,完成即可
```

**GDScript实现**:
```gdscript
# script/task/TaskSystem.gd

# 工作时间常量
const WORK_START_HOUR = 9
const WORK_LUNCH_START = 12
const WORK_LUNCH_END = 13
const WORK_END_HOUR = 18  # 核心边界
const MAX_OVERTIME_HOURS = 4
const MAX_WEEKLY_OVERTIME = 15

func is_work_time(hour: int) -> bool:
	"""判断是否为工作时间"""
	if TimeSystem.is_weekend():
		return false

	if hour >= WORK_START_HOUR and hour < WORK_LUNCH_START:
		return true
	elif hour >= WORK_LUNCH_END and hour < WORK_END_HOUR:
		return true
	else:
		return false

func on_work_day_ended(ai: Node):
	"""18:00工作日结束处理"""

	# 检查未完成任务
	var pending_work_tasks = _get_pending_work_tasks(ai.id)
	var urgent_tasks = pending_work_tasks.filter(func(t): return t.get("is_urgent", false))

	# 计算本周加班时长
	var overtime_this_week = ai.work_data.get("overtime_this_week", 0.0)

	# 如果有紧急任务且未超过加班上限,考虑加班
	if urgent_tasks.size() > 0 and overtime_this_week < MAX_WEEKLY_OVERTIME:
		var overtime_decision = await _llm_decide_overtime(ai, pending_work_tasks, urgent_tasks)

		if overtime_decision.work_overtime:
			_start_overtime(ai, overtime_decision.overtime_hours, overtime_decision.reason)
		else:
			_leave_office(ai, overtime_decision.reason)
	else:
		# 无紧急任务或加班已超限,正常下班
		_leave_office(ai, "正常下班时间到")

func _llm_decide_overtime(
	ai: Node,
	pending_tasks: Array,
	urgent_tasks: Array
) -> Dictionary:
	"""LLM决策是否加班"""

	var completed_today = _get_completed_tasks_today(ai.id)
	var overtime_this_week = ai.work_data.get("overtime_this_week", 0.0)

	var boss_pressure = "无特别要求"
	if urgent_tasks.size() >= 2:
		boss_pressure = "要求加班完成紧急任务"

	var prompt = """你是{name},现在是18:00下班时间。

你今天的工作情况:
- 已完成任务: {completed}个
- 未完成任务: {pending}个
- 紧急任务: {urgent_list}

你的状态:
- 疲劳度: {fatigue}/100
- 本周已加班: {overtime}小时
- 心情: {mood}/100

你的性格:
- 尽责性: {C}/100 (高=更愿意加班)
- 神经质: {N}/100 (高=担心任务完不成)

老板态度: {boss}

请决定是否加班,以及加班多久(最多4小时)。
返回JSON: {{
  "work_overtime": true/false,
  "overtime_hours": 0-4,
  "reason": "理由"
}}
""".format({
		"name": ai.character_name,
		"completed": completed_today.size(),
		"pending": pending_tasks.size(),
		"urgent_list": _format_urgent_tasks(urgent_tasks),
		"fatigue": ai.physical_state.fatigue,
		"overtime": overtime_this_week,
		"mood": ai.current_mood,
		"C": ai.personality.conscientiousness,
		"N": ai.personality.neuroticism,
		"boss": boss_pressure
	})

	var llm_response = await APIManager.call_llm_async(
		ai.ai_settings.api_type,
		ai.ai_settings.model_type_small,
		prompt,
		0.7
	)

	var decision = JSON.parse_string(llm_response)
	return decision

func _start_overtime(ai: Node, hours: float, reason: String):
	"""开始加班"""

	ai.work_data.is_overtime = true
	ai.work_data.overtime_end_hour = WORK_END_HOUR + hours
	ai.work_data.overtime_this_week += hours

	# 记录加班记忆
	MemoryManager.add_memory(ai, {
		"content": "我决定加班%d小时。%s" % [int(hours), reason],
		"type": MemoryManager.MemoryType.TASK,
		"importance": MemoryManager.MemoryImportance.NORMAL,
		"valence": -0.2  # 轻微负面
	})

	# 继续工作任务
	print("📊 %s 加班%d小时: %s" % [ai.character_name, int(hours), reason])

func _leave_office(ai: Node, reason: String):
	"""下班离开"""

	ai.work_data.is_overtime = false

	# 移动到下班后的位置 (家/社交地点)
	ai.ai_movement.leave_office()

	# 记录下班记忆
	MemoryManager.add_memory(ai, {
		"content": "下班了。%s" % reason,
		"type": MemoryManager.MemoryType.DAILY,
		"importance": MemoryManager.MemoryImportance.LOW
	})

	print("🏠 %s 下班: %s" % [ai.character_name, reason])

func _format_urgent_tasks(urgent_tasks: Array) -> String:
	"""格式化紧急任务列表"""
	if urgent_tasks.is_empty():
		return "无"

	var task_names = urgent_tasks.map(func(t): return t.title)
	return ", ".join(task_names)
```

### 1.3 任务生成机制

#### 每日工作任务生成

```gdscript
# TaskSystem.gd
func generate_daily_work_tasks(ai: Node) -> Array:
    """为AI生成今日工作任务"""

    var career_id = ai.career
    var career_data = CareerSystem.get_career_data(career_id)
    var schedule_template = career_data.get("schedule_template", [])

    var tasks = []

    # 从日程模板生成任务
    for schedule_item in schedule_template:
        var activity = schedule_item.get("activity", "")

        # 跳过非工作活动
        if activity in ["arrive_office", "leave_office", "lunch", "break", "coffee_break"]:
            continue

        # 根据activity生成对应任务
        var task = _create_task_from_activity(ai, activity, schedule_item)
        if task:
            tasks.append(task)

    # 随机事件任务 (10%概率)
    if randf() < 0.1:
        var urgent_task = _generate_urgent_task(ai)
        if urgent_task:
            tasks.insert(0, urgent_task)  # 插入到最前面

    return tasks

func _create_task_from_activity(ai: Node, activity: String, schedule_item: Dictionary) -> Dictionary:
    """从活动创建任务"""

    var task_templates = TaskDefinitions.get_task_templates_by_activity(activity)
    if task_templates.size() == 0:
        return {}

    # 随机选择一个任务模板
    var template = task_templates.pick_random()

    # 实例化任务
    var task = {
        "id": _generate_task_id(),
        "type": "work",
        "template_id": template.id,
        "title": template.title,
        "description": template.description,
        "scheduled_time": schedule_item.get("time", 9.0),
        "duration": schedule_item.get("duration", 1.0),
        "difficulty": template.difficulty,
        "priority": _calculate_initial_priority(template),
        "status": TaskStatus.PENDING,
        "progress": 0.0,
        "created_at": TimeSystem.get_current_timestamp(),
        "deadline": null,  # 工作任务一般无明确deadline,按日程走
        "rewards": template.rewards,
        "penalties": template.penalties
    }

    return task

func _generate_urgent_task(ai: Node) -> Dictionary:
    """生成紧急任务"""

    var career_id = ai.career
    var urgent_templates = TaskDefinitions.get_urgent_task_templates(career_id)

    if urgent_templates.size() == 0:
        return {}

    var template = urgent_templates.pick_random()

    var task = {
        "id": _generate_task_id(),
        "type": "work",
        "template_id": template.id,
        "title": "[紧急] " + template.title,
        "description": template.description,
        "scheduled_time": TimeSystem.get_current_hour(),  # 立即开始
        "duration": template.duration,
        "difficulty": template.difficulty,
        "priority": TaskPriority.URGENT_IMPORTANT,  # 最高优先级
        "status": TaskStatus.PENDING,
        "progress": 0.0,
        "created_at": TimeSystem.get_current_timestamp(),
```

```gdscript
    """完成任务"""

    task.status = TaskStatus.IN_REVIEW
    task.completed_at = TimeSystem.get_current_timestamp()
    task.actual_duration = task.completed_at - task.started_at

    var result = {}

    # 根据任务复杂度选择判定方式
    if task.difficulty <= TaskDifficulty.LOW:
        # 简单任务 - 规则判定
        result = _evaluate_simple_task(ai, task)
    else:
        # 复杂任务 - LLM评估
        result = await _evaluate_complex_task_with_llm(ai, task)

    # 应用奖励
    if result.requirements_met:
        _apply_task_rewards(ai, task, result)
        task.status = TaskStatus.COMPLETED
    else:
        _apply_task_penalties(ai, task, result)
        task.status = TaskStatus.FAILED

    # 创建记忆
    _create_task_memory(ai, task, result)

    # 更新绩效
    ai.work_data.performance_score += result.performance_impact

    # 发出信号
    task_completed.emit(ai.id, task.id, result)

    return result

func _evaluate_simple_task(ai: Node, task: Dictionary) -> Dictionary:
    """评估简单任务"""

    var is_overdue = false
    if task.deadline:
        is_overdue = task.completed_at > task.deadline

    var quality_score = 100
    if is_overdue:
        quality_score -= 20

    # 性格影响质量
    var C = ai.personality.conscientiousness
    quality_score = int(quality_score * (C / 100.0))

    return {
        "quality_score": quality_score,
        "requirements_met": quality_score >= 60,
        "strengths": ["按时完成"],
        "weaknesses": [] if not is_overdue else ["超时完成"],
        "performance_impact": int(quality_score / 10) - 5,  # -5 ~ +5
        "feedback": "任务完成" if not is_overdue else "任务超时完成"
    }

func _evaluate_complex_task_with_llm(ai: Node, task: Dictionary) -> Dictionary:
    """使用LLM评估复杂任务"""

    # 构建评估prompt
    var prompt = _build_task_evaluation_prompt(ai, task)

        ai.ai_settings.api_type,

        prompt,
        0.7  # temperature
    )

    # 解析LLM输出
    var result = _parse_llm_evaluation(llm_response)

    return result

func _apply_task_rewards(ai: Node, task: Dictionary, result: Dictionary):
    """应用任务奖励"""

    var rewards = task.get("rewards", {})

    # 绩效奖励
    if rewards.has("performance"):
        var performance_bonus = rewards.performance * (result.quality_score / 100.0)
        ai.work_data.performance_score += int(performance_bonus)

    # 经验奖励
    if rewards.has("experience"):
        var exp = rewards.experience
        ai.work_data.experience += exp

    # 金钱奖励 (极少,主要是工资)
    if rewards.has("money"):
        ai.money += rewards.money

    # 技能提升
    if rewards.has("skill"):
        var skill_name = rewards.skill
        if ai.skills.has(skill_name):
            ai.skills[skill_name] += 1

func _apply_task_penalties(ai: Node, task: Dictionary, result: Dictionary):
    """应用任务惩罚"""

    var penalties = task.get("penalties", {})

    # 绩效惩罚
    if penalties.has("performance"):
        ai.work_data.performance_score -= penalties.performance

    # 压力增加
    if penalties.has("stress"):
        ai.emotional_state.stress += penalties.stress

    # 心情下降
    ai.current_mood -= 10

func _create_task_memory(ai: Node, task: Dictionary, result: Dictionary):
    """创建任务完成记忆"""

    var memory_content = ""
    var emotional_valence = 0.0

    if result.requirements_met:
        memory_content = "我完成了任务: %s。%s" % [task.title, result.feedback]
        emotional_valence = 0.5 + (result.quality_score / 200.0)  # 0.5~1.0
    else:
        memory_content = "我没能完成好任务: %s。%s" % [task.title, result.feedback]
        emotional_valence = -0.5 - (0.5 - result.quality_score / 200.0)  # -0.5~-1.0

    MemoryManager.add_memory(
        ai,
        memory_content,
        MemoryManager.MemoryType.TASK,
        MemoryManager.MemoryImportance.NORMAL if result.requirements_met else MemoryManager.MemoryImportance.HIGH
    )
```

### 5.2 动态优先级计算

```gdscript
# TaskSystem.gd
enum TaskPriority {
    URGENT_IMPORTANT = 1,      # 紧急重要
    IMPORTANT_NOT_URGENT = 2,  # 重要不紧急
    URGENT_NOT_IMPORTANT = 3,  # 紧急不重要
    NOT_URGENT_NOT_IMPORTANT = 4  # 不紧急不重要
}

func calculate_task_priority(ai: Node, task: Dictionary) -> int:
    """动态计算任务优先级"""

    var urgency = _calculate_urgency(task)
    var importance = _calculate_importance(ai, task)

    if urgency >= 70 and importance >= 70:
        return TaskPriority.URGENT_IMPORTANT
    elif importance >= 70:
        return TaskPriority.IMPORTANT_NOT_URGENT
    elif urgency >= 70:
        return TaskPriority.URGENT_NOT_IMPORTANT
    else:
        return TaskPriority.NOT_URGENT_NOT_IMPORTANT

func _calculate_urgency(task: Dictionary) -> float:
    """计算紧急度 (0-100)"""

    var urgency = 0.0

    # 因素1: Deadline临近
    if task.has("deadline"):
        var time_left = task.deadline - TimeSystem.get_current_timestamp()
        var deadline_urgency = 100.0 - (time_left / 3600.0) * 10  # 每小时-10
        urgency += clamp(deadline_urgency, 0, 100) * 0.6

    # 因素2: 任务类型天然紧急度
    var type_urgency = {
        "urgent_bug": 100,
        "meeting": 80,
        "meal": 70,
        "sleep": 60,
        "work": 40,
        "social": 30,
        "growth": 10
    }
    urgency += type_urgency.get(task.type, 30) * 0.4

    return clamp(urgency, 0, 100)

func _calculate_importance(ai: Node, task: Dictionary) -> float:
    """计算重要度 (0-100)"""

    var importance = 0.0

    # 因素1: 任务类型基础重要度
    var type_importance = {
        "work": 80,      # 工作最重要 (收入来源)
        "meal": 75,      # 吃饭很重要
        "sleep": 85,     # 睡觉非常重要
        "health": 70,    # 健康重要
        "social": 50,    # 社交中等重要
        "growth": 40,    # 成长长期重要
        "entertainment": 20  # 娱乐不重要
    }
    importance += type_importance.get(task.type, 50) * 0.5

    # 因素2: 性格影响
    if task.type == "work":
        # 尽责性高的AI认为工作更重要
        importance += (ai.personality.conscientiousness / 100.0) * 20
    elif task.type == "social":
        # 外向性高的AI认为社交更重要
        importance += (ai.personality.extraversion / 100.0) * 30
    elif task.type == "growth":
        # 开放性高的AI认为学习更重要
        importance += (ai.personality.openness / 100.0) * 40

    # 因素3: 当前需求影响
    if task.type == "meal":
        var hunger = ai.physical_state.hunger
        if hunger > 80:
            importance += 20  # 非常饿时,吃饭极重要
    elif task.type == "sleep":
        var fatigue = ai.physical_state.fatigue
        if fatigue > 80:
            importance += 15

    return clamp(importance, 0, 100)
```

```gdscript
func remove_completed_tasks(ai_id: String):
    """移除已完成/失败的任务"""

    if not active_tasks.has(ai_id):
        return

    var remaining_tasks = []

    for task in active_tasks[ai_id]:
        if task.status in [TaskData.TaskStatus.COMPLETED, TaskData.TaskStatus.FAILED, TaskData.TaskStatus.CANCELED]:
            # 移到历史记录
            if not task_history.has(ai_id):
                task_history[ai_id] = []
            task_history[ai_id].append(task)
        else:
            remaining_tasks.append(task)

    active_tasks[ai_id] = remaining_tasks

# ========================================
# 任务调度
# ========================================

func _on_hour_changed(new_hour: int):
    """每小时检查任务"""

    for ai_id in active_tasks.keys():
        var ai = _get_ai_by_id(ai_id)
        if not ai:
            continue

        # 检查是否有任务到时间
        var next_task = get_next_task(ai_id)
        if next_task:
            # 通知AI开始任务 (AIAgent会处理)
            ai.on_new_task_available(next_task)

func _on_day_changed(new_day: int):
    """每天生成新任务"""

    var all_ais = _get_all_ai_nodes()
    for ai in all_ais:
        generate_daily_tasks(ai)

# ========================================
# 工具函数
# ========================================

func _generate_task_id() -> String:
    """生成任务ID"""
    return "task_%d_%d" % [Time.get_ticks_msec(), randi()]

func _format_time(hour: float) -> String:
    """格式化时间"""
    var h = int(hour)
    var m = int((hour - h) * 60)
    return "%02d:%02d" % [h, m]

func _get_ai_by_id(ai_id: String) -> Node:

func _get_all_ai_nodes() -> Array:

func _calculate_growth_task_probability(ai: Node) -> float:
    """计算生成成长任务的概率"""

    # 开放性高的AI更可能设定成长任务
    var O = ai.personality.openness
    var base_prob = O / 200.0  # 0.0 ~ 0.5

    # 尽责性影响是否坚持
    var C = ai.personality.conscientiousness
    base_prob *= (C / 50.0)  # × 0 ~ 2

    return clamp(base_prob, 0.0, 0.3)  # 最高30%
```

## 总结

AI任务系统是Microverse生活模拟的**行为具象化引擎**。它将抽象的"工作"、"社交"、"学习"转化为具体的任务单元,赋予AI生活节奏和目标感。

**核心价值:**
1. **连接系统** - 任务是职业、经济、日程、关系的交汇点
2. **驱动叙事** - 任务完成/失败创造故事和记忆
3. **展现性格** - 任务决策和完成方式体现性格差异
4. **创造压力** - Deadline和优先级矛盾创造真实的生活压力感

**文件清单:**
- `script/task/TaskSystem.gd` - 任务系统管理器 (Autoload)
- `script/task/TaskData.gd` - 任务数据结构
- `script/task/TaskDefinitions.gd` - 任务模板定义
- `script/task/SocialTaskSystem.gd` - 社交任务子系统
- `docs/design/09.5_AI任务系统详细规范.md` - 本规范文档
