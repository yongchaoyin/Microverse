## 🎯 系统概述

### 设计原则

**核心哲学**:
- ✅ **完整性**: 存储AI的所有状态、记忆、思考
- ✅ **可追溯**: 每个数据变化都有时间戳和原因
- ✅ **可扩展**: 支持未来新增字段和系统
- ✅ **高性能**: 快速读写,支持实时查询
- ✅ **可读性**: 数据结构清晰,便于调试和查看

### 数据分层

```
┌─────────────────────────────────────────────┐
│  运行时数据 (Runtime Data)                   │
│  - AI当前状态                                │

               │

└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│  持久化数据 (Persistent Data)                │
│  - AI核心属性                                │
│  - 长期记忆                                  │
│  - 关系网络                                  │
│  - 目标和计划                                │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐

│  - 完整游戏状态                              │

│  - 世界状态                                  │
└─────────────────────────────────────────────┘
```

### 数据存储策略

**方案**: **JSON + SQLite 混合方案**

| 数据类型 | 存储方式 | 原因 |
|---------|---------|------|
| **AI核心属性** | JSON文件 | 易于编辑、版本控制 |
| **性格配置** | JSON文件 | 静态数据、预设配置 |
| **记忆数据** | SQLite数据库 | 大量数据、需要查询 |
| **关系网络** | SQLite数据库 | 复杂查询、关系图谱 |
| **思考历史** | SQLite数据库 | 时序数据、可追溯 |
| **游戏存档** | JSON文件 | 完整快照、易于备份 |

```gdscript
# 计算记忆有效性
func calculate_effectiveness() -> float:
	var time_factor = recency_score
	var strength_factor = strength
	var importance_factor = importance / 100.0
	var access_factor = min(access_count / 10.0, 1.0)

	return (time_factor * 0.3 + strength_factor * 0.3 +
	        importance_factor * 0.2 + access_factor * 0.2)

# 更新访问
func on_accessed():
	access_count += 1
	last_accessed = TimeSystem.get_current_timestamp()
	strength = min(strength + 0.1, 1.0)  # 访问增强记忆

# 应用衰减
func apply_decay(days_passed: int):
	var decay = decay_rate * days_passed
	strength = max(strength - decay, 0.0)

	if strength < 0.1:
		is_forgotten = true

	# 更新时效性评分
	recency_score = max(recency_score - (days_passed * 0.05), 0.0)
```

```gdscript
func calculate_relationship_quality() -> float:
	var f_score = familiarity / 100.0
	var a_score = (affection + 100) / 200.0  # 归一化到0-1
	var t_score = trust / 100.0
	var r_score = romance / 100.0 if is_romance_unlocked else 0.0

	# 加权平均
	return (f_score * 0.3 + a_score * 0.4 + t_score * 0.2 + r_score * 0.1)

# 更新关系标签
func update_tags():
	tags.clear()

	# 根据各维度值确定标签
	if familiarity < 20:
		tags.append("strangers")
	elif familiarity < 50:
		tags.append("acquaintances")
	elif familiarity < 80:
		tags.append("friends")
	else:
		tags.append("close_friends")

	if affection > 70 and familiarity > 60:
		tags.append("best_friends")

	if affection < -50:
		tags.append("enemies")
	elif affection < -20:
		tags.append("rivals")

	if is_romance_unlocked and romance > 50:
		tags.append("lovers")

	if is_romance_unlocked and romance > 80 and affection > 80:
		tags.append("engaged")

	if is_colleague:
		tags.append("colleagues")

	if is_family:
		tags.append("family")

func record_interaction(interaction_type: String, value_changes: Dictionary):
	total_interactions += 1
	last_interaction = TimeSystem.get_current_timestamp()

	# 记录趋势
	if value_changes.has("affection"):
		affection_trend.append(value_changes.affection)
		if affection_trend.size() > 10:
			affection_trend.remove_at(0)

		if trust_trend.size() > 10:
			trust_trend.remove_at(0)

	# 记录变化
	recent_changes.append({
		"type": interaction_type,
		"changes": value_changes,
		"timestamp": TimeSystem.get_current_timestamp()
	})

	if recent_changes.size() > 20:
```
