# AI性格系统详细规范 (Personality System - Big Five Model)

## 📋 系统概述

AI性格系统是Microverse的**核心差异化特征**。每个AI角色拥有基于**大五人格模型（Big Five）**的独特性格,性格会影响AI的所有决策和行为。

**设计原则**:
- 性格是**永久的**（不会因事件改变,但会影响AI对事件的反应）
- 性格影响**所有系统**（社交、工作、消费、健康）
- 性格创造**可预测的多样性**（玩家可以逐渐理解每个AI的特质）
- 性格是**涌现叙事的基础**（性格冲突和契合产生故事）

## 🧠 Big Five人格维度定义

每个AI角色拥有5个性格维度,每个维度范围：**0-100**

### 1. 外向性 (Extraversion) - E值

**定义**: 社交主动性、精力来源、表达欲望

```yaml
外向性: 0-100
  0-20: 极度内向 (Highly Introverted)
    - 避免社交,独处充电
    - 主动对话概率: 5%
    - 参加聚会概率: 10%
    - 独处需求: 高

  21-40: 内向 (Introverted)
    - 偏好小规模社交
    - 主动对话概率: 15%
    - 参加聚会概率: 30%

  41-60: 中性 (Ambivert)
    - 社交和独处均衡
    - 主动对话概率: 30%
    - 参加聚会概率: 50%

  61-80: 外向 (Extraverted)
    - 享受社交,主动交流
    - 主动对话概率: 50%
    - 参加聚会概率: 80%

  81-100: 极度外向 (Highly Extraverted)
    - 需要社交,害怕孤独
    - 主动对话概率: 80%
    - 参加聚会概率: 95%
```

**影响系统**:
- **社交频率**: `基础社交需求 × (E/50)`
- **咖啡馆去频率**: `基础值 × (E/50)`
- **周末独处概率**: `100% - E%`
- **孤独惩罚**: 外向AI长时间独处 → 心情-20

---

### 2. 宜人性 (Agreeableness) - A值

**定义**: 友善、合作、利他主义

```yaml
宜人性: 0-100
  0-20: 极度不友善 (Highly Disagreeable)
    - 自我中心,难以相处
    - 送礼概率: 5%
    - 接受邀请概率: 20%
    - 冲突概率: 80%

  21-40: 不友善 (Disagreeable)
    - 直率,不在意他人感受
    - 送礼概率: 15%
    - 冲突概率: 40%

  41-60: 中性 (Neutral)
    - 有选择性的友善
    - 送礼概率: 30%
    - 冲突概率: 20%

  61-80: 友善 (Agreeable)
    - 乐于助人,避免冲突
    - 送礼概率: 60%
    - 冲突概率: 5%

  81-100: 极度友善 (Highly Agreeable)
    - 牺牲自我,讨好他人
    - 送礼概率: 90%
    - 冲突概率: 1%
```

**影响系统**:
- **送礼频率**: `基础值 × (A/50)`
- **帮助他人概率**: `A%`
- **冲突发生率**: `100% - A%`
- **关系修复速度**: `基础值 × (A/50)`

---

### 3. 尽责性 (Conscientiousness) - C值

**定义**: 自律、规划、目标导向

```yaml
尽责性: 0-100
  0-20: 极度随性 (Highly Unconscientious)
    - 无计划,冲动行为
    - 迟到概率: 80%
    - 加班概率: 5%
    - 储蓄率: 0-10%

  21-40: 随性 (Unconscientious)
    - 较少规划
    - 迟到概率: 40%
    - 加班概率: 15%
    - 储蓄率: 10-20%

  41-60: 中性 (Moderate)
    - 基本计划
    - 迟到概率: 15%
    - 加班概率: 30%
    - 储蓄率: 20-30%

  61-80: 尽责 (Conscientious)
    - 有规划,守时
    - 迟到概率: 5%
    - 加班概率: 60%
    - 储蓄率: 30-50%

  81-100: 极度尽责 (Highly Conscientious)
    - 完美主义,过度自律
    - 迟到概率: 1%
    - 加班概率: 90%
    - 储蓄率: 50-70%
```

**影响系统**:
- **加班概率**: `职业基础加班率 × (C/50)`
- **储蓄率**: `月收入 × (C/100)`
- **迟到概率**: `100% - C%`
- **完成任务速度**: `基础速度 × (1 + C/200)`

---

### 4. 神经质 (Neuroticism) - N值

**定义**: 情绪稳定性、焦虑倾向、压力敏感

```yaml
神经质: 0-100
  0-20: 极度稳定 (Highly Stable)
    - 情绪平稳,压力不敏感
    - 焦虑概率: 5%
    - 生病概率: 0.5%/周
    - 压力阈值: 80

  21-40: 稳定 (Stable)
    - 较少情绪波动
    - 焦虑概率: 15%
    - 生病概率: 2%/周
    - 压力阈值: 60

  41-60: 中性 (Moderate)
    - 正常情绪波动
    - 焦虑概率: 30%
    - 生病概率: 4%/周
    - 压力阈值: 40

  61-80: 神经质 (Neurotic)
    - 容易焦虑,压力敏感
    - 焦虑概率: 60%
    - 生病概率: 6%/周
    - 压力阈值: 20

  81-100: 极度神经质 (Highly Neurotic)
    - 持续焦虑,脆弱
    - 焦虑概率: 90%
    - 生病概率: 8%/周
    - 压力阈值: 10
```

**影响系统**:
- **生病概率**: `基础概率 × (N/50)`
- **压力累积速度**: `基础速度 × (N/50)`
- **负面事件心情惩罚**: `基础惩罚 × (N/50)`
- **恢复速度**: `基础速度 × (2 - N/50)`

---

### 5. 开放性 (Openness) - O值

**定义**: 好奇心、创造力、接受新事物

```yaml
开放性: 0-100
  0-20: 极度保守 (Highly Closed)
    - 拒绝改变,固守习惯
    - 尝试新事物概率: 5%
    - 接受新朋友概率: 10%
    - 跳槽概率: 1%

  21-40: 保守 (Closed)
    - 偏好熟悉事物
    - 尝试新事物概率: 20%
    - 接受新朋友概率: 30%
    - 跳槽概率: 5%

  41-60: 中性 (Moderate)
    - 有选择的尝试
    - 尝试新事物概率: 40%
    - 接受新朋友概率: 50%
    - 跳槽概率: 10%

  61-80: 开放 (Open)
    - 好奇,乐于尝试
    - 尝试新事物概率: 70%
    - 接受新朋友概率: 80%
    - 跳槽概率: 20%

  81-100: 极度开放 (Highly Open)
    - 追求新鲜,难以专注
    - 尝试新事物概率: 95%
    - 接受新朋友概率: 95%
    - 跳槽概率: 40%
```

**影响系统**:
- **对话主题多样性**: `基础主题数 × (O/50)`
- **跳槽概率**: `基础值 × (O/50)`
- **创业意愿**: `O > 60 才考虑`
- **新关系建立速度**: `基础速度 × (O/50)`

## 🎯 性格对各系统的具体影响公式

### 1. 社交系统影响

```gdscript
# 主动社交频率（每周次数）
func calculate_social_frequency(personality) -> int:
    var E = personality.extraversion
    var A = personality.agreeableness
    var base_frequency = 3  # 基础每周3次
    var e_modifier = E / 50.0  # 0.0-2.0倍
    var a_modifier = 1.0 + (A - 50) / 100.0  # 0.5-1.5倍
    return int(base_frequency * e_modifier * a_modifier)

# 送礼概率
func get_gift_probability(personality) -> float:
    var A = personality.agreeableness
    var base_prob = 0.1  # 基础10%
    return base_prob * (A / 50.0)

# 冲突概率
func get_conflict_probability(p1, p2) -> float:
    var A_avg = (p1.agreeableness + p2.agreeableness) / 2.0
    var base_conflict = 0.2  # 基础20%
    return base_conflict * (1.0 - A_avg / 100.0)
```

### 2. 经济系统影响

```gdscript
# 每月储蓄率
func calculate_savings_rate(personality) -> float:
    var C = personality.conscientiousness
    var min_savings = 0.0
    var max_savings = 0.7
    return min_savings + (max_savings - min_savings) * (C / 100.0)

# 冲动消费概率
func get_impulse_buy_probability(personality) -> float:
    var C = personality.conscientiousness
    var O = personality.openness
    var base_prob = 0.3
    var c_modifier = (100 - C) / 100.0  # 尽责性越低,冲动性越高
    var o_modifier = O / 100.0  # 开放性越高,尝试新东西概率越高
    return base_prob * c_modifier * o_modifier
```

### 3. 工作系统影响

```gdscript
# 加班概率
func get_overtime_probability(personality, career_base) -> float:
    var C = personality.conscientiousness
    var N = personality.neuroticism
    var c_modifier = C / 50.0
    var n_modifier = 1.0 + (N - 50) / 200.0  # 神经质AI可能因焦虑而加班
    return career_base * c_modifier * n_modifier

# 迟到概率
func get_late_probability(personality) -> float:
    var C = personality.conscientiousness
    var base_late = 0.2  # 基础20%
    return base_late * (1.0 - C / 100.0)

# 跳槽概率（每季度检查）
func get_job_change_probability(personality) -> float:
    var O = personality.openness
    var N = personality.neuroticism
    var base_prob = 0.05  # 基础5%
    var o_modifier = O / 50.0
    var n_modifier = 1.0 + (N - 50) / 100.0  # 神经质AI可能因压力跳槽
    return base_prob * o_modifier * n_modifier
```

### 4. 健康系统影响

```gdscript
# 每周生病概率
func get_illness_probability(personality, stress) -> float:
    var N = personality.neuroticism
    var base_prob = 0.02  # 基础2%
    var n_modifier = N / 50.0
    var stress_modifier = 1.0 + (stress / 100.0)  # 压力越大,越容易生病
    return base_prob * n_modifier * stress_modifier

# 压力累积速度（每周）
func calculate_stress_accumulation(personality) -> float:
    var N = personality.neuroticism
    var C = personality.conscientiousness
    var base_stress = 10.0  # 基础每周+10压力
    var n_modifier = N / 50.0
    var c_modifier = C / 50.0  # 尽责AI加班多,压力大
    return base_stress * n_modifier * c_modifier
```

### 5. 情绪系统影响

```gdscript
# 基础心情值（50为中性）
func get_base_mood(personality) -> int:
    var N = personality.neuroticism
    var E = personality.extraversion
    var base_mood = 50
    var n_penalty = (N - 50) * 0.3  # 神经质惩罚
    var e_bonus = (E - 50) * 0.2  # 外向奖励
    return int(base_mood - n_penalty + e_bonus)

# 负面事件心情惩罚倍率
func get_negative_event_modifier(personality) -> float:
    var N = personality.neuroticism
    return N / 50.0  # 0.0-2.0倍

# 正面事件心情奖励倍率
func get_positive_event_modifier(personality) -> float:
    var E = personality.extraversion
    var O = personality.openness
    return (E + O) / 100.0  # 0.0-2.0倍
```

```gdscript
func _random_normal(mean: float, std_dev: float) -> float:
    """正态分布随机数（Box-Muller变换）"""
    var u1 = randf()
    var u2 = randf()
    var z = sqrt(-2.0 * log(u1)) * cos(2.0 * PI * u2)
    return clamp(mean + z * std_dev, 0, 100)

func get_compatibility(p1: Personality, p2: Personality) -> float:
    """计算两个性格的契合度 (0.0-1.0)"""
    var e_diff = abs(p1.extraversion - p2.extraversion)
    var a_sum = p1.agreeableness + p2.agreeableness
    var n_diff = abs(p1.neuroticism - p2.neuroticism)
    var o_sim = 100 - abs(p1.openness - p2.openness)

    # 宜人性越高越容易相处
    # 外向性和神经质差异过大会有摩擦
    # 开放性相似容易有共同话题
    var compatibility = (a_sum / 200.0) * 0.4 + \
                       (1.0 - e_diff / 100.0) * 0.2 + \
                       (1.0 - n_diff / 100.0) * 0.2 + \
                       (o_sim / 100.0) * 0.2

    return clamp(compatibility, 0.0, 1.0)
```

## 🎭 AI情绪系统详细规范 (Emotion System)

### 情绪系统概述

情绪系统是AI行为的**短期动态层**，与性格系统（永久特质）形成对比。情绪会随时间和事件变化，直接影响AI的决策和行为。

**设计原则**:
- 情绪是**动态的**（随事件触发、随时间衰减）
- 情绪与**性格交互**（性格影响情绪强度和持续时间）
- 情绪影响**行为权重**（同样的AI在不同情绪下做出不同决策）
- 情绪创造**短期戏剧性**（快乐时主动社交、悲伤时回避他人）

### 情绪衰减算法

```gdscript
# EmotionSystem.gd

class EmotionData:
	var happiness: float = 0.0      # -100到100
	var anger: float = 0.0          # 0到100
	var anxiety: float = 0.0        # 0到100
	var loneliness: float = 0.0     # 0到100
	var energy: float = 70.0        # 0到100

	func decay_emotions(delta_hours: float, personality: Personality):
		"""每小时自动衰减情绪"""

		# 快乐/悲伤 自然回归中性
		var happiness_decay_rate = 0.05 * (2.0 - personality.neuroticism / 100.0)
		if happiness > 0:
			happiness = max(happiness - happiness * happiness_decay_rate * delta_hours, 0)
		else:
			happiness = min(happiness - happiness * happiness_decay_rate * delta_hours, 0)

		# 愤怒 逐渐消退
		var anger_decay_rate = 0.1 * (personality.agreeableness / 50.0)
		anger = max(anger - anger * anger_decay_rate * delta_hours, 0)

		# 焦虑 逐渐缓解
		var anxiety_decay_rate = 0.08 * (2.0 - personality.neuroticism / 50.0)
		anxiety = max(anxiety - anxiety * anxiety_decay_rate * delta_hours, 0)

		# 孤独 外向AI自然累积（无社交时）
		var loneliness_gain_rate = (personality.extraversion / 50.0) * 1.5
		loneliness = clamp(loneliness + loneliness_gain_rate * delta_hours, 0, 100)

		# 精力 缓慢恢复（非睡眠时）
		if energy < 70:
			energy = min(energy + 2.0 * delta_hours, 70)

# 情绪触发事件
func trigger_emotion_event(ai: Node, event_name: String):
	"""触发情绪事件"""
	var emotion = ai.character_data.emotion
	var personality = ai.personality

	# 从事件表获取基础情绪变化
	var event_data = EMOTION_EVENTS.get(event_name, {})

	# 应用性格修正
	var happiness_mod = event_data.get("happiness", 0) * _get_happiness_modifier(personality)
	var anger_mod = event_data.get("anger", 0) * _get_anger_modifier(personality)
	var anxiety_mod = event_data.get("anxiety", 0) * _get_anxiety_modifier(personality)
	var loneliness_mod = event_data.get("loneliness", 0)
	var energy_mod = event_data.get("energy", 0)

	# 应用情绪变化
	emotion.happiness = clamp(emotion.happiness + happiness_mod, -100, 100)
	emotion.anger = clamp(emotion.anger + anger_mod, 0, 100)
	emotion.anxiety = clamp(emotion.anxiety + anxiety_mod, 0, 100)
	emotion.loneliness = clamp(emotion.loneliness + loneliness_mod, 0, 100)
	emotion.energy = clamp(emotion.energy + energy_mod, 0, 100)

	# 创建记忆
	var memory_text = "经历了事件: %s (心情%+d, 愤怒%+d)" % [
		event_name,
		int(happiness_mod),
		int(anger_mod)
	]
	MemoryManager.create_memory(ai.id, MemoryType.EMOTION, memory_text)

	# 发送事件通知
	EventBus.emit_signal("emotion_changed", ai.id, emotion)

func _get_happiness_modifier(p: Personality) -> float:
	"""快乐事件性格修正"""
	# 外向AI对正面事件反应更强烈
	# 神经质AI对负面事件反应更强烈
	var e_mod = 0.5 + (p.extraversion / 100.0)  # 0.5-1.5
	var n_mod = 0.5 + (p.neuroticism / 100.0)   # 0.5-1.5
	# 正面事件用E修正,负面事件用N修正（在trigger时判断）
	return (e_mod + n_mod) / 2.0

func _get_anger_modifier(p: Personality) -> float:
	"""愤怒事件性格修正"""
	# 宜人性低的AI更容易愤怒
	return 2.0 - (p.agreeableness / 100.0)  # 1.0-2.0

func _get_anxiety_modifier(p: Personality) -> float:
	"""焦虑事件性格修正"""
	# 神经质AI更容易焦虑
	return 0.5 + (p.neuroticism / 50.0)  # 0.5-2.5
```

```gdscript
class EmotionData:
	var happiness: float = 0.0      # -100到100
	var anger: float = 0.0          # 0到100
	var anxiety: float = 0.0        # 0到100
	var loneliness: float = 0.0     # 0到100
	var energy: float = 70.0        # 0到100

	# 上次更新时间（用于计算衰减）
	var last_update_time: float = 0.0

	func to_dict() -> Dictionary:
		return {
			"happiness": happiness,
			"anger": anger,
			"anxiety": anxiety,
			"loneliness": loneliness,
			"energy": energy,
			"last_update_time": last_update_time
		}

	static func from_dict(data: Dictionary) -> EmotionData:
		var emotion = EmotionData.new()
		emotion.happiness = data.get("happiness", 0.0)
		emotion.anger = data.get("anger", 0.0)
		emotion.anxiety = data.get("anxiety", 0.0)
		emotion.loneliness = data.get("loneliness", 0.0)
		emotion.energy = data.get("energy", 70.0)
		emotion.last_update_time = data.get("last_update_time", 0.0)
		return emotion

	func get_overall_mood() -> int:
		"""计算综合心情值（0-100）"""
		var mood = 50.0  # 基础
		mood += happiness * 0.4  # 快乐权重最高
		mood -= anger * 0.3
		mood -= anxiety * 0.2
		mood -= loneliness * 0.2
		mood += (energy - 50) * 0.1
		return int(clamp(mood, 0, 100))

	func get_emotion_label() -> String:
		"""获取情绪描述标签"""
		if happiness > 60:
			return "非常开心"
		elif happiness > 30:
			return "开心"
		elif happiness < -60:
			return "极度悲伤"
		elif happiness < -30:
			return "悲伤"
		elif anger > 70:
			return "暴怒"
		elif anger > 40:
			return "愤怒"
		elif anxiety > 70:
			return "惊恐焦虑"
		elif anxiety > 40:
			return "焦虑"
		elif loneliness > 70:
			return "极度孤独"
		elif loneliness > 40:
			return "孤独"
		elif energy < 20:
			return "精疲力竭"
		elif energy < 40:
			return "疲惫"
		else:
			return "平静"

func update_emotion(ai: Node, delta_hours: float):
	"""每小时更新AI情绪（自动衰减）"""
	var emotion: EmotionData = ai.character_data.get("emotion", EmotionData.new())
	var personality: PersonalitySystem.Personality = ai.personality

	# 快乐/悲伤 自然回归中性
	var happiness_decay_rate = 0.05 * (2.0 - personality.neuroticism / 100.0)
	if emotion.happiness > 0:
		emotion.happiness = max(emotion.happiness - emotion.happiness * happiness_decay_rate * delta_hours, 0)
	else:
		emotion.happiness = min(emotion.happiness - emotion.happiness * happiness_decay_rate * delta_hours, 0)

	# 愤怒 逐渐消退
	var anger_decay_rate = 0.1 * (personality.agreeableness / 50.0)
	emotion.anger = max(emotion.anger - emotion.anger * anger_decay_rate * delta_hours, 0)

	# 焦虑 逐渐缓解
	var anxiety_decay_rate = 0.08 * (2.0 - personality.neuroticism / 50.0)
	emotion.anxiety = max(emotion.anxiety - emotion.anxiety * anxiety_decay_rate * delta_hours, 0)

	# 孤独 外向AI自然累积（无社交时）
	var loneliness_gain_rate = (personality.extraversion / 50.0) * 1.5
	emotion.loneliness = clamp(emotion.loneliness + loneliness_gain_rate * delta_hours, 0, 100)

	# 精力 缓慢恢复（非睡眠时）
	if emotion.energy < 70:
		emotion.energy = min(emotion.energy + 2.0 * delta_hours, 70)

	emotion.last_update_time = TimeSystem.get_total_hours()

	# 保存回AI数据
	ai.character_data["emotion"] = emotion

func trigger_emotion_event(ai: Node, event_name: String):
	"""触发情绪事件"""
	var emotion: EmotionData = ai.character_data.get("emotion", EmotionData.new())
	var personality: PersonalitySystem.Personality = ai.personality

	# 从事件表获取基础情绪变化
	var event_data = EMOTION_EVENTS.get(event_name, {})
	if event_data.is_empty():
		push_warning("Unknown emotion event: " + event_name)
		return

	# 应用性格修正
	var happiness_change = event_data.get("happiness", 0)
	if happiness_change > 0:
		happiness_change *= (0.5 + personality.extraversion / 100.0)  # 外向AI对正面事件反应强
	else:
		happiness_change *= (0.5 + personality.neuroticism / 100.0)  # 神经质AI对负面事件反应强

	var anger_change = event_data.get("anger", 0) * (2.0 - personality.agreeableness / 100.0)
	var anxiety_change = event_data.get("anxiety", 0) * (0.5 + personality.neuroticism / 50.0)
	var loneliness_change = event_data.get("loneliness", 0)
	var energy_change = event_data.get("energy", 0)

	# 应用情绪变化
	emotion.happiness = clamp(emotion.happiness + happiness_change, -100, 100)
	emotion.anger = clamp(emotion.anger + anger_change, 0, 100)
	emotion.anxiety = clamp(emotion.anxiety + anxiety_change, 0, 100)
	emotion.loneliness = clamp(emotion.loneliness + loneliness_change, 0, 100)
	emotion.energy = clamp(emotion.energy + energy_change, 0, 100)

	# 保存回AI数据
	ai.character_data["emotion"] = emotion

	# 创建记忆
	var memory_text = "经历了%s，心情变为%s（快乐%+d, 愤怒%+d）" % [
		event_name,
		emotion.get_emotion_label(),
		int(happiness_change),
		int(anger_change)
	]
	MemoryManager.create_memory(ai.id, MemoryManager.MemoryType.EMOTION, memory_text, [], "", 0.6, happiness_change / 100.0)

	print("[情绪] %s 触发事件 %s: %s" % [ai.character_data.character_name, event_name, emotion.get_emotion_label()])

	# 发送事件通知
	EventBus.emit_signal("emotion_changed", ai.id, emotion)

func get_social_modifier(emotion: EmotionData) -> Dictionary:
	"""获取情绪对社交行为的影响"""
	var mod = {
		"initiate_social": 1.0,
		"accept_invitation": 1.0,
		"gift_probability": 1.0,
		"conflict_probability": 1.0
	}

	# 快乐影响
	if emotion.happiness > 60:
		mod.initiate_social *= 1.5
		mod.accept_invitation *= 1.8
		mod.gift_probability *= 2.0
		mod.conflict_probability *= 0.3
	elif emotion.happiness < -60:
		mod.initiate_social *= 0.1
		mod.accept_invitation *= 0.2
		mod.gift_probability *= 0.3
		mod.conflict_probability *= 0.8
	elif emotion.happiness < -30:
		mod.initiate_social *= 0.5
		mod.accept_invitation *= 0.6
		mod.gift_probability *= 0.7
		mod.conflict_probability *= 1.3

	# 愤怒影响
	if emotion.anger > 70:
		mod.initiate_social *= 0.2
		mod.accept_invitation *= 0.1
		mod.gift_probability *= 0.1
		mod.conflict_probability *= 5.0
	elif emotion.anger > 40:
		mod.initiate_social *= 0.6
		mod.accept_invitation *= 0.4
		mod.gift_probability *= 0.5
		mod.conflict_probability *= 2.0

	# 焦虑影响
	if emotion.anxiety > 70:
		mod.initiate_social *= 0.3
		mod.accept_invitation *= 0.2
		mod.conflict_probability *= 1.5
	elif emotion.anxiety > 40:
		mod.initiate_social *= 0.7
		mod.accept_invitation *= 0.6
		mod.conflict_probability *= 1.2

	# 孤独影响
	if emotion.loneliness > 70:
		mod.initiate_social *= 3.0
		mod.accept_invitation *= 2.0
		mod.gift_probability *= 1.5
		mod.conflict_probability *= 0.5
	elif emotion.loneliness > 40:
		mod.initiate_social *= 1.5
		mod.accept_invitation *= 1.3
		mod.conflict_probability *= 0.8

	return mod
```
