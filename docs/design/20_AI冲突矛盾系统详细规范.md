## 🎯 系统概述

### 设计原则

**核心理念**:
- ✅ **冲突是自然的** - 人际关系中必然有摩擦和矛盾
- ✅ **冲突创造故事** - 最精彩的故事往往源于冲突
- ✅ **冲突是可解的** - 冲突可以和解,也可以恶化
- ✅ **冲突影响深远** - 冲突会长期影响关系和行为

**设计目标**:
1. **多样化的冲突类型** - 价值观冲突、利益冲突、误会、竞争等
2. **真实的冲突过程** - 从轻微不和到激烈争吵到冷战
3. **丰富的表现形式** - 对话争吵、冷嘲热讽、回避、背后抱怨
4. **完整的冲突循环** - 触发→升级→高峰→冷战→和解/恶化

### 系统定位

在Microverse的AI社交网络中,冲突系统是:
- **关系系统**的动态层 - 让关系有起伏波动
- **情绪系统**的催化剂 - 冲突产生强烈情绪
- **记忆系统**的重要来源 - 冲突创造深刻记忆
- **LLM决策**的关键场景 - 冲突需要AI真实反应

## 🎭 冲突分类体系

### 1. 冲突类型 (ConflictType)

```yaml
冲突类型分类:

  # 价值观冲突 (Ideological Conflict)
  ideological:
    定义: 核心价值观、信念、生活方式的根本分歧
    严重性: 高 (难以调和)
    示例:
      - 工作狂 vs 享乐主义者 (尽责性极端差异)
      - 外向社交蝴蝶 vs 内向独行者 (外向性极端差异)
      - 完美主义 vs 随性自由 (尽责性冲突)
    触发条件:
      - 性格维度差异 > 50分
      - 长期互动暴露价值观差异
      - 涉及重要决策时分歧明显

  # 利益冲突 (Interest Conflict)
  interest:
    定义: 争夺有限资源、机会、利益
    严重性: 中高 (可能调和)
    示例:
      - 竞争同一个升职机会
      - 争抢同一个客户/项目
      - 追求同一个恋爱对象
      - 金钱纠纷 (借钱不还)
    触发条件:
      - 同职业且目标相似
      - 同时暗恋同一个AI
      - 财务往来中出现问题

  # 误会冲突 (Misunderstanding)
  misunderstanding:
    定义: 沟通不畅、信息偏差导致的冲突
    严重性: 低中 (容易解决)
    示例:
      - 误解对方言论的意图
      - 信息传递失真(传话走样)
      - 无心之言被过度解读
      - 行为被误判为恶意
    触发条件:
      - 神经质AI过度敏感
      - 宜人性低的AI言辞犀利被误解
      - 第三方传话失真

  # 竞争冲突 (Competition)
  competition:
    定义: 良性或恶性的竞争关系
    严重性: 低中 (可激励可恶化)
    示例:
      - 工作绩效竞争
      - 社交圈影响力竞争
      - 才华/能力比拼
      - 体育/游戏竞赛
    触发条件:
      - 同领域同水平的AI
      - 开放性高的AI乐于竞争
      - 尽责性高的AI追求卓越

  # 侵犯冲突 (Violation)
  violation:
    定义: 边界侵犯、权益受损
    严重性: 高 (破坏信任)
    示例:
      - 泄露秘密/隐私
      - 背叛承诺
      - 越界行为(过度干涉)
      - 侵占私人空间/物品
    触发条件:
      - 信任被打破
      - 承诺未兑现
      - 边界被反复侵犯

  # 情感冲突 (Emotional Conflict)
  emotional:
    定义: 情绪积累导致的爆发
    严重性: 中 (波动性大)
    示例:
      - 长期压抑后的情绪爆发
      - 嫉妒引发的冲突
      - 被忽视/冷落的不满
      - 情绪传染导致的连锁反应
    触发条件:
      - 神经质AI情绪积累
      - 被冷落超过阈值
      - 嫉妒心强的性格
```

### 2. 冲突严重等级 (ConflictSeverity)

```yaml
冲突严重等级:

  Level 1 - 轻微不和 (Minor Disagreement):
    好感度影响: -5 ~ -15
    信任度影响: -0 ~ -5
    冷战期: 0天 (无)
    和解概率: 90%
    自然消退: 1-2天
    表现:
      - 意见不合,礼貌争论
      - 轻微不悦,但不影响互动
      - "我不太同意你的看法"

  Level 2 - 明显分歧 (Clear Disagreement):
    好感度影响: -15 ~ -30
    信任度影响: -5 ~ -15
    冷战期: 1-3天
    和解概率: 70%
    自然消退: 3-5天
    表现:
      - 争论激烈,但保持克制
      - 明显不满,减少互动
      - "你怎么能这么想?!"
      - 互动频率降低50%

  Level 3 - 激烈冲突 (Heated Conflict):
    好感度影响: -30 ~ -50
    信任度影响: -15 ~ -30
    冷战期: 5-10天
    和解概率: 40%
    自然消退: 1-2周
    表现:
      - 公开争吵,情绪激动
      - 言辞犀利,可能伤人
      - "我受够你了!"
      - 主动回避对方
      - 互动频率降低90%

  Level 4 - 严重对立 (Severe Conflict):
    好感度影响: -50 ~ -70
    信任度影响: -30 ~ -50
    冷战期: 2-4周
    和解概率: 15%
    自然消退: 1-2月
    表现:
      - 完全拒绝沟通
      - 背后抱怨/诋毁
      - "别跟我提他/她!"
      - 100%回避
      - 可能影响共同朋友

  Level 5 - 敌对仇恨 (Hostility):
    好感度影响: -70 ~ -100
    信任度影响: -50 ~ -80
    冷战期: 永久 (除非特殊事件)
    和解概率: <5%
    自然消退: 几乎不可能
    表现:
      - 完全敌对
      - 主动破坏对方关系
      - 可能采取报复行动
      - "我再也不想见到你!"
      - 关系标签变为"enemies"
```

## ⚡ 冲突触发机制

### 触发公式

```gdscript
# 冲突触发概率计算
func calculate_conflict_probability(ai_a: Node, ai_b: Node, context: Dictionary) -> float:
	var base_prob = 0.05  # 基础5%概率

	# 1. 性格因素 (权重40%)
	var personality_factor = _get_personality_conflict_factor(ai_a, ai_b)

	# 2. 关系因素 (权重30%)
	var relationship_factor = _get_relationship_conflict_factor(ai_a, ai_b)

	# 3. 情绪因素 (权重20%)
	var emotion_factor = _get_emotion_conflict_factor(ai_a, ai_b)

	# 4. 环境因素 (权重10%)
	var context_factor = _get_context_conflict_factor(context)

	var total_prob = base_prob * (
		personality_factor * 0.4 +
		relationship_factor * 0.3 +
		emotion_factor * 0.2 +
		context_factor * 0.1
	)

	return clamp(total_prob, 0.0, 0.8)  # 最高80%
```

### 1. 性格冲突因子

```yaml
性格冲突计算:

  宜人性 (Agreeableness) - 最关键:
    - 双方平均宜人性 < 40: ×3.0倍冲突概率
    - 双方平均宜人性 40-60: ×1.5倍
    - 双方平均宜人性 > 60: ×0.3倍
    - 一方宜人性 < 20: +50%额外概率

  神经质 (Neuroticism):
    - 至少一方神经质 > 70: ×1.8倍 (敏感易怒)
    - 双方神经质都 > 60: ×2.2倍 (互相刺激)
    - 双方神经质都 < 30: ×0.5倍 (冷静理智)

  外向性 (Extraversion) 极端差异:
    - 差异 > 60分: ×1.5倍 (生活方式冲突)
    - 示例: 外向85 vs 内向10 = 社交需求完全相反

  尽责性 (Conscientiousness) 极端差异:
    - 差异 > 60分: ×1.6倍 (价值观冲突)
    - 示例: 完美主义90 vs 随性15 = 工作方式矛盾

  开放性 (Openness) 差异:
    - 差异 > 50分: ×1.3倍 (思维方式不同)
```

### 2. 关系冲突因子

```yaml
关系状态影响:

  好感度 (Affection):
    - 好感度 < 0: ×5.0倍 (已经厌恶)
    - 好感度 0-20: ×2.5倍 (不喜欢)
    - 好感度 20-50: ×1.0倍 (中性)
    - 好感度 > 50: ×0.3倍 (喜欢不易冲突)

  信任度 (Trust):
    - 信任度 < 30: ×2.0倍 (缺乏信任)
    - 信任度被降低事件: ×3.0倍 (背叛感)

  熟悉度 (Familiarity):
    - 熟悉度 < 20: ×1.5倍 (陌生容易误解)
    - 熟悉度 > 70: ×0.7倍 (了解减少冲突)

  历史冲突:
    - 过去7天有冲突: ×2.0倍
    - 过去30天冲突>3次: ×3.0倍 (积怨)

  浪漫关系特殊:
    - 恋人关系: 基础概率×0.5 (更包容)
    - 但情感冲突概率×3.0 (期待更高)
```

### 3. 情绪冲突因子

```yaml
情绪状态影响:

  愤怒 (Anger):
    - 至少一方愤怒 > 50: ×3.0倍
    - 双方愤怒 > 40: ×4.5倍

  压力 (Stress/Anxiety):
    - 至少一方压力 > 70: ×2.0倍
    - 双方压力 > 60: ×2.8倍

  悲伤 (Sadness):
    - 悲伤AI更易误解: ×1.5倍

  疲惫 (Energy < 30):
    - 疲惫降低耐心: ×1.6倍

  孤独 (Loneliness > 60):
    - 孤独AI可能敏感: ×1.4倍
```

### 4. 环境触发因素

```yaml
特定场景触发:

  工作场景:
    - 竞争同一升职机会: 基础50%
    - 工作失误被指责: 30%
    - 工作方式冲突: 20%
    - 加班被迫取消约会: 15%

  社交场景:
    - 公开场合被批评: 40%
    - 聚会上被冷落: 25%
    - 朋友被"抢走": 35%

  恋爱场景:
    - 发现出轨/暧昧: 90%
    - 被冷落忽视: 40%
    - 第三者介入: 70%
    - 价值观分歧(结婚、生子): 50%

  金钱场景:
    - 借钱不还: 80%
    - AA制分歧: 15%
    - 金钱价值观差异: 30%
```

## 📈 冲突升级路径

### 完整升级流程

```
正常关系 (好感度 > 30)
  ↓ 触发事件
轻微不和 Level 1 (-5~-15好感)
  ↓ 未和解 + 新冲突
明显分歧 Level 2 (-15~-30好感)
  ↓ 持续摩擦
激烈冲突 Level 3 (-30~-50好感)
  ↓ 公开争吵
严重对立 Level 4 (-50~-70好感)
  ↓ 重大事件/背叛
敌对仇恨 Level 5 (-70~-100好感)
```

### 升级条件矩阵

```yaml
从 Level N 升级到 Level N+1 的条件:

Level 1 → Level 2:
  - 冷战期内再次冲突
  - 或冲突未解决超过3天
  - 或对方做出轻微冒犯行为
  概率: 30%

Level 2 → Level 3:
  - 冷战期内激烈争论
  - 或公开场合意见对立
  - 或涉及核心价值观分歧
  概率: 40%

Level 3 → Level 4:
  - 争吵中言辞过激伤人
  - 或涉及重要利益冲突
  - 或情绪失控(愤怒>80)
  概率: 25%

Level 4 → Level 5:
  - 发生背叛/泄密
  - 或公开诋毁
  - 或伤害对方重要关系
  - 或报复行为
  概率: 15%
```

### 降级条件 (和解)

```yaml
从 Level N 降级到 Level N-1:

Level 2 → Level 1:
  - 一方主动道歉(宜人性>60)
  - 或第三方调解成功
  - 或冷战期自然降温
  概率: 70%

Level 3 → Level 2:
  - 真诚道歉+补偿
  - 或共同经历正面事件
  - 或第三方深度调解
  概率: 40%

Level 4 → Level 3:
  - 重大道歉+实质性弥补
  - 或面临共同危机(统一战线)
  - 或长时间(1月+)冷静
  概率: 15%

Level 5 → Level 4:
  - 几乎不可能自然和解
  - 需要特殊事件触发
  - 或玩家(观察者)干预
  概率: <5%
```

## 🎬 冲突表现形式

### 1. 对话表现

```yaml
Level 1 - 轻微不和:
  对话特征:
    - 礼貌但疏远
    - "我觉得...可能不太合适"
    - "我们还是各自有各自的想法吧"
    - 避免深入话题

  LLM Prompt提示:
    - "你和{对方}有些意见不合,但你保持礼貌"
    - "你的语气略显疏离"

Level 2 - 明显分歧:
  对话特征:
    - 直接表达不满
    - "你这样做真的不对"
    - "我不理解你为什么会这么想"
    - 语气明显不悦

  LLM Prompt提示:
    - "你对{对方}的做法很不满,直接表达出来"
    - "你的语气带着明显的不满和失望"

Level 3 - 激烈冲突:
  对话特征:
    - 情绪激动,声音提高
    - "你简直不可理喻!"
    - "我受够了你这种态度!"
    - "你凭什么这么说?!"

  LLM Prompt提示:
    - "你和{对方}正在激烈争吵,情绪很激动"
    - "你的话语犀利,甚至有些刻薄"
    - "你感到愤怒和受伤"

Level 4 - 严重对立:
  对话特征:
    - 拒绝对话
    - "我不想跟你说话"
    - "别来烦我"
    - 转身离开
    - 背后抱怨

  LLM Prompt提示:
    - "你完全不想和{对方}交流"
    - "看到{对方}你就感到厌烦"
    - "你可能会向别人抱怨{对方}"

Level 5 - 敌对仇恨:
  对话特征:
    - 公开敌对
    - "别让我看到你"
    - 冷嘲热讽
    - 主动破坏

  LLM Prompt提示:
    - "你对{对方}充满敌意"
    - "你甚至想破坏{对方}的人际关系"
```

### 2. 行为表现

```yaml
行为变化:

  Level 1-2:
    - 减少主动对话频率 (-50%)
    - 避免单独相处
    - 聚会上保持距离
    - 回复消息延迟

  Level 3:
    - 主动回避 (-90%互动)
    - 拒绝邀约
    - 同一房间也不交流
    - 聚会上明显对立

  Level 4:
    - 完全回避 (100%)
    - 对方靠近会离开
    - 背后向朋友抱怨
    - 可能影响共同朋友关系

  Level 5:
    - 主动敌对行为
    - 公开诋毁
    - 破坏对方社交网络
    - 可能报复(破坏工作等)
```

### 3. 视觉表现 (游戏内)

```yaml
UI表现:

  对话气泡:
    - Level 1-2: 黄色气泡 ⚠️

    - Level 4-5: 红色气泡,爆炸符号💥

  角色表情:
    - Level 1: 😐 (冷淡)
    - Level 2: 😤 (不满)
    - Level 3: 😠 (愤怒)
    - Level 4: 😡 (暴怒)
    - Level 5: 🤬 (仇恨)

  关系图谱:
    - 连线颜色: 橙色(Level 1-2) → 红色(Level 3-5)
    - 连线样式: 虚线(冷战) → 闪电(激烈)
    - 特殊图标: ⚡冲突中, ❄️冷战中

  动作表现:
    - 争吵时: 角色面对面,手势激动
    - 冷战时: 背对背,保持距离
    - 回避时: 看到对方转身离开
```

```gdscript
# script/ai/conflict/ConflictData.gd
class_name ConflictData extends Resource

# 冲突类型枚举
enum ConflictType {
	IDEOLOGICAL,      # 价值观冲突
	INTEREST,         # 利益冲突
	MISUNDERSTANDING, # 误会
	COMPETITION,      # 竞争
	VIOLATION,        # 侵犯
	EMOTIONAL         # 情感冲突
}

# 冲突严重等级
enum Severity {
	MINOR = 1,        # 轻微不和
	DISAGREEMENT = 2, # 明显分歧
	HEATED = 3,       # 激烈冲突
	SEVERE = 4,       # 严重对立
	HOSTILITY = 5     # 敌对仇恨
}

# 冲突状态
enum Status {
	ACTIVE,           # 正在发生
	COOLDOWN,         # 冷战中
	AWKWARD,          # 尴尬期
	RESOLVING,        # 和解中
	RESOLVED,         # 已解决
	ESCALATED         # 已升级为永久对立
}

# 基础信息
var conflict_id: String
var ai_a_id: String
var ai_b_id: String

# 冲突属性
var conflict_type: ConflictType
var severity: Severity
var status: Status

# 冲突原因
var trigger_reason: String
var trigger_event: String
var trigger_timestamp: Dictionary

# 冲突影响
var affection_damage_a: int = 0  # A对B好感度降低
var affection_damage_b: int = 0  # B对A好感度降低
var trust_damage_a: int = 0
var trust_damage_b: int = 0

# 冷战相关
var cooldown_days: int = 0
var cooldown_remaining: int = 0

# 历史记录
var dialogue_history: Array = []  # 冲突对话记录
var escalation_history: Array = []  # 升级历史
var attempts_reconciliation: int = 0  # 尝试和解次数

# 和解相关
var reconciliation_probability: float = 0.0
var mediator_id: String = ""  # 调解人ID (如果有)

func _init(a_id: String, b_id: String, type: ConflictType, reason: String):
	conflict_id = "%s_%s_%d" % [a_id, b_id, Time.get_unix_time_from_system()]
	ai_a_id = a_id
	ai_b_id = b_id
	conflict_type = type
	severity = Severity.MINOR
	status = Status.ACTIVE
	trigger_reason = reason
	trigger_timestamp = TimeSystem.get_current_time()

	_calculate_initial_damage()

func _calculate_initial_damage():
	match severity:
		Severity.MINOR:
			affection_damage_a = randi_range(5, 15)
			affection_damage_b = randi_range(5, 15)
			trust_damage_a = randi_range(0, 5)
			trust_damage_b = randi_range(0, 5)
			cooldown_days = 0
		Severity.DISAGREEMENT:
			affection_damage_a = randi_range(15, 30)
			affection_damage_b = randi_range(15, 30)
			trust_damage_a = randi_range(5, 15)
			trust_damage_b = randi_range(5, 15)
			cooldown_days = randi_range(1, 3)
		Severity.HEATED:
			affection_damage_a = randi_range(30, 50)
			affection_damage_b = randi_range(30, 50)
			trust_damage_a = randi_range(15, 30)
			trust_damage_b = randi_range(15, 30)
			cooldown_days = randi_range(5, 10)
		Severity.SEVERE:
			affection_damage_a = randi_range(50, 70)
			affection_damage_b = randi_range(50, 70)
			trust_damage_a = randi_range(30, 50)
			trust_damage_b = randi_range(30, 50)
			cooldown_days = randi_range(14, 28)
		Severity.HOSTILITY:
			affection_damage_a = randi_range(70, 100)
			affection_damage_b = randi_range(70, 100)
			trust_damage_a = randi_range(50, 80)
			trust_damage_b = randi_range(50, 80)
			cooldown_days = 9999  # 永久

	cooldown_remaining = cooldown_days

func escalate():
	"""冲突升级"""
	if severity < Severity.HOSTILITY:
		severity += 1
		escalation_history.append({
			"timestamp": TimeSystem.get_current_time(),
			"from_level": severity - 1,
			"to_level": severity,
			"reason": "冲突升级"
		})
		_calculate_initial_damage()

func start_cooldown():
	"""进入冷战期"""
	status = Status.COOLDOWN
	cooldown_remaining = cooldown_days

func attempt_reconciliation(mediator: String = ""):
	"""尝试和解"""
	attempts_reconciliation += 1
	status = Status.RESOLVING
	if mediator != "":
		mediator_id = mediator

func resolve(success: bool):
	"""和解结果"""
	if success:
		status = Status.RESOLVED
	else:
		status = Status.COOLDOWN

func to_dict() -> Dictionary:
	return {
		"conflict_id": conflict_id,
		"ai_a_id": ai_a_id,

		"conflict_type": ConflictType.keys()[conflict_type],

		"trigger_reason": trigger_reason,
		"affection_damage_a": affection_damage_a,
		"affection_damage_b": affection_damage_b,
		"trust_damage_a": trust_damage_a,
		"trust_damage_b": trust_damage_b,
```

```gdscript
extends Node

func check_conflict_trigger(ai_a: Node, ai_b: Node, context: Dictionary) -> bool:
	"""检查两个AI是否会发生冲突"""
	var prob = _calculate_conflict_probability(ai_a, ai_b, context)

	print("[Conflict] %s vs %s 冲突概率: %.1f%%" % [
		ai_a.character_name,
		ai_b.character_name,
		prob * 100
	])

	# 随机判定
	if randf() < prob:
		# 调用LLM判断冲突类型和严重性
		_trigger_conflict_via_llm(ai_a, ai_b, context)
		return true

	return false

func _calculate_conflict_probability(ai_a: Node, ai_b: Node, context: Dictionary) -> float:
	"""计算冲突概率"""
	var base_prob = 0.05

	# 1. 性格因素
	var personality_factor = _get_personality_conflict_factor(ai_a, ai_b)

	# 2. 关系因素
	var relationship_factor = _get_relationship_conflict_factor(ai_a, ai_b)

	# 3. 情绪因素
	var emotion_factor = _get_emotion_conflict_factor(ai_a, ai_b)

	# 4. 环境因素
	var context_factor = _get_context_conflict_factor(context)

	var total_prob = base_prob * (
		personality_factor * 0.4 +
		relationship_factor * 0.3 +
		emotion_factor * 0.2 +
		context_factor * 0.1
	)

	return clamp(total_prob, 0.0, 0.8)

func _get_personality_conflict_factor(ai_a: Node, ai_b: Node) -> float:
	"""性格冲突因子"""
	var p_a = PersonalitySystem.get_personality(ai_a.character_name)
	var p_b = PersonalitySystem.get_personality(ai_b.character_name)

	var factor = 1.0

	# 宜人性是最关键因素
	var avg_agreeableness = (p_a.agreeableness + p_b.agreeableness) / 2.0
	if avg_agreeableness < 40:
		factor *= 3.0
	elif avg_agreeableness < 60:
		factor *= 1.5
	else:
		factor *= 0.3

	# 神经质
	if p_a.neuroticism > 70 or p_b.neuroticism > 70:
		factor *= 1.8
	if p_a.neuroticism > 60 and p_b.neuroticism > 60:
		factor *= 2.2

	# 极端差异
	var e_diff = abs(p_a.extraversion - p_b.extraversion)
	if e_diff > 60:
		factor *= 1.5

	var c_diff = abs(p_a.conscientiousness - p_b.conscientiousness)
	if c_diff > 60:
		factor *= 1.6

	return factor

func _get_relationship_conflict_factor(ai_a: Node, ai_b: Node) -> float:
	"""关系冲突因子"""
	var rel = RelationshipSystem.get_relationship(ai_a.id, ai_b.id)
	var factor = 1.0

	# 好感度
	if rel.affection < 0:
		factor *= 5.0
	elif rel.affection < 20:
		factor *= 2.5
	elif rel.affection > 50:
		factor *= 0.3

	# 信任度
	if rel.trust < 30:
		factor *= 2.0

	# 历史冲突
	var recent_conflicts = _get_recent_conflicts(ai_a.id, ai_b.id, 7)
	if recent_conflicts > 0:
		factor *= (1.0 + recent_conflicts)

	return factor

func _get_emotion_conflict_factor(ai_a: Node, ai_b: Node) -> float:
	"""情绪冲突因子"""
	var emotion_a = ai_a.character_data.get("emotion", EmotionSystem.EmotionData.new())
	var emotion_b = ai_b.character_data.get("emotion", EmotionSystem.EmotionData.new())

	var factor = 1.0

	# 愤怒
	if emotion_a.anger > 50 or emotion_b.anger > 50:
		factor *= 3.0
	if emotion_a.anger > 40 and emotion_b.anger > 40:
		factor *= 4.5

	# 压力/焦虑
	if emotion_a.anxiety > 70 or emotion_b.anxiety > 70:
		factor *= 2.0

	# 精力低下
	if emotion_a.energy < 30 or emotion_b.energy < 30:
		factor *= 1.6

	return factor

func _get_context_conflict_factor(context: Dictionary) -> float:
	"""环境因素"""
	var factor = 1.0

	var scenario = context.get("scenario", "")

	match scenario:
		"work_criticism":
			factor = 3.0
		"competition":
			factor = 2.5
		"money_dispute":
			factor = 8.0
		"romance_triangle":
			factor = 7.0
		"betrayal":
			factor = 9.0

	return factor

# 冲突创建和管理

func _trigger_conflict_via_llm(ai_a: Node, ai_b: Node, context: Dictionary):
	"""通过LLM判断冲突详情并触发"""
	# 构建LLM Prompt
	var prompt_context = {
		"name": ai_a.character_name,
		"target_name": ai_b.character_name,
		"agreeableness": PersonalitySystem.get_personality(ai_a.character_name).agreeableness,
		"neuroticism": PersonalitySystem.get_personality(ai_a.character_name).neuroticism,

		"context_description": context.get("description", ""),

	}

	# 调用LLM (conflict_trigger_check Prompt)
	var llm_response = await _call_conflict_trigger_llm(ai_a, prompt_context)

	if llm_response.will_conflict:
		create_conflict(
			ai_a.id,
			ai_b.id,
			llm_response.conflict_type,
			llm_response.trigger_reason,
			llm_response.initial_severity
		)

func create_conflict(
	ai_a_id: String,
	ai_b_id: String,
	conflict_type: ConflictData.ConflictType,
	reason: String,
	initial_severity: int = 1
):
	"""创建新冲突"""
	var conflict = ConflictData.new(ai_a_id, ai_b_id, conflict_type, reason)
	conflict.severity = initial_severity

	var key = _get_conflict_key(ai_a_id, ai_b_id)
	active_conflicts[key] = conflict

	# 应用关系伤害
	_apply_conflict_damage(conflict)

	# 触发情绪反应
	_trigger_emotional_response(ai_a_id, conflict)
	_trigger_emotional_response(ai_b_id, conflict)

	# 开始冷战
	if conflict.severity >= ConflictData.Severity.DISAGREEMENT:
		conflict.start_cooldown()
		conflict_cooldown_started.emit(conflict)

	# 发出信号
	conflict_started.emit(conflict)

	print("[Conflict] 冲突创建: %s vs %s (类型:%s, 等级:%d)" % [
		ai_a_id,
		ai_b_id,
		ConflictData.ConflictType.keys()[conflict_type],
		initial_severity
	])

func _apply_conflict_damage(conflict: ConflictData):
	"""应用冲突对关系的伤害"""
	var rel_a_to_b = RelationshipSystem.get_relationship(conflict.ai_a_id, conflict.ai_b_id)
	var rel_b_to_a = RelationshipSystem.get_relationship(conflict.ai_b_id, conflict.ai_a_id)

	# 降低好感度
	rel_a_to_b.affection = clamp(
		rel_a_to_b.affection - conflict.affection_damage_a,
		-100, 100
	)
	rel_b_to_a.affection = clamp(
		rel_b_to_a.affection - conflict.affection_damage_b,
		-100, 100
	)

	# 降低信任度
	rel_a_to_b.trust = max(rel_a_to_b.trust - conflict.trust_damage_a, 0)
	rel_b_to_a.trust = max(rel_b_to_a.trust - conflict.trust_damage_b, 0)

	# 标记冲突状态
	rel_a_to_b.is_in_conflict = true
	rel_b_to_a.is_in_conflict = true
	rel_a_to_b.conflict_cooldown_days = conflict.cooldown_days
	rel_b_to_a.conflict_cooldown_days = conflict.cooldown_days

	# 添加冲突标签
	if not rel_a_to_b.tags.has("in_conflict"):
		rel_a_to_b.tags.append("in_conflict")
	if not rel_b_to_a.tags.has("in_conflict"):
		rel_b_to_a.tags.append("in_conflict")

func _trigger_emotional_response(ai_id: String, conflict: ConflictData):
	"""触发AI的情绪反应"""
	var ai = CharacterManager.get_character(ai_id)
	if not ai:
		return

	# 根据冲突严重性触发情绪
	var anger_increase = conflict.severity * 15
	var happiness_decrease = conflict.severity * 10

	EmotionSystem.trigger_emotion_event(ai, "conflict_occurred")

	# 额外愤怒
	var emotion = ai.character_data.get("emotion")
	if emotion:
		emotion.anger = min(emotion.anger + anger_increase, 100)
		emotion.happiness = max(emotion.happiness - happiness_decrease, -100)

# 冲突升级
# ========================================

func escalate_conflict(ai_a_id: String, ai_b_id: String, escalation_reason: String = ""):
	"""冲突升级"""
	var key = _get_conflict_key(ai_a_id, ai_b_id)
	var conflict = active_conflicts.get(key)

	if not conflict:
		return

	if conflict.severity >= ConflictData.Severity.HOSTILITY:
		print("[Conflict] 已达最高等级,无法继续升级")
		return

	conflict.escalate()
	_apply_conflict_damage(conflict)  # 重新应用伤害

	conflict_escalated.emit(conflict)

	print("[Conflict] 冲突升级: %s vs %s → Level %d (%s)" % [
		ai_a_id,
		ai_b_id,
		conflict.severity,
		escalation_reason
	])

# 和解系统
# ========================================

func attempt_reconciliation(
	ai_a_id: String,
	ai_b_id: String,
	mediator_id: String = ""
) -> bool:
	"""尝试和解"""
	var key = _get_conflict_key(ai_a_id, ai_b_id)
	var conflict = active_conflicts.get(key)

	if not conflict:
		print("[Conflict] 无活跃冲突,无需和解")
		return false

	if conflict.status != ConflictData.Status.COOLDOWN:
		print("[Conflict] 冲突尚未冷却,无法和解")
		return false

	conflict.attempt_reconciliation(mediator_id)

	# 计算和解成功率
	var success_rate = _calculate_reconciliation_success_rate(conflict, mediator_id)

	print("[Conflict] 和解尝试: %s vs %s (成功率:%.1f%%)" % [
		ai_a_id,
		ai_b_id,
		success_rate * 100
	])

	if randf() < success_rate:
		_resolve_conflict(conflict, true)
		return true
	else:
		conflict.status = ConflictData.Status.COOLDOWN
		return false

func _calculate_reconciliation_success_rate(conflict: ConflictData, mediator_id: String) -> float:
	"""计算和解成功率"""
	var base_rate = 0.0

	# 根据严重等级
	match conflict.severity:
		ConflictData.Severity.MINOR:
			base_rate = 0.9
		ConflictData.Severity.DISAGREEMENT:
			base_rate = 0.7
		ConflictData.Severity.HEATED:
			base_rate = 0.4
		ConflictData.Severity.SEVERE:
			base_rate = 0.15
		ConflictData.Severity.HOSTILITY:
			base_rate = 0.05

	# 调解人加成
	if mediator_id != "":
		var mediator = CharacterManager.get_character(mediator_id)
		if mediator:
			var mediator_personality = PersonalitySystem.get_personality(mediator.character_name)
			var bonus = mediator_personality.agreeableness / 200.0  # 0-0.5
			base_rate += bonus

	# 冷却时间加成
	var cooldown_passed = conflict.cooldown_days - conflict.cooldown_remaining
	if cooldown_passed > conflict.cooldown_days * 0.8:
		base_rate += 0.2  # 冷静期过了80%,+20%成功率

	return clamp(base_rate, 0.0, 0.95)

func _resolve_conflict(conflict: ConflictData, success: bool):
	"""解决冲突"""
	conflict.resolve(success)

	if success:
		# 移除冲突状态
		var rel_a_to_b = RelationshipSystem.get_relationship(conflict.ai_a_id, conflict.ai_b_id)
		var rel_b_to_a = RelationshipSystem.get_relationship(conflict.ai_b_id, conflict.ai_a_id)

		rel_a_to_b.is_in_conflict = false
		rel_b_to_a.is_in_conflict = false
		rel_a_to_b.tags.erase("in_conflict")
		rel_b_to_a.tags.erase("in_conflict")

		# 添加和解标签
		if not rel_a_to_b.tags.has("reconciled"):
			rel_a_to_b.tags.append("reconciled")
		if not rel_b_to_a.tags.has("reconciled"):
			rel_b_to_a.tags.append("reconciled")

		# 恢复部分好感度和信任度
		rel_a_to_b.affection = min(rel_a_to_b.affection + conflict.affection_damage_a * 0.5, 100)
		rel_b_to_a.affection = min(rel_b_to_a.affection + conflict.affection_damage_b * 0.5, 100)
		rel_a_to_b.trust = min(rel_a_to_b.trust + conflict.trust_damage_a * 0.3, 100)
		rel_b_to_a.trust = min(rel_b_to_a.trust + conflict.trust_damage_b * 0.3, 100)

		# 移除活跃冲突
		var key = _get_conflict_key(conflict.ai_a_id, conflict.ai_b_id)
		active_conflicts.erase(key)

		# 添加到历史
		conflict_history.append(conflict)

		conflict_resolved.emit(conflict)

		print("[Conflict] 冲突和解成功: %s vs %s" % [conflict.ai_a_id, conflict.ai_b_id])

# ========================================
# 每日更新
# ========================================

func process_daily_conflicts():
	"""每日处理冲突冷却"""
	for key in active_conflicts.keys():
		var conflict = active_conflicts[key]

		if conflict.status == ConflictData.Status.COOLDOWN:
			conflict.cooldown_remaining = max(conflict.cooldown_remaining - 1, 0)

			# 冷却期结束
			if conflict.cooldown_remaining == 0:
				conflict.status = ConflictData.Status.AWKWARD
				print("[Conflict] 冷战结束,进入尴尬期: %s vs %s" % [
					conflict.ai_a_id,
					conflict.ai_b_id
				])

func _call_conflict_trigger_llm(ai: Node, context: Dictionary) -> Dictionary:
	"""调用LLM判断冲突触发"""
	# 这里需要实际调用APIManager
	# 返回示例数据

		"will_conflict": true,

		"initial_severity": 2,

# ========================================
# 工具函数
# ========================================

func _get_conflict_key(ai_a_id: String, ai_b_id: String) -> String:
	"""生成冲突键 (双向统一)"""
	var ids = [ai_a_id, ai_b_id]
	ids.sort()
	return "%s:%s" % [ids[0], ids[1]]

func _get_recent_conflicts(ai_a_id: String, ai_b_id: String, days: int) -> int:
	"""获取最近N天的冲突次数"""
	var count = 0
	var current_time = TimeSystem.get_total_days()

	for conflict in conflict_history:
		if (conflict.ai_a_id == ai_a_id and conflict.ai_b_id == ai_b_id) or \
		   (conflict.ai_a_id == ai_b_id and conflict.ai_b_id == ai_a_id):
			var conflict_days = conflict.trigger_timestamp.total_days
			if current_time - conflict_days <= days:
				count += 1

	return count

func get_active_conflict(ai_a_id: String, ai_b_id: String) -> ConflictData:
	"""获取活跃冲突"""
	var key = _get_conflict_key(ai_a_id, ai_b_id)
	return active_conflicts.get(key)

func has_active_conflict(ai_a_id: String, ai_b_id: String) -> bool:
	"""是否有活跃冲突"""
	return get_active_conflict(ai_a_id, ai_b_id) != null
```

### 冲突系统核心特性

1. ✅ **6种冲突类型** - 价值观、利益、误会、竞争、侵犯、情感
2. ✅ **5个严重等级** - 从轻微不和到敌对仇恨

4. ✅ **真实冲突表现** - 争吵对话、冷战回避、背后抱怨
5. ✅ **多样化和解机制** - 道歉、调解、共同经历、时间淡化
6. ✅ **LLM深度集成** - 冲突对话和和解都由LLM生成
7. ✅ **完整数据结构** - ConflictData记录所有冲突信息
8. ✅ **与现有系统集成** - 关系、性格、情绪系统无缝衔接

- **性格驱动** - 宜人性低的AI更易冲突,神经质AI更敏感

- **情绪催化** - 冲突产生强烈情绪(愤怒、悲伤、压力)
- **记忆深刻** - 冲突成为重要记忆,影响未来决策
- **故事涌现** - 最精彩的故事往往源于冲突和和解
