# 21. AI导航系统详细规范 (AI Navigation System Specification)

## 系统概述

AI导航系统为AI角色提供基于命名地点的自主移动能力,配合日程系统实现AI角色在游戏世界中的智能导航和位置管理。

**核心功能:**
- 命名地点管理 (办公室、咖啡馆、家等)
- AI自主移动控制
- 基于日程的自动导航
- 地点占用追踪
- 最近地点查询
- 与现有NavigationServer2D pathfinding集成

---

## 架构设计

### 1. 系统组件

```
AI导航系统
├── LocationManager (Autoload单例)
│   ├── Location类 - 地点数据结构
│   ├── LocationType枚举 - 地点类型
│   ├── 地点注册/查询
│   └── 占用管理
│
├── AIMovementController (组件)
│   ├── 移动状态机
│   ├── 地点导航
│   ├── 日程驱动移动
│   └── CharacterController封装
│
└── 集成层
    ├── CharacterController - 现有移动控制器
    ├── NavigationServer2D - Godot导航系统
    └── AIAgent - AI行为控制
```

### 1.3 核心API

#### 地点注册

```gdscript
func register_location(
    id: String,
    name_cn: String,
    position: Vector2,
    type: LocationType,
    capacity: int = 10,
    interaction_points: Dictionary = {}
) -> Location
```

**用途:** 注册一个新地点到系统中

**参数:**
- `id`: 地点唯一标识符 (建议格式: `location_office_001`)
- `name_cn`: 中文显示名称 (如: "CEO办公室")
- `position`: 地点在场景中的世界坐标
- `type`: 地点类型枚举值
- `capacity`: 同时容纳人数上限 (默认10)
- `interaction_points`: 交互点字典 (可选)

**示例:**
```gdscript
LocationManager.register_location(
    "office_stephen",
    "CEO办公室",
    Vector2(1200, 800),
    LocationManager.LocationType.OFFICE,
    5,
    {"sit": [Vector2(1180, 820), Vector2(1220, 820)]}
)
```

### 1.4 从场景加载地点

LocationManager可以自动从场景中加载标记为`"location"`组的节点。

**场景配置方法:**

1. **在Godot编辑器中添加地点标记:**
   - 在Office场景中创建`Marker2D`节点
   - 添加到`location`组 (Node → Groups → Add "location")
   - 设置元数据 (Node → Meta Properties):
     ```
     location_id: "office_alice"
     location_name_cn: "Alice的工位"
     location_type: "OFFICE"
     location_capacity: 2
     ```

2. **LocationManager自动加载:**
   ```gdscript
   func _load_locations_from_scene():
       await get_tree().process_frame

       var location_nodes = get_tree().get_nodes_in_group("location")
       for node in location_nodes:
           if node.has_meta("location_id"):
               var id = node.get_meta("location_id")
               var name_cn = node.get_meta("location_name_cn", id)
               var type_str = node.get_meta("location_type", "OTHER")
               var type = _parse_location_type(type_str)
               var capacity = node.get_meta("location_capacity", 10)

               register_location(
                   id,
                   name_cn,
                   node.global_position,
                   type,
                   capacity
               )
   ```

## 二、AIMovementController (AI移动控制器)

### 2.1 移动状态机

```gdscript
enum MovementState {
    IDLE,                # 空闲状态
    MOVING_TO_LOCATION,  # 正在前往命名地点
    MOVING_TO_POSITION,  # 正在前往坐标
    WAITING,             # 等待状态
    FOLLOWING            # 跟随其他角色

```

**状态转换:**
```
IDLE ──move_to_location()──→ MOVING_TO_LOCATION ──到达──→ IDLE
  │                                                          ↑
  └──move_to_position()──→ MOVING_TO_POSITION ─────────────┘
```

### 2.3 日程驱动移动

```gdscript
func execute_schedule_movement(
    activity_type: String,
    location_id: String = ""
)
```

**功能:** 根据AI日程系统的活动类型,自动选择并移动到合适的地点。

**活动类型映射:**

| 活动类型 | 自动选择地点类型 |
|---------|----------------|
| "work" | OFFICE (办公室) |
| "meeting" | MEETING_ROOM (会议室) |
| "lunch", "dinner" | CAFETERIA (食堂) |
| "coffee_break" | COFFEE_SHOP (咖啡馆) |
| "gym", "exercise" | GYM (健身房) |
| "rest", "break" | LOUNGE (休息室) |
| "bathroom" | BATHROOM (洗手间) |
| "library", "study" | LIBRARY (图书馆) |
| "home", "sleep" | HOME (家) |
| 其他 | 随机游荡 (wander) |

**实现代码:**
```gdscript
func execute_schedule_movement(activity_type: String, location_id: String = ""):
    print("[AIMovementController] %s 执行日程移动: %s → %s" % [
        character_controller.name,
        activity_type,
        location_id if location_id != "" else "自动选择"
    ])

    # 如果指定了地点ID,直接移动
    if location_id != "":
        move_to_location(location_id)
        return

    # 根据活动类型自动选择地点
    match activity_type:
        "work":
            move_to_nearest_location(LocationManager.LocationType.OFFICE)
        "meeting":
            move_to_nearest_location(LocationManager.LocationType.MEETING_ROOM)
        "lunch", "dinner":
            move_to_nearest_location(LocationManager.LocationType.CAFETERIA)
        "coffee_break":
            move_to_nearest_location(LocationManager.LocationType.COFFEE_SHOP)
        "gym", "exercise":
            move_to_nearest_location(LocationManager.LocationType.GYM)
        "rest", "break":
            move_to_nearest_location(LocationManager.LocationType.LOUNGE)
        "bathroom":
            move_to_nearest_location(LocationManager.LocationType.BATHROOM)
        "library", "study":
            move_to_nearest_location(LocationManager.LocationType.LIBRARY)
        "home", "sleep":
            move_to_nearest_location(LocationManager.LocationType.HOME)
        _:
            # 未知活动类型,随机游荡
            wander_around(150.0)
```

**日程系统集成示例:**
```gdscript
# 在AIAgent.gd中
func _on_schedule_activity_changed(activity):
    if ai_movement_controller:
        ai_movement_controller.execute_schedule_movement(
            activity.type,
            activity.location_id  # 可选,如果日程指定了特定地点
        )
```

## 三、与现有系统集成

### 3.1 CharacterController集成

AIMovementController设计为CharacterController的**包装层**,不替换现有移动逻辑。

**集成方式:**
```gdscript
# AIMovementController._ready()
func _ready():
    character_controller = get_parent()
    if not character_controller:
        push_error("[AIMovementController] 必须挂载到CharacterController节点上")
        return

    # 连接CharacterController信号
    if character_controller.has_signal("navigation_completed"):
        character_controller.connect("navigation_completed", _on_navigation_completed)
```

**调用CharacterController方法:**
```gdscript
func move_to_location(location_id: String, callback: Callable = Callable()) -> bool:
    var location = LocationManager.get_location(location_id)
    if not location:
        return false

    # 调用CharacterController的move_to
    character_controller.move_to(location.position)

    movement_started.emit(location_id)
    return true
```

func create_all_locations():
    var locations_data = [

        ["lounge", "休息室", Vector2(1400, 1100), "LOUNGE", 12],

        ["tom_desk", "Tom的工位", Vector2(850, 600), "OFFICE", 1],

    ]

    var locations_container = Node2D.new()
    locations_container.name = "Locations"
    add_child(locations_container)

    for loc_data in locations_data:
        var marker = Marker2D.new()
        marker.name = loc_data[1]  # 使用中文名称
        marker.global_position = loc_data[2]
        marker.add_to_group("location")

        marker.set_meta("location_id", loc_data[0])
        marker.set_meta("location_name_cn", loc_data[1])
        marker.set_meta("location_type", loc_data[3])
        marker.set_meta("location_capacity", loc_data[4])

        locations_container.add_child(marker)
        marker.owner = get_tree().edited_scene_root  # 保存到场景

        print("创建地点标记: %s at %v" % [loc_data[1], loc_data[2]])

    print("所有地点标记创建完成!")
```

1. 在Godot编辑器中打开Office.tscn

3. 运行场景 (F5)
4. 地点标记自动创建
5. 保存场景 (Ctrl+S)
6. 删除临时脚本

@tool

func _run():

        var scene = load(scene_path)
        var character = scene.instantiate()

        # 检查是否已有AIMovementController
        if character.has_node("AIMovementController"):
            print("%s 已有AIMovementController,跳过" % character.name)
            continue

        # 添加AIMovementController节点
        var ai_movement = Node.new()
        ai_movement.name = "AIMovementController"
        ai_movement.set_script(load("res://script/navigation/AIMovementController.gd"))
        character.add_child(ai_movement)
        ai_movement.owner = character

        # 保存场景
        var packed_scene = PackedScene.new()
        packed_scene.pack(character)
        ResourceSaver.save(packed_scene, scene_path)

        print("为 %s 添加AIMovementController完成" % character.name)

    print("所有角色AIMovementController添加完成!")
```

**使用方法:**
1. 在Godot编辑器中: File → Run Script
2. 选择`AddAIMovementToCharacters.gd`
3. 运行

class Location:
    var reservations: Array = []  # [{ai_id: "Alice", time_start: 900, time_end: 1000}]

    func reserve(ai_id: String, time_start: int, time_end: int) -> bool:
        # 检查时间冲突
        for res in reservations:
            if time_start < res.time_end and time_end > res.time_start:

        })
