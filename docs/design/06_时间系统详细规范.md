# 时间系统详细规范 (Time System)

## 📋 系统概述

时间系统是Microverse的**核心基础系统**，所有其他系统（AI决策、经济、关系、日程）都依赖于时间系统运行。

**设计原则**:
- 时间流速要**适中**（既让玩家能观察到细节，又不会太慢）
- AI更新频率要**平衡**（既要有足够时间生成高质量内容，又要保持游戏流畅）
- 时间要**可控**（玩家可以暂停、加速、快进）
- 时间要**有意义**（不同时段、季节、星期对AI行为有真实影响）

---

## ⏰ 时间流速设计

### 核心参数

```yaml
基础倍速: ×3 (相对星露谷×14)
时间单位: 10分钟游戏时间
AI更新间隔: 30分钟游戏时间(3个时间单位)

换算关系:
  10分钟游戏时间 = 60秒现实时间
  1小时游戏时间 = 6分钟现实时间
  1游戏日(20小时) = 120分钟现实时间 (2小时)
  1游戏周 = 14小时现实时间
  1游戏季(28天) = 56小时现实时间
  1游戏年(112天) = 224小时现实时间
```

### 设计理由

**为什么选择×3倍速？**

1. **LLM生成质量保证**: 60秒现实时间让LLM有足够时间生成高质量的AI对话和决策
2. **观察体验平衡**: 2小时现实时间 = 1游戏日，玩家可以舒适地观察AI的完整一天
3. **API成本控制**: 30分钟游戏时间更新一次，平衡了AI智能性和API调用成本
4. **游戏节奏**: 既不会太慢（无聊），也不会太快（看不清）

## 📅 时间结构

### 日时间划分

```yaml
每日时间流程:
  6:00-8:00: 黎明时段 (12分钟现实)
    - AI起床、洗漱、早餐
    - 光线逐渐变亮

  8:00-12:00: 上午时段 (24分钟现实)
    - 工作日: 上班通勤、工作
    - 休息日: 自由活动

  12:00-14:00: 午间时段 (12分钟现实)
    - 午餐时间
    - 社交高峰期（咖啡馆、餐厅）

  14:00-18:00: 下午时段 (24分钟现实)
    - 继续工作/活动

  18:00-20:00: 傍晚时段 (12分钟现实)
    - 下班回家
    - 晚餐时间

  20:00-24:00: 夜间时段 (24分钟现实)
    - 社交活动（聚会、约会）
    - 个人娱乐

  24:00-2:00: 深夜时段 (12分钟现实)
    - 大部分AI睡觉
    - 少数夜猫子活动

  2:00-6:00: 凌晨时段 (自动跳过)
    - 所有AI睡眠
    - 快进到黎明
```

```yaml
一周7天:
  周一(Monday): 工作日 - 新的一周开始
```

## 🎮 时间控制功能

### 玩家可用的时间控制

```yaml
时间控制选项:
  暂停(Pause):
    - 快捷键: Space
    - 游戏时间停止
    - 可以查看数据、UI

  正常速度(×1):
    - 快捷键: 1
    - 10分钟游戏时间 = 60秒现实

  加速(×2):
    - 快捷键: 2
    - 10分钟游戏时间 = 30秒现实

  快速(×5):
    - 快捷键: 3
    - 10分钟游戏时间 = 12秒现实

  极速(×10):
    - 快捷键: 4
    - 10分钟游戏时间 = 6秒现实
    - 用于快速度过无聊时段

  快进到...(Skip to...):
    - 快进到特定时间（如8:00、12:00）
    - 快进到特定事件（如"Alice醒来"）
    - 快进到下一天
```

### 自动时间调整

```yaml
自动减速触发条件:
  - 玩家正在跟随某个AI
  - 重要事件发生（冲突、表白、重要对话）
  - 玩家打开了UI面板

自动暂停触发条件:
  - 玩家打开了复杂菜单
  - 发生了需要玩家注意的事件（可选）
```

## 💻 GDScript实现

### TimeSystem.gd (Autoload单例)

```gdscript
extends Node

# ========================================
# 信号定义
# ========================================

signal time_updated(current_hour: float)
signal hour_changed(new_hour: int)
signal day_changed(new_day: int)
signal week_changed(new_week: int)
signal season_changed(new_season: String)
signal year_changed(new_year: int)

# ========================================
# 常量定义
# ========================================

const REAL_SECONDS_PER_GAME_MINUTE = 6.0  # 1游戏分钟 = 6现实秒（×10倍速基准）
const GAME_MINUTES_PER_UPDATE = 10.0      # 每10游戏分钟为1个时间单位
const GAME_HOURS_PER_DAY = 20.0           # 游戏内一天20小时（6:00-26:00即次日2:00）
const DAYS_PER_WEEK = 7
const DAYS_PER_SEASON = 28
const DAYS_PER_YEAR = 112

const SEASONS = ["Spring", "Summer", "Autumn", "Winter"]
const WEEKDAYS = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]

# ========================================
# 时间状态
# ========================================

var current_year: int = 1
var current_season: String = "Spring"
var current_day: int = 1           # 1-112 (一年中的第几天)
var current_weekday: int = 1       # 1-7 (1=周一)
var current_hour: float = 6.0      # 6.0-26.0 (6:00AM - 次日2:00AM)

var time_speed_multiplier: float = 1.0  # 观察者可调节: 0(暂停), 1, 2, 5, 10
var is_paused: bool = false

var accumulated_time: float = 0.0  # 累积的现实时间（秒）

# ========================================
# 初始化
# ========================================

func _ready():
    print("[TimeSystem] 时间系统初始化")
    print("  - 当前时间: Year %d, %s, Day %d (%s), %02d:00" % [
        current_year, current_season, current_day, get_weekday_name(), int(current_hour)
    ])

func _process(delta: float):
    if is_paused:
        return

    # 累积时间
    accumulated_time += delta * time_speed_multiplier

    # 计算应该前进多少游戏分钟
    var game_minutes_to_advance = accumulated_time / REAL_SECONDS_PER_GAME_MINUTE

    if game_minutes_to_advance >= GAME_MINUTES_PER_UPDATE:
        var updates = int(game_minutes_to_advance / GAME_MINUTES_PER_UPDATE)
        accumulated_time -= updates * GAME_MINUTES_PER_UPDATE * REAL_SECONDS_PER_GAME_MINUTE

        _advance_time(updates * GAME_MINUTES_PER_UPDATE)

# ========================================
# 时间推进核心逻辑
# ========================================

func _advance_time(game_minutes: float):
    """推进游戏时间（以游戏分钟为单位）"""
    var old_hour = int(current_hour)
    var old_day = current_day
    var old_season = current_season
    var old_year = current_year

    # 推进小时
    current_hour += game_minutes / 60.0

    # 检查是否跨天
    if current_hour >= 26.0:  # 26:00 = 次日2:00
        current_hour -= 24.0
        current_day += 1
        current_weekday += 1

        if current_weekday > 7:
            current_weekday = 1

        # 检查是否跨季节
        if current_day > DAYS_PER_SEASON:
            current_day = 1
            _advance_season()

        day_changed.emit(current_day)

        if current_weekday == 1:  # 周一
            week_changed.emit(get_current_week())

    # 检查是否跨小时
    if int(current_hour) != old_hour:
        hour_changed.emit(int(current_hour))

    # 发送时间更新信号
    time_updated.emit(current_hour)

func _advance_season():
    """推进季节"""
    var season_index = SEASONS.find(current_season)
    season_index = (season_index + 1) % 4

    if season_index == 0:  # 回到春季，说明跨年了
        current_year += 1
        year_changed.emit(current_year)

    current_season = SEASONS[season_index]
    season_changed.emit(current_season)

# ========================================
# 时间控制API
# ========================================

func pause():
    """暂停时间"""
    is_paused = true
    print("[TimeSystem] 时间暂停")

func resume():
    """恢复时间"""
    is_paused = false
    print("[TimeSystem] 时间恢复")

func set_time_speed(speed: float):
    """设置时间流速倍率 (0=暂停, 1=正常, 2/5/10=加速)"""
    if speed <= 0:
        pause()
    else:
        time_speed_multiplier = speed
        is_paused = false
        print("[TimeSystem] 时间流速设置为 ×%.1f" % speed)

func fast_forward_to_hour(target_hour: int):
    """快进到指定小时"""
    print("[TimeSystem] 快进到 %02d:00" % target_hour)

    var original_speed = time_speed_multiplier
    time_speed_multiplier = 10.0

    while int(current_hour) != target_hour:
        await get_tree().create_timer(0.1).timeout
        if int(current_hour) == target_hour:
            break

    time_speed_multiplier = original_speed
    print("[TimeSystem] 快进完成")

func skip_to_next_day():
    """跳到下一天的早上6:00"""
    print("[TimeSystem] 跳到下一天")
    current_hour = 6.0
    current_day += 1
    current_weekday += 1

    if current_weekday > 7:
        current_weekday = 1

    if current_day > DAYS_PER_SEASON:
        current_day = 1
        _advance_season()

    day_changed.emit(current_day)

# ========================================
# 查询API
# ========================================

func get_current_hour() -> float:
    """获取当前小时（浮点数，如 14.5 = 14:30）"""
    return current_hour

func get_current_time_string() -> String:
    """获取当前时间字符串 (如 "14:30")"""
    var hour = int(current_hour)
    var minute = int((current_hour - hour) * 60)
    return "%02d:%02d" % [hour, minute]

func get_total_days() -> int:
    """获取总天数（从游戏开始算起）"""
    return (current_year - 1) * DAYS_PER_YEAR + get_day_of_year()

func get_day_of_year() -> int:
    """获取当年的第几天 (1-112)"""
    var season_index = SEASONS.find(current_season)
    return season_index * DAYS_PER_SEASON + current_day

func get_current_week() -> int:
    """获取当前第几周"""
    return int((get_total_days() - 1) / 7) + 1

func get_weekday_name() -> String:
    """获取星期几的名称"""
    return WEEKDAYS[current_weekday - 1]

func is_weekend() -> bool:
    """是否是周末"""
    return current_weekday >= 6  # 6=周六, 7=周日

func is_workday() -> bool:
    """是否是工作日"""
    return current_weekday <= 5

func get_time_period() -> String:
    """获取当前时段（黎明/上午/午间/下午/傍晚/夜间/深夜）"""
    var h = int(current_hour)
    if h >= 6 and h < 8:
        return "dawn"
    elif h >= 8 and h < 12:
        return "morning"
    elif h >= 12 and h < 14:
        return "noon"
    elif h >= 14 and h < 18:
        return "afternoon"
    elif h >= 18 and h < 20:
        return "evening"
    elif h >= 20 and h < 24:
        return "night"
    else:
        return "late_night"

func get_current_time_dict() -> Dictionary:
    """获取当前时间的完整字典（用于记忆系统等）"""
    return {
        "year": current_year,
        "season": current_season,
        "day": current_day,
        "weekday": get_weekday_name(),
        "hour": int(current_hour),
        "minute": int((current_hour - int(current_hour)) * 60),
        "time_string": get_current_time_string()
    }

func get_season_data(season_name: String = "") -> Dictionary:
    """获取季节数据"""
    if season_name == "":
        season_name = current_season

    var season_data = {
        "Spring": {
            "name_cn": "春季",
            "color_tint": Color(1.0, 1.0, 0.9),
            "weather_chances": {"sunny": 0.6, "rainy": 0.3, "cloudy": 0.1},
            "ai_mood_modifier": 10,
            "events": ["Spring Festival", "Flower Dance"],
            "description": "樱花盛开，春意盎然"
        },
        "Summer": {
            "name_cn": "夏季",
            "color_tint": Color(1.0, 0.95, 0.8),
            "weather_chances": {"sunny": 0.8, "rainy": 0.1, "cloudy": 0.1},
            "ai_mood_modifier": 5,
            "events": ["Beach Party", "Summer Festival"],
            "description": "阳光明媚，热情似火"
        },
        "Autumn": {
            "name_cn": "秋季",
            "color_tint": Color(1.0, 0.9, 0.7),
            "weather_chances": {"sunny": 0.7, "rainy": 0.1, "cloudy": 0.2},
            "ai_mood_modifier": 8,
            "events": ["Harvest Festival", "Halloween"],
            "description": "金秋时节，凉爽宜人"
        },
        "Winter": {
            "name_cn": "冬季",
            "color_tint": Color(0.9, 0.95, 1.0),
            "weather_chances": {"sunny": 0.3, "snowy": 0.5, "cloudy": 0.2},
            "ai_mood_modifier": -5,
            "events": ["Winter Festival", "New Year"],
            "description": "白雪皑皑，银装素裹"
        }
    }

    return season_data.get(season_name, {})

# ========================================
# 调试工具
# ========================================

func get_debug_info() -> String:
    """获取调试信息"""
    return """
[时间系统]
年份: %d
季节: %s (%s)
日期: Day %d / %d
星期: %s
时间: %s
时段: %s
流速: ×%.1f
暂停: %s
总天数: %d
    """ % [
        current_year,
        current_season,
        get_season_data().get("name_cn", ""),
        current_day,
        DAYS_PER_SEASON,
        get_weekday_name(),
        get_current_time_string(),
        get_time_period(),
        time_speed_multiplier,
        "是" if is_paused else "否",
        get_total_days()
    ]
```

## ✅ 验收标准

1. **时间流速准确**
   - 1游戏日 = 2小时现实时间
   - 10分钟游戏时间 = 60秒现实时间

2. **时间控制响应**
   - 暂停立即生效
   - 加速流畅无卡顿
   - 快进准确到达目标时间

3. **周/季节/年转换正确**
   - 周一6:00发工资
   - 季节28天准确切换
   - 年份正确递增

4. **AI行为符合时间**
   - 工作日8:00-18:00 AI在工作
   - 周末AI有不同活动
   - 季节影响AI心情

## 🔧 性能优化

```yaml
优化策略:
  1. 信号驱动:
     - 使用信号而非轮询检查时间变化
     - 各系统订阅需要的信号

  2. 批量更新:
     - AI不是每帧更新，而是每30游戏分钟
     - 减少LLM API调用频率

  3. 休眠优化:
     - 凌晨2:00-6:00自动快进（所有AI睡觉）
     - 玩家可选择是否启用

  4. 异步处理:
     - 时间推进和AI更新异步
     - 避免阻塞主线程
```
