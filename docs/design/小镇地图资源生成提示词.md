# 小镇地图资源生成提示词

本文档提供详细的AI绘图提示词，用于生成 Microverse 项目所需的小镇地图素材。

## 项目规格说明

### 基础参数
- **视角风格**: 2.5D 俯视角（Top-Down 45度）
- **画风**: Stardew Valley 像素风格
- **单位尺寸**: 16x16 像素/格
- **地图尺寸**: 150x120 格（2400x1920 像素）
- **色调**: 温暖、明亮、饱和度适中
- **主题**: 现代小镇 + 自然景观

## 十、AI 绘图工具推荐配置

### 10.1 Stable Diffusion 推荐设置
- **模型**: Pixel Art Diffusion XL 或 Anything V5
- **采样器**: Euler a 或 DPM++ 2M Karras
- **采样步数**: 20-30
- **CFG Scale**: 7-9
- **分辨率**: 根据需要尺寸设置（如512x512生成后缩放）
- **负面提示词**:
  ```
  blurry, low quality, realistic, 3D render, photograph,
  watermark, signature, text, messy, noisy, jpeg artifacts,
  wrong perspective, inconsistent style
  ```

### 10.2 MidJourney 参数建议
- 添加参数：`--style raw --v 6 --ar 1:1`
- 像素风格触发词：`pixel art, 16-bit style, retro game, Stardew Valley`
- 精度控制：使用 `--tile` 生成可平铺素材

### 10.3 后期处理建议
1. **缩放处理**: 使用 Nearest Neighbor 算法（保持像素锐利）
2. **去噪**: 轻度降噪，保留像素边缘
3. **色彩统一**: 确保同类素材色调一致
4. **透明背景**: 使用 Remove.bg 或 Photoshop 魔棒工具
5. **拼接检查**: Tileset 需检查边缘无缝衔接
