## 🎯 教程设计哲学

### 核心原则

```yaml
Microverse新手教程五大原则:

1. 观察优先,不打断:
   - 教程不暂停游戏
   - AI继续自主生活
   - 玩家在观察中学习

2. 渐进式揭示:
   - 从简单到复杂
   - 不一次性灌输所有信息
   - 跟随玩家好奇心展开

3. 情境化教学:
   - 在AI产生行为时解释
   - 在事件发生时引导
   - 让教学成为故事的一部分

4. 可跳过,可重温:
   - 老玩家可完全跳过
   - 任何提示可永久关闭
   - 帮助菜单可随时查阅

5. "Show, Don't Tell":
   - 通过高亮、箭头、动画引导
   - 减少文字说明
   - 让玩家"发现"而非"被告知"
```

### 不是什么

- ❌ **传统RPG的强制教程** - 不锁定玩家操作
- ❌ **大段文字墙** - 不用长篇幅解释
- ❌ **手把手教学** - 不强制玩家做特定操作
- ❌ **填鸭式信息灌输** - 不一次性展示所有UI

### 是什么

- ✅ **引导式探索** - 给线索,让玩家自己发现
- ✅ **实时情境提示** - 在需要时才出现
- ✅ **渐进式揭示** - UI元素逐步解锁
- ✅ **故事化引导** - 跟随AI的故事学习游戏

## 📈 学习曲线设计

### 三阶段学习路径

```
第一阶段: 基础观察 (前5分钟)
    ↓
学会: 观察AI、理解时间流逝、切换镜头
    ↓
第二阶段: 深入理解 (5-15分钟)
    ↓
学会: 查看AI状态、理解关系、观察对话
    ↓
第三阶段: 完整掌握 (15-30分钟)
    ↓
学会: 事件系统、记忆系统、长期观察
    ↓
自由探索 (30分钟后)
```

### 知识点分层

```yaml
Layer 1 - 必须知道 (前5分钟):
  - 游戏是观察AI生活的模拟器
  - 时间会自动流逝
  - 可以点击AI查看详情
  - 可以暂停/加速时间
  - AI会自主行动

Layer 2 - 应该知道 (5-15分钟):
  - AI有性格、情绪、关系
  - AI之间会对话和互动
  - AI有工作、日程、任务
  - 事件会自动发生并通知
  - 可以查看AI的想法

Layer 3 - 可以知道 (15-30分钟):
  - AI有记忆系统
  - 关系会动态变化
  - 可能发生冲突
  - 可能产生恋情
  - 天气影响AI行为
  - 可以保存和读取游戏

Layer 4 - 高级技巧 (30分钟后):
  - 观察剧情链发展
  - 追踪特定关系
  - 理解AI的LLM思考
  - 使用高级筛选
  - 关系图谱分析
```

## 🎯 渐进式UI引导

### UI元素逐步解锁策略

```gdscript
# script/tutorial/UIUnlockManager.gd
class_name UIUnlockManager extends Node

# UI解锁阶段
enum UnlockStage {
	STAGE_0_MINIMAL,      # 最小UI - 只有时间和游戏视野
	STAGE_1_BASIC,        # 基础UI - 添加角色列表
	STAGE_2_OBSERVATION,  # 观察UI - 添加观察面板基础信息
	STAGE_3_ADVANCED,     # 高级UI - 添加关系、记忆标签页
	STAGE_4_FULL          # 完整UI - 所有功能开放
}

var current_stage: UnlockStage = UnlockStage.STAGE_0_MINIMAL
var tutorial_manager: TutorialManager

# UI元素引用
var ui_elements = {
	"character_list": null,
	"observation_panel": null,
	"stats_tab": null,
	"relationship_tab": null,
	"memory_tab": null,
	"thought_display": null,
	"notification_bar": null,
	"speed_control": null,
	"event_log": null
}

func _ready():
	tutorial_manager = get_node("/root/TutorialManager")
	_collect_ui_references()
	_apply_stage(current_stage)

# 收集UI引用
func _collect_ui_references():
	ui_elements["character_list"] = get_node("/root/Main/UILayer/CharacterListPanel")
	ui_elements["observation_panel"] = get_node("/root/Main/UILayer/ObservationPanel")
	# ... 其他UI元素

# 应用UI阶段
func _apply_stage(stage: UnlockStage):
	current_stage = stage

	# 重置所有UI为隐藏
	for element in ui_elements.values():
		if element:
			element.visible = false

	# 根据阶段显示UI
	match stage:
		UnlockStage.STAGE_0_MINIMAL:
			_unlock_minimal_ui()
		UnlockStage.STAGE_1_BASIC:
			_unlock_basic_ui()
		UnlockStage.STAGE_2_OBSERVATION:
			_unlock_observation_ui()
		UnlockStage.STAGE_3_ADVANCED:
			_unlock_advanced_ui()
		UnlockStage.STAGE_4_FULL:
			_unlock_full_ui()

# 最小UI (游戏启动)
func _unlock_minimal_ui():
	# 只显示时间
	var time_display = get_node("/root/Main/UILayer/HUD/TimeDisplay")
	if time_display:
		time_display.visible = true

# 基础UI (教程步骤3)
func _unlock_basic_ui():
	_unlock_minimal_ui()

	# 显示角色列表
	if ui_elements["character_list"]:
		ui_elements["character_list"].visible = true
		_animate_slide_in(ui_elements["character_list"], "left")

	# 显示速度控制
	if ui_elements["speed_control"]:
		ui_elements["speed_control"].visible = true

# 观察UI (教程步骤4)
func _unlock_observation_ui():
	_unlock_basic_ui()

	# 显示观察面板
	if ui_elements["observation_panel"]:
		ui_elements["observation_panel"].visible = true
		_animate_slide_in(ui_elements["observation_panel"], "right")

	# 只显示基本信息和状态页
	if ui_elements["stats_tab"]:
		ui_elements["stats_tab"].visible = true

# 高级UI (教程步骤8+)
func _unlock_advanced_ui():
	_unlock_observation_ui()

	# 解锁关系页
	if ui_elements["relationship_tab"]:
		ui_elements["relationship_tab"].visible = true
		_highlight_new_feature(ui_elements["relationship_tab"])

	# 解锁记忆页
	if ui_elements["memory_tab"]:
		ui_elements["memory_tab"].visible = true
		_highlight_new_feature(ui_elements["memory_tab"])

	# 显示事件日志
	if ui_elements["event_log"]:
		ui_elements["event_log"].visible = true

# 完整UI (教程完成)
func _unlock_full_ui():
	# 显示所有UI
	for element in ui_elements.values():
		if element:
			element.visible = true

# 滑入动画
func _animate_slide_in(element: Control, direction: String):
	var start_pos = element.position
	var offset = Vector2.ZERO

	match direction:
		"left":
			offset = Vector2(-200, 0)
		"right":
			offset = Vector2(200, 0)

	element.position = start_pos + offset

	var tween = create_tween()
	tween.tween_property(element, "position", start_pos, 0.5).set_ease(Tween.EASE_OUT)

# 高亮新功能
func _highlight_new_feature(element: Control):
	# 金色闪烁效果
	var original_modulate = element.modulate

	var tween = create_tween()
	tween.set_loops(3)
	tween.tween_property(element, "modulate", Color(1.5, 1.5, 0.5), 0.3)
	tween.tween_property(element, "modulate", original_modulate, 0.3)
```

## 📚 关键概念教学

### 概念1: "观察者"身份

```yaml
教学时机: 游戏启动欢迎界面

教学方法:
  视觉: 淡入文字 + 温和动画
  文案:
    "欢迎来到 Microverse

     在这个世界里,你是一位 观察者

     你不能控制AI的行为
     你不能改变他们的决定
     你只能观察和见证

     这是一个关于观察的游戏"

强化:
  - 在玩家尝试"命令"AI时提示
  - 在帮助文档中重复强调
  - UI设计上没有"命令"按钮

类比:
  "就像看一部真人秀
   或者观察一个蚂蚁农场
   你是旁观者,不是导演"
```

### 概念2: AI的自主性

```yaml
教学时机: 第一次看到AI自主移动 (步骤6)

教学方法:
  情境: Tom主动去泡咖啡
  提示:
    "Tom感到疲惫,所以决定去泡咖啡

     这不是脚本,而是他的真实决策
     基于他的:
     - 当前精力值 (低)
     - 性格偏好 (喜欢咖啡)
     - AI思考 (需要提神)"

演示:
  - 高亮Tom的精力条 (红色低值)
  - 显示Tom的想法气泡
  - 展示行动路径

强化点:
  - 每次AI做重要决策时,解释原因
  - 在观察面板显示"决策因素"
```

### 概念3: 时间流逝与加速

```yaml
教学时机: 步骤5

教学方法:
  互动教学:
    第1步: "时间正在流逝,现在是 09:05"
    第2步: "AI们按照自己的日程生活"
    第3步: "你可以控制时间速度"
    第4步: [高亮速度按钮] "试试加速到 2x"
    第5步: [玩家操作后] "很好!时间流动得更快了"

注意事项:
  - 暂停状态: "暂停后AI会停止思考,但你可以慢慢查看"
  - 3x速度: "最快速度,适合等待特定时刻"
  - 推荐: "推荐使用 1x 或 2x 观察日常"

实用场景:
  - 等待下班时间 → 3x
  - 观察对话细节 → 暂停或1x
  - 日常观察 → 2x
```

### 概念4: 关系动态

```yaml
教学时机: 步骤8 + 第一次关系变化事件

初次教学:
  展示: Alice和Lea的关系卡片
  说明:
    "好感度: 75/100 - 代表Alice对Lea的喜欢程度
     信任度: 60/100 - 代表Alice对Lea的信任

     这些数值会随着互动而变化"

深入教学 (触发式):
  当第一次好感度上升:
    通知: "Alice 和 Lea 的好感度提升了!"
    解释: "愉快的对话让她们更亲近了
           好感度 75 → 80"

  当第一次好感度下降:
    通知: "Alice 和 Bob 的好感度下降了!"
    解释: "Bob的批评让Alice不高兴
           好感度 45 → 35"

关系里程碑:
  50分: 从陌生人变成认识的人
  70分: 成为朋友
  85分: 成为挚友
  浪漫度>70 + 好感度>75: 可能表白
```

### 概念5: 事件系统

```yaml
教学时机: 第一次重要事件 (步骤9)

分层教学:

Layer 1 - 事件通知:
  第一次事件弹出时:
    "这是一个重要事件
     当AI生活中发生关键时刻时
     系统会这样通知你"

  通知分级:
    - 小事: 右上角小气泡
    - 一般事: 右侧面板
    - 重要事: 中央卡片
    - 史诗事: 全屏

Layer 2 - 事件影响:
  展示事件影响:
    "这个事件影响了:
     - Alice的心情 (+20)
     - Alice的记忆 (新增重要记忆)
     - Alice对Stephen的好感度 (+5)"

Layer 3 - 事件历史:
  引导点击底部事件日志:
    "所有事件都会记录在这里
     你可以随时回顾"
```

	# 自动消失
	if config.get("auto_dismiss", false):
		var delay = config.get("dismiss_delay", 5.0)
		await get_tree().create_timer(delay).timeout
		if is_inside_tree():
			_dismiss()

func _animate_in():
	modulate.a = 0.0
	scale = Vector2(0.8, 0.8)

	var tween = create_tween()
	tween.set_parallel(true)
	tween.tween_property(self, "modulate:a", 1.0, 0.3)
	tween.tween_property(self, "scale", Vector2(1.0, 1.0), 0.3).set_ease(Tween.EASE_OUT)

	_dismiss()

### TutorialManager核心类

```gdscript
# script/tutorial/TutorialManager.gd
extends Node

# 教程状态
enum TutorialState {
	NOT_STARTED,          # 未开始
	IN_PROGRESS,          # 进行中
	COMPLETED,            # 已完成
	SKIPPED               # 已跳过
}

# 教程步骤
enum TutorialStep {
	WELCOME = 0,
	INITIAL_SCENE = 1,
	CLICK_AI = 2,
	OBSERVATION_PANEL = 3,
	TIME_CONTROL = 4,
	AI_MOVEMENT = 5,
	FIRST_DIALOGUE = 6,
	RELATIONSHIP_SYSTEM = 7,
	FIRST_EVENT = 8,
	MEMORY_SYSTEM = 9,
	FREE_EXPLORATION = 10
}

# 当前状态
var current_state: TutorialState = TutorialState.NOT_STARTED
var current_step: TutorialStep = TutorialStep.WELCOME

# 组件引用
var ui_unlock_manager: UIUnlockManager
var contextual_tip_manager: ContextualTipManager

# 教程配置
var tutorial_enabled: bool = true
var show_contextual_tips: bool = true

func _ready():
	_load_tutorial_settings()

	if tutorial_enabled and _is_first_launch():
		start_tutorial()

# 开始教程
func start_tutorial():
	current_state = TutorialState.IN_PROGRESS
	current_step = TutorialStep.WELCOME

	EventBus.emit_signal("tutorial_started")

	# 显示欢迎界面
	_show_welcome_screen()

# 推进到下一步
func advance_to_step(step: TutorialStep):
	current_step = step
	EventBus.emit_signal("tutorial_step_changed", step)

	# 执行步骤逻辑
	_execute_step(step)

	# 保存进度
	_save_progress()

# 执行教程步骤
func _execute_step(step: TutorialStep):
	match step:
		TutorialStep.WELCOME:
			_show_welcome_screen()

		TutorialStep.INITIAL_SCENE:
			_show_initial_scene()

		TutorialStep.CLICK_AI:
			_guide_click_ai()

		TutorialStep.OBSERVATION_PANEL:
			_introduce_observation_panel()
			ui_unlock_manager._apply_stage(UIUnlockManager.UnlockStage.STAGE_2_OBSERVATION)

		TutorialStep.TIME_CONTROL:
			_introduce_time_control()

		TutorialStep.AI_MOVEMENT:
			_wait_for_ai_movement()

		TutorialStep.FIRST_DIALOGUE:
			_wait_for_first_dialogue()

		TutorialStep.RELATIONSHIP_SYSTEM:
			_introduce_relationships()
			ui_unlock_manager._apply_stage(UIUnlockManager.UnlockStage.STAGE_3_ADVANCED)

		TutorialStep.FIRST_EVENT:
			_trigger_first_event()

		TutorialStep.MEMORY_SYSTEM:
			_introduce_memory_system()

		TutorialStep.FREE_EXPLORATION:
			_complete_tutorial()

# 完成教程
func _complete_tutorial():
	current_state = TutorialState.COMPLETED

	# 解锁所有UI
	ui_unlock_manager._apply_stage(UIUnlockManager.UnlockStage.STAGE_4_FULL)

	# 显示完成提示
	_show_completion_message()

	# 启用情境提示系统
	show_contextual_tips = true

	EventBus.emit_signal("tutorial_completed")

	_save_progress()

# 跳过教程
func skip_tutorial():
	current_state = TutorialState.SKIPPED

	# 立即解锁所有UI
	ui_unlock_manager._apply_stage(UIUnlockManager.UnlockStage.STAGE_4_FULL)

	# 禁用基础教程,但保留情境提示
	tutorial_enabled = false
	show_contextual_tips = true

	_save_progress()

# 检查是否首次启动
func _is_first_launch() -> bool:
	return not FileAccess.file_exists("user://tutorial_progress.dat")

# 保存进度
func _save_progress():
	var progress = {
		"state": current_state,
		"step": current_step,
		"tutorial_enabled": tutorial_enabled,
		"show_contextual_tips": show_contextual_tips
	}

	var file = FileAccess.open("user://tutorial_progress.dat", FileAccess.WRITE)
	if file:
		file.store_var(progress)
		file.close()

# 加载进度
func _load_tutorial_settings():
	if FileAccess.file_exists("user://tutorial_progress.dat"):
		var file = FileAccess.open("user://tutorial_progress.dat", FileAccess.READ)
		if file:
			var progress = file.get_var()
			current_state = progress.get("state", TutorialState.NOT_STARTED)
			current_step = progress.get("step", TutorialStep.WELCOME)
			tutorial_enabled = progress.get("tutorial_enabled", true)
			show_contextual_tips = progress.get("show_contextual_tips", true)
			file.close()
```

## 🎯 总结

新手教程的核心是**渐进式引导**,让玩家在观察AI生活的过程中自然学习游戏机制。

### 设计亮点

1. **非侵入式** - 教程不暂停游戏,不强制操作
2. **情境化** - 在AI行为发生时解释,而非提前灌输
3. **分层递进** - 从必须知道到可以知道,逐层揭示
4. **可跳过可关闭** - 尊重玩家选择
5. **持续引导** - 基础教程后,情境提示继续帮助

### 关键成功因素

- **前5分钟至关重要** - 必须让玩家理解"观察者"身份
- **前15分钟建立兴趣** - 通过有趣的AI行为吸引玩家
- **30分钟形成习惯** - 玩家掌握观察节奏,产生继续欲望

**文档字数**: ~10,000字
**实现优先级**: P2 (可在核心系统完成后添加)
**开发时间估计**: 3-5天
