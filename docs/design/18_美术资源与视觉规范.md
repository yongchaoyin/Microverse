### 1.3 像素艺术规范

#### 1.3.1 像素风格标准

```
【Pixel Art基础规则】

1. 分辨率规范:
   - Tile尺寸: 16×16像素 (基础单位)
   - 角色尺寸: 16×32像素 (1×2 tiles)
   - UI图标: 16×16, 32×32, 64×64
   - 大型建筑: 多tile组合

2. 抗锯齿规则:
   ❌ 不使用Photoshop/GIMP的自动抗锯齿
   ✅ 手工抗锯齿(仅在曲线处)
   ✅ 使用1-2个中间色平滑过渡

   示例:
   ❌ 错误: [黑][灰1][灰2][灰3][白] (过度平滑)
   ✅ 正确: [黑][深灰][白] (清晰像素感)

3. 线条规则:
   - 外轮廓: 1-2像素宽
   - 内部线条: 1像素
   - 避免孤立像素点
   - 保持线条连续性

4. 阴影与高光:
   - 阴影: 主色-20%亮度
   - 高光: 主色+20%亮度
   - 光源方向统一: 左上方45度
   - 阴影柔和,避免纯黑

5. 透视规则:
   - 俯视角度: 轻微透视
   - 垂直物体: 正面+顶部可见
   - 地面物体: 完全俯视
```

#### 1.3.2 动画规范

```
【动画帧数标准】

最小动画 (2帧):
- 待机呼吸
- 水面波动(简化)
- 灯光闪烁

标准动画 (3-4帧):
- 角色走路: 4帧/方向
- 树叶摇摆: 3帧
- 水面波光: 4帧
- 火焰燃烧: 4帧

复杂动画 (6-8帧):
- 角色特殊动作: 6帧
- 机械运转: 8帧
- 复杂特效: 6-8帧

【动画时间规范】
- 慢速循环: 0.5秒/帧 (树叶、呼吸)
- 标准循环: 0.3秒/帧 (水面)
- 快速循环: 0.15秒/帧 (走路)
- 特效: 0.1秒/帧 (火花、闪光)

【动画制作原则】
1. 保持像素对齐(整数位置)
2. 循环动画首尾帧平滑过渡
3. 避免突然跳跃
4. 使用ease-in-out缓动感
```

### 4.2 Aseprite工作流

```

   - 宽度: 16 (或对应尺寸)
   - 高度: 16 (或对应尺寸)
   - 颜色模式: RGBA
   - 背景: 透明

2. 网格设置:
   - 网格大小: 1×1像素 (精确绘制)
   - 显示网格: 开启

3. 调色板设置:
   - 导入项目色板 (microverse_palette.pal)
   - 锁定色板(避免意外添加颜色)

【绘制流程】

1. 绘制轮廓:
   - 使用Pencil工具 (B键)
   - 1-2像素宽轮廓
   - 深色轮廓色

2. 填充主色:
   - 使用Paint Bucket (G键)
   - 填充基础色

3. 添加阴影:
   - 选择阴影色(主色-20%亮度)
   - 手工绘制阴影区域
   - 光源方向: 左上45度

4. 添加高光:
   - 选择高光色(主色+20%亮度)
   - 绘制受光区域

5. 细节打磨:
   - 添加纹理细节
   - 修正像素对齐
   - 检查整体协调

【动画流程】

1. 创建帧:
   - New Frame (Alt+N)
   - 复制当前帧内容

2. 开启Onion Skin:
   - 查看前后帧
   - 调整动画连贯性

3. 调整时间轴:
   - 设置每帧持续时间(ms)
   - 播放预览(Enter)

4. 导出Sprite Sheet:
   - File > Export Sprite Sheet
   - 布局: 按行/列排列
   - 输出: PNG, 透明背景

【批量处理】

## 7. 导出与集成规范

### 7.1 导出设置

```
【Aseprite导出Sprite Sheet】

1. File > Export Sprite Sheet
2. Layout:
   - 类型: By Rows (按行排列)
   - 行数: 根据需要
   - Padding: 0 (无间距)
3. Sprite:
   - Trim Cels: 关闭
   - Merge Duplicates: 关闭
4. Borders:
   - Border Padding: 0
   - Shape Padding: 0
   - Inner Padding: 0
5. Output:
   - 文件类型: PNG
   - 颜色模式: RGBA
   - Resize: 100% (无缩放)
6. JSON数据:
   - 同时导出JSON (用于Godot SpriteFrames)
```

### 7.2 Godot导入配置

```
【导入Sprite Sheet到Godot】

1. 复制PNG到res://assets/characters/
2. 在Godot中选中文件
3. Import设置:
   - Compress: Lossless
   - Filter: Off (保持像素锐利)
   - Mipmaps: Off
   - Anisotropic: Off

4. 创建SpriteFrames资源:
   - 新建AnimatedSprite2D
   - 创建SpriteFrames
   - 从Sprite Sheet导入帧
   - 设置动画:
     * idle_down (2帧, 0.5秒/帧, 循环)
     * walk_down (4帧, 0.15秒/帧, 循环)
     * ... (其他方向和动作)

【导入Tileset到Godot】

1. 复制PNG到res://assets/tilesets/
2. 创建TileSet资源(.tres)
3. Atlas Source:
   - Texture: 选择PNG
   - Tile Size: 16×16
4. 配置Auto-tile:
   - Physics Layers: 0 (碰撞层)
   - Terrain Sets: 设置地形类型
   - Bitmask: 配置Auto-tile规则
5. 绘制碰撞形状 (需要的Tile)
6. 保存TileSet资源
```

【统一命名格式】
