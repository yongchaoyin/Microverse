# 经济系统详细规范 (Economy System)

## 📋 系统概述

经济系统是Microverse的**生存压力与目标动机引擎**。每个AI需要通过工作赚取金币，并管理日常开支。经济压力创造真实的生活感和戏剧性事件（财务危机、借贷、奢侈消费等）。

**设计原则**:
- 经济要**有压力但不窒息**（AI能生存但需要规划）
- 收入要**与职业相符**（不同职业有合理的薪资差异）
- 支出要**有意义**（每笔钱都有具体用途）
- 财务状况要**影响行为**（缺钱时减少社交，有钱时更大方）

## 💰 工资系统

### 核心参数

```yaml
工资系统:
  发放周期: 每周一早上6:00
  工作制: 周一至周五 (5天工作日)
  病假: 无薪 (重要!)
  迟到: 不扣工资（但影响绩效评分）
```

### 工资发放触发机制 ⚙️

**设计原则**: 信号驱动架构,EconomyManager被动响应TimeSystem的时间变化

```yaml
触发流程:
  1. TimeSystem每小时触发 hour_changed(hour, day_of_week) 信号
  2. EconomyManager监听该信号
  3. 检测到周一(day_of_week==1) 且 hour==6 时执行发放
  4. 遍历所有AI角色,计算并发放工资
  5. 广播 salary_paid 事件到EventBus
  6. 创建工资收入记忆到MemoryManager

系统集成:
  TimeSystem → (hour_changed) → EconomyManager
  EconomyManager → (salary_paid) → EventBus → UI
  EconomyManager → (add_memory) → MemoryManager
  EconomyManager → (get_performance) → TaskSystem

异常处理:
  - AI没有职业: 跳过发放,记录日志
  - 工资配置缺失: 触发 salary_payment_failed 信号
  - AI节点不存在: 跳过并记录警告
```

### 绩效奖金系统 🎯

**设计原则**: 多维度评估,数据驱动,与TaskSystem集成

```yaml
绩效评分因素:
  完成率 (40%权重):
    - 来源: TaskSystem.get_weekly_performance(ai_id)
    - 计算: 已完成任务数 / 总任务数
    - 示例: 完成5/10任务 → 得分0.5 × 40 = 20分

  工作质量 (30%权重):
    - 来源: TaskSystem提供的LLM质量评分
    - 计算: 平均质量分 (0.0-1.0) × 30
    - LLM评分标准:
      * 1.0 - 完美完成,超出预期
      * 0.8 - 优秀完成,符合预期
      * 0.6 - 合格完成,有小瑕疵
      * 0.4 - 勉强完成,有明显问题
      * 0.2 - 质量很差
    - 示例: 平均质量0.8 → 得分0.8 × 30 = 24分

  准时性 (20%权重):
    - 来源: TaskSystem记录的准时完成率
    - 计算: 准时任务数 / 总任务数 × 20
    - 示例: 8/10任务准时 → 得分0.8 × 20 = 16分

  考勤 (10%权重):
    - 来源: TaskSystem记录的迟到早退次数
    - 计算: 基础10分 - 迟到次数×0.5 - 早退次数×0.8
    - 示例: 迟到2次,早退1次 → 得分10 - 1 - 0.8 = 8.2分

总分计算:
  基础分数 = 完成率×0.4 + 质量×0.3 + 准时×0.2 + 考勤×0.1
  基础分数范围: 0.0 - 1.0

  绩效系数映射:
  系数 = 0.5 + 基础分数 × 1.5
  系数范围: 0.5 - 2.0

  加班奖励:
  每小时加班 +0.05系数 (最多+0.2)

  最终工资:
  工资 = 基础工资 × 绩效系数

绩效等级:
  S级 (系数≥1.8): 优秀
  A级 (系数≥1.5): 良好
  B级 (系数≥1.0): 合格
  C级 (系数≥0.7): 待改进
  D级 (系数<0.7):  不合格

完整示例:
  Bob（责任心90, 本周完成8/10任务, 平均质量0.85, 准时率90%, 无迟到早退, 加班3小时）:
    完成率: 0.8 × 0.4 = 0.32
    质量:   0.85 × 0.3 = 0.255
    准时:   0.9 × 0.2 = 0.18
    考勤:   1.0 × 0.1 = 0.1
    基础分数: 0.855
    基础系数: 0.5 + 0.855 × 1.5 = 1.7825
    加班奖励: 3 × 0.05 = 0.15
    最终系数: 1.7825 + 0.15 = 1.9325 (限制为2.0) → 1.93
    等级: S级 (优秀)
    周薪: 800G × 1.93 = 1,544G

系统集成:
  TaskSystem → 提供绩效数据 (完成率、质量、准时率、加班时长)
  EconomyManager → 计算绩效系数和奖金
  MemoryManager → 记录绩效报告到AI记忆
```

**数据来源接口**:

## 💸 支出系统

### 日常开支结算机制 💳

**设计原则**: 每天23:00结算当日开支,LLM驱动消费习惯,支持负债机制

```yaml
结算时机:
  触发时间: 每天23:00 (EXPENSE_SETTLEMENT_HOUR = 23)
  触发方式: TimeSystem.hour_changed 信号
  结算对象: 所有AI角色

结算流程:
  1. TimeSystem触发 hour_changed(23, day_of_week)
  2. EconomyManager._on_hour_changed() 检测到23:00
  3. 调用 _settle_daily_expenses(day_of_week)
  4. 遍历所有AI,计算当日实际开支
  5. 扣除金钱,检查是否负债
  6. 创建开支记忆,广播经济事件
  7. 负债AI触发财务危机处理

开支计算公式:
  基础开支 = 工作日70G 或 周末150G
  个性化倍数 = _get_expense_multiplier(ai)
  实际开支 = 基础开支 × 个性化倍数

  个性化倍数影响因素:
    1. 外向性: E>70 → ×1.25, E<30 → ×0.75
    2. 心情: mood>70 → ×1.3, mood<30 → ×0.8
    3. 财务状况: money<100 → ×0.6 (节俭)
    4. AI主动设置的消费偏好 (frugal/normal/lavish)

消费偏好系统:
  AI每周一早上通过LLM重新评估消费习惯
  可选偏好:
    - frugal (节俭): 基础开支 × 0.6
    - normal (正常): 基础开支 × 1.0
    - lavish (挥霍): 基础开支 × 1.5

  LLM决策因素:
    - 当前余额
    - 债务总额
    - 外向性和责任心
    - 最近记忆(是否有财务压力)

负债处理:
  允许负债: true
  负债后果:
    - 信用评分下降: 每次负债 -5分
    - 记录到记忆: importance=HIGH, valence=-0.5
    - 触发财务危机事件
    - 可能向朋友借款

示例:
  Alice (E=85, C=45, money=2000G, mood=75, 周六):
    基础开支: 150G
    外向性修正: ×1.175 (E=85)
    心情修正: ×1.15 (mood=75)
    财务修正: ×1.0 (money>1000)
    消费偏好: normal (×1.0)
    实际开支: 150 × 1.175 × 1.15 × 1.0 = 203G
    新余额: 2000 - 203 = 1797G ✅

  Henry (E=30, C=15, money=50G, mood=30, 周六):
    基础开支: 150G
    外向性修正: ×0.9 (E=30)
    心情修正: ×0.8 (mood=30)
    财务修正: ×0.6 (money<100, 自动节俭)
    消费偏好: frugal (×0.6, LLM因缺钱选择节俭)
    实际开支: 150 × 0.9 × 0.8 × 0.6 × 0.6 = 39G
    新余额: 50 - 39 = 11G ⚠️ (接近负债)

系统集成:
  TimeSystem → (hour_changed) → EconomyManager
  EconomyManager → (economy_transaction) → EventBus
  EconomyManager → (add_memory) → MemoryManager
  EconomyManager → (economy_debt_incurred) → UI/MemoryManager
  AIAgent → (LLM决策) → EconomyManager.set_expense_preference()
```

## 💳 消费决策系统

### 消费概率模型

```gdscript
func calculate_purchase_probability(ai: Node, item_price: int, item_type: String) -> float:
    """计算购买概率"""

    # 基础概率
    var base_prob = 0.5

    # 因素1: 财务状况
    var savings_ratio = ai.money / (ai.monthly_income * 1.0)
    var financial_modifier = 1.0

    if savings_ratio < 0.5:  # 存款不足半个月收入
        financial_modifier = 0.3
    elif savings_ratio < 1.0:  # 不足1个月
        financial_modifier = 0.6
    elif savings_ratio > 3.0:  # 超过3个月
        financial_modifier = 1.5

    # 因素2: 性格 - 尽责性（储蓄倾向）
    var C = ai.personality.conscientiousness
    var personality_modifier = 2.0 - (C / 50.0)  # C=100时0倍，C=0时2倍

    # 因素3: 性格 - 开放性（尝试新事物）
    var O = ai.personality.openness
    if item_type == "luxury" or item_type == "new_experience":
        personality_modifier *= (O / 50.0)

    # 因素4: 物品价格占收入比
    var price_ratio = item_price / (ai.monthly_income / 4.0)  # 占周薪的比例
    var price_penalty = 1.0 / (1.0 + price_ratio)  # 越贵越不敢买

    # 因素5: 心情
    var mood_modifier = 1.0
    if ai.current_mood > 70:
        mood_modifier = 1.3  # 心情好更容易消费
    elif ai.current_mood < 30:
        mood_modifier = 0.7  # 心情差不想买

    var final_prob = base_prob * financial_modifier * personality_modifier * price_penalty * mood_modifier

    return clamp(final_prob, 0.0, 1.0)
```

## 📊 储蓄系统

### 储蓄率计算

```yaml
储蓄率公式:
  储蓄率 = 基础储蓄率 × 性格修正 × 压力修正

  基础储蓄率:
    根据职业和生活方式: 10-30%

  性格修正:
    尽责性 (C值):
      C=100: 储蓄率×2.0
      C=50:  储蓄率×1.0
      C=0:   储蓄率×0.0

  压力修正:
    压力>60: 储蓄率×0.8（压力大时安慰性消费）
    压力<30: 储蓄率×1.2（放松时理性）

示例:
  Bob（C=90，压力50）:
    基础储蓄率: 20%
    性格修正: 1.8 (90/50)
    压力修正: 1.0
    实际储蓄率: 20% × 1.8 × 1.0 = 36%
    月收入3200G，月支出2048G，月储蓄1152G

  Henry（C=15，压力20）:
    基础储蓄率: 15%
    性格修正: 0.3 (15/50)
    压力修正: 1.2
    实际储蓄率: 15% × 0.3 × 1.2 = 5.4%
    月收入2800G，月支出2649G，月储蓄151G
```

## 💸 借贷系统

### 借贷规则 🤝

**设计原则**: 与RelationshipManager集成,信任度阈值统一管理

```yaml
借钱资格检查:
  ⚠️ 信任度阈值由 RelationshipManager 统一定义
  📖 详见: 10_AI关系系统详细规范.md - 信任度阈值

  RelationshipManager.can_request_loan(requester_id, lender_id):
    返回: {
      "eligible": bool,
      "reason": String,
      "trust_level": float,
      "required_trust": 60  # TRUST_THRESHOLDS.can_loan
    }

  贷款额度计算:
    基础额度: 500G
    信任度倍数: RelationshipManager.calculate_loan_multiplier(trust)
      trust 60  → 倍数 1.0 → 最多借 500G
      trust 80  → 倍数 2.0 → 最多借 1000G
      trust 100 → 倍数 3.0 → 最多借 1500G

  利率计算:
    利率与信任度成反比
    trust 60  → 利率 10%
    trust 100 → 利率 2%
    公式: rate = 0.10 - (trust - 60) / 40 × 0.08

借钱流程:
  1. EconomyManager.request_loan(requester, lender, amount)
  2. 调用 RelationshipManager.can_request_loan() 检查资格
  3. 资格不符 → 返回失败,附带拒绝原因
  4. 资格符合 → 计算可贷额度和利率
  5. 检查贷方余额是否充足
  6. 执行转账,记录债务,创建记忆
  7. 广播 economy_loan_created 事件
  8. RelationshipManager添加债务标签 (creditor/debtor)

还钱机制:
  自动还款触发:
    - 每周一发工资后检查
    - 如果存款 > 借款 × 1.5，触发还款决策
    - 还款概率 = 尽责性/100 × (1 + 宜人性/200)

  还款影响:
    按时还: 信任度+20, 好感度+10, 移除债务标签
    逾期1周: 信任度-5/周
    逾期1个月: 信任度-50, 好感度-30, 关系破裂
    不还: 信任度-80, 好感度-60, 成为敌人

系统集成:
  EconomyManager → (can_request_loan) → RelationshipManager
  EconomyManager → (calculate_loan_multiplier) → RelationshipManager
  EconomyManager → (economy_loan_created) → EventBus
  EconomyManager → (add_memory) → MemoryManager
  RelationshipManager → (add_functional_tag) → 添加债务标签

示例:
  Alice向Bob借500G:
    Alice存款: 200G
    Alice月收入: 3000G
    Bob对Alice信任度: 70

  判断:
    ✅ 信任度70可以借最多500G
    ✅ Alice月收入3000G > 500G
    ✅ Alice真的需要钱（存款<1000G）

  结果: Bob同意借出

  2周后:
    Alice发工资，存款变为950G
    触发还款决策: 概率 = 45/100 × (1 + 70/200) = 0.608
    60.8%概率Alice主动还钱
```

```yaml
    - 珠宝、艺术品、定制物品
    - 好感度: +40~60
    - 适用: 恋人、求婚

送礼决策:
  触发条件:
    - 对方生日
    - 节日
    - 道歉/和解
    - 表达好感

  决策概率:
    基础概率 = 宜人性/100
    关系修正 = 好感度/100
    财务修正 = min(存款/月收入, 2.0)

    最终概率 = 基础 × 关系 × 财务

  礼物价值选择:
    根据关系亲密度和财务状况:
      存款<1000G: 只送小礼物
      存款1000-3000G: 小~普通礼物
      存款>3000G 且 好感>70: 可能送贵重礼物
```

```gdscript
func _pay_weekly_salaries():
    """发放周薪"""
    print("[经济系统] 周一发工资日")

    var all_ais = _get_all_ai_nodes()
    for ai in all_ais:
        var salary = _calculate_weekly_salary(ai)

        money_changed.emit(ai.id, ai.money)
        salary_paid.emit(ai.id, salary)

        # 创建记忆
        MemorySystem.create_memory(
            ai.id,
            "salary_received",
            "收到本周工资: %dG" % salary,
            [],
            "",
            0.4,
            0.5
        )

func _calculate_weekly_salary(ai: Node) -> int:
    """计算周薪"""
    var career_data = CareerSystem.CAREERS.get(ai.career, {})
    var daily_salary = career_data.get("salary", {}).get("base_daily", 100)

    # 计算本周实际工作天数
    var work_days = _calculate_work_days_this_week(ai)

    # 基础周薪
    var base_salary = daily_salary * work_days

    # 绩效奖金
    var performance_bonus = _calculate_performance_bonus(ai)

    # 最终工资
    var final_salary = int(base_salary * (1.0 + performance_bonus))

    return final_salary

func _calculate_work_days_this_week(ai: Node) -> int:
    """计算本周实际工作天数（扣除病假）"""
    var career_data = CareerSystem.CAREERS.get(ai.career, {})
    var work_days_per_week = career_data.get("work_days", [1,2,3,4,5]).size()

    # 获取本周病假/缺勤天数
    var absences = ai.work_data.get("absences_this_week", [])
    var absence_days = 0

    for absence in absences:
        if absence.type == "sick_leave" or absence.type == "absent":
            absence_days += 1

    var actual_days = max(work_days_per_week - absence_days, 0)

    # 重置本周记录
    ai.work_data.absences_this_week = []

    return actual_days

func _calculate_performance_bonus(ai: Node) -> float:
    """计算绩效奖金倍率 (-0.5 ~ 0.5)"""
    var score = 0.0

    # 出勤率（30分）
    var attendance = ai.work_data.get("attendance_rate", 1.0)
    score += attendance * 30.0

    # 工作质量（40分）- 基于尽责性
    var quality = ai.personality.conscientiousness / 100.0
    score += quality * 40.0

    # 加班时长（20分）
    var overtime_count = ai.work_data.get("overtime_count_this_week", 0)
    score += min(overtime_count * 2.0, 20.0)

    # 同事关系（10分）
    var coworker_relations = _get_average_coworker_affection(ai)
    score += coworker_relations / 10.0

    # 转换为奖金倍率
    var bonus = (score - 50.0) / 100.0  # -0.5 ~ 0.5

    return bonus

func _get_average_coworker_affection(ai: Node) -> float:
    """获取与同事的平均好感度"""
    var all_ais = _get_all_ai_nodes()
    var coworkers = []

    for other_ai in all_ais:
        if other_ai.id != ai.id and other_ai.career == ai.career:
            coworkers.append(other_ai)

    if coworkers.size() == 0:
        return 50.0

    var total_affection = 0.0
    for coworker in coworkers:
        var rel = RelationshipSystem.get_relationship(ai.id, coworker.id)
        total_affection += max(rel.affection, 0)  # 只计算正面关系

    return total_affection / coworkers.size()

func _process_daily_expenses():
    """处理每日支出"""
    var all_ais = _get_all_ai_nodes()

    for ai in all_ais:
        var expense = _calculate_daily_expense(ai)
        ai.money -= expense

        money_changed.emit(ai.id, ai.money)

        # 检查财务危机

            financial_crisis.emit(ai.id, -ai.money)
            _handle_financial_crisis(ai)

func _calculate_daily_expense(ai: Node) -> int:
    """计算每日支出"""
    var is_weekend = TimeSystem.is_weekend()

    var base_min = DAILY_EXPENSE_WEEKEND_MIN if is_weekend else DAILY_EXPENSE_WEEKDAY_MIN
    var base_max = DAILY_EXPENSE_WEEKEND_MAX if is_weekend else DAILY_EXPENSE_WEEKDAY_MAX

    var base_expense = randi_range(base_min, base_max)

    # 性格修正 - 尽责性影响节俭程度
    var C = ai.personality.conscientiousness
    var frugality_modifier = 1.0 - (C - 50) / 200.0  # C=100时0.75倍，C=0时1.25倍

    # 外向性影响社交支出
    var E = ai.personality.extraversion
    var social_modifier = 1.0 + (E - 50) / 200.0  # E=100时1.25倍

    var final_expense = int(base_expense * frugality_modifier * social_modifier)

    return final_expense

func _handle_financial_crisis(ai: Node):
    """处理财务危机"""
    print("[经济危机] %s 存款为负: %dG" % [ai.character_name, ai.money])

func _consider_borrowing_money(ai: Node):
    """考虑向朋友借钱"""
    var friends = RelationshipSystem.get_all_friends(ai.id, 50)

    if friends.size() == 0:
        print("  %s 没有可以借钱的朋友" % ai.character_name)
        return

    # 按信任度排序
    friends.sort_custom(func(a, b):
        var rel_a = RelationshipSystem.get_relationship(ai.id, a)
        var rel_b = RelationshipSystem.get_relationship(ai.id, b)
        return rel_a.trust > rel_b.trust
    )

    var needed_amount = -ai.money + 500  # 借到能撑2周的钱

    for friend_id in friends:
        var success = RelationshipSystem.request_loan(ai.id, friend_id, needed_amount)
        if success:
            print("  %s 向 %s 借了 %dG" % [ai.character_name, friend_id, needed_amount])
            return

    print("  %s 借钱失败" % ai.character_name)

func calculate_purchase_probability(ai: Node, item_price: int, item_type: String) -> float:
    """计算购买概率"""
    var base_prob = 0.5

    # 财务状况
    var monthly_income = _get_monthly_income(ai)
    var savings_ratio = ai.money / (monthly_income * 1.0)
    var financial_modifier = 1.0

    if savings_ratio < 0.5:
        financial_modifier = 0.3
    elif savings_ratio < 1.0:
        financial_modifier = 0.6
    elif savings_ratio > 3.0:
        financial_modifier = 1.5

    # 性格 - 尽责性
    var C = ai.personality.conscientiousness
    var personality_modifier = 2.0 - (C / 50.0)

    # 性格 - 开放性
    var O = ai.personality.openness
    if item_type in ["luxury", "new_experience"]:
        personality_modifier *= (O / 50.0)

    # 价格惩罚
    var price_ratio = item_price / (monthly_income / 4.0)
    var price_penalty = 1.0 / (1.0 + price_ratio)

    # 心情
    var mood_modifier = 1.0
    if ai.current_mood > 70:
        mood_modifier = 1.3
    elif ai.current_mood < 30:
        mood_modifier = 0.7

    var final_prob = base_prob * financial_modifier * personality_modifier * price_penalty * mood_modifier

    return clamp(final_prob, 0.0, 1.0)

    var work_days = career_data.get("work_days", [1,2,3,4,5])

    var weekly_salary = daily_salary * work_days.size()
    var monthly_salary = weekly_salary * 4

    return monthly_salary

    elif stress < 30:
```

## ✅ 验收标准

1. **工资系统准确**
   - 周一6:00准时发工资
   - 病假正确扣除（无薪）
   - 绩效奖金合理

2. **支出合理**
   - 平均AI能维持生存（不会破产）
   - 高尽责AI有稳定储蓄
   - 低尽责AI经常缺钱

3. **借贷系统有戏剧性**
   - AI会在困难时借钱
   - 按时还钱增进关系
   - 不还钱破坏关系

4. **经济压力影响行为**
   - 缺钱时减少社交/送礼
   - 有钱时更大方
   - 财务危机影响心情
