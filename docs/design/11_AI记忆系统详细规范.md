# AI记忆系统详细规范 (Memory System)

## 📋 系统概述

AI记忆系统是Microverse的**智能涌现核心**。每个AI拥有多层次的记忆结构，记忆影响AI的决策、对话、情绪和关系。记忆系统需要平衡**真实性**（AI记得重要事件）和**性能**（LLM上下文限制）。

**设计原则**:
- 记忆是**分层的**（短期记忆、长期记忆、核心记忆）
- 记忆是**有选择的**（重要事件保留，琐事遗忘）
- 记忆是**影响决策的**（过去经历塑造当前行为）
- 记忆是**LLM友好的**（结构化存储，动态检索，上下文优化）

## 🧠 记忆层次结构

### 三层记忆架构

```yaml
记忆系统架构:
  第一层 - 工作记忆 (Working Memory):
    - 持续时间: 当前对话/活动结束前
    - 容量: 无限制
    - 存储: 临时变量
    - 用途: 对话上下文、当前任务状态

  第二层 - 短期记忆 (Short-term Memory):
    - 持续时间: 7天游戏时间
    - 容量: 最多50条
    - 存储: 数据库，按时间排序
    - 用途: 近期事件、日常互动、情绪记忆
    - 衰减机制: 超过7天自动转移到长期记忆或遗忘

  第三层 - 长期记忆 (Long-term Memory):
    - 持续时间: 永久（除非被覆盖）
    - 容量: 最多200条
    - 存储: 数据库，按重要性排序
    - 用途: 重要事件、深刻经历、核心关系
    - 遗忘机制: 满容量后，最不重要的记忆被遗忘

  特殊层 - 核心记忆 (Core Memory):
    - 持续时间: 永久（不可遗忘）
    - 容量: 最多10条
    - 存储: AI身份定义
    - 用途: 性格特征、人生目标、核心价值观、身份信息
```

## 🔢 重要性评分算法

### 记忆重要性计算公式

```gdscript
func calculate_importance(memory: Memory, ai: Node) -> float:
    """
    计算记忆重要性 (0.0-1.0)
    综合考虑: 事件类型、情感强度、关系亲密度、性格因素
    """
    var base_importance = _get_base_importance_by_type(memory.memory_type)

    # 因素1: 情感强度（越强烈越重要）
    var emotion_factor = memory.emotional_intensity

    # 因素2: 关系亲密度（与重要人物的记忆更重要）
    var relationship_factor = 0.5  # 默认
    if memory.participants.size() > 0:
        var max_affection = 0.0
        for participant_id in memory.participants:
            var rel = RelationshipSystem.get_relationship(ai.id, participant_id)
            max_affection = max(max_affection, abs(rel.affection))
        relationship_factor = max_affection / 100.0

    # 因素3: 性格因素
    var personality_factor = 1.0
    if memory.memory_type in ["conversation", "social_event"]:
        # 外向AI更重视社交记忆
        personality_factor = ai.personality.extraversion / 50.0
    elif memory.memory_type in ["achievement", "work"]:
        # 尽责AI更重视工作记忆
        personality_factor = ai.personality.conscientiousness / 50.0
    elif memory.emotional_intensity > 0.7:
        # 神经质AI更容易记住情感强烈的事件
        personality_factor = ai.personality.neuroticism / 50.0

    # 因素4: 新鲜度（近期记忆更重要）
    var days_ago = TimeSystem.get_total_days() - memory.timestamp
    var recency_factor = max(1.0 - (days_ago / 30.0), 0.3)  # 30天后降到最低

    # 综合计算
    var importance = base_importance * 0.4 + \
                    emotion_factor * 0.25 + \
                    relationship_factor * 0.2 + \
                    personality_factor * 0.1 + \
                    recency_factor * 0.05

    return clamp(importance, 0.0, 1.0)

func _get_base_importance_by_type(type: String) -> float:
    """不同记忆类型的基础重要性"""
    var base_values = {
        "confession": 1.0,
        "breakup": 1.0,
        "job_change": 1.0,
        "conflict": 0.85,
        "reconciliation": 0.8,
        "illness": 0.7,
        "promotion": 0.9,
        "achievement": 0.75,
        "gift_received": 0.6,
        "conversation": 0.4,
        "overtime": 0.35,
        "festival": 0.6,
        "coworker_interaction": 0.45
    }
    return base_values.get(type, 0.5)
```

## 🔍 记忆检索系统

### 检索策略

```yaml
记忆检索方式:
  1. 时间检索 (Temporal Retrieval):
     用途: "我上周做了什么?"
     方法: 按时间戳排序，返回最近N条

  2. 重要性检索 (Importance Retrieval):
     用途: "我人生中最重要的事件是什么?"
     方法: 按importance排序，返回Top N

  3. 关联检索 (Associative Retrieval):
     用途: "我和Alice的所有记忆"
     方法: 筛选participants包含特定AI的记忆

  4. 情感检索 (Emotional Retrieval):
     用途: "最让我快乐的记忆"
     方法: 按emotional_valence排序

  5. 语义检索 (Semantic Retrieval):
     用途: "关于工作的记忆"
     方法: 使用embedding向量相似度匹配（可选）

  6. 混合检索 (Hybrid Retrieval):
     用途: LLM上下文构建
     方法: 综合时间、重要性、相关性的加权检索
```

### LLM上下文构建策略

```gdscript
func build_llm_context(ai: Node, context_type: String, max_tokens: int = 1000) -> String:
    """
    为LLM构建记忆上下文

    参数:
      - context_type: "conversation" | "decision" | "reflection"
      - max_tokens: 最大token数（估算：1条记忆≈50 tokens）
    """
    var max_memories = max_tokens / 50
    var context = ""

    match context_type:
        "conversation":
            # 对话上下文：最近记忆 + 相关人物记忆
            var recent = get_recent_memories(ai.id, 10)
            var relevant = get_memories_with_participant(ai.id, ai.current_conversation_target, 5)
            context = _format_memories_for_llm(recent + relevant, max_memories)

        "decision":
            # 决策上下文：重要记忆 + 相关情感记忆
            var important = get_important_memories(ai.id, 15)
            var emotional = get_emotional_memories(ai.id, 5)
            context = _format_memories_for_llm(important + emotional, max_memories)

        "reflection":
            # 反思上下文：所有重要记忆
            var all_important = get_important_memories(ai.id, 30)
            context = _format_memories_for_llm(all_important, max_memories)

    return context

func _format_memories_for_llm(memories: Array, max_count: int) -> String:
    """格式化记忆为LLM友好的文本"""
    var sorted_memories = memories.duplicate()
    sorted_memories.sort_custom(func(a, b):
        return a.importance * (1.0 + a.emotional_intensity) > b.importance * (1.0 + b.emotional_intensity)
    )

    var context = "### 相关记忆 ###\n"
    var count = 0
    for memory in sorted_memories:
        if count >= max_count:
            break

        var time_str = _format_game_time(memory.game_time)
        var emotion_str = _format_emotion(memory.emotional_valence, memory.emotional_intensity)

        context += "[%s] %s %s\n" % [time_str, memory.llm_summary, emotion_str]
        count += 1

    return context

func _format_game_time(time: Dictionary) -> String:
    """格式化游戏时间"""
    return "%s %d日" % [time.get("season", ""), time.get("day", 0)]

func _format_emotion(valence: float, intensity: float) -> String:
    """格式化情感标签"""
    if intensity < 0.3:
        return ""

    var emotion = ""
    if valence > 0.6:
        emotion = "😊快乐"
    elif valence > 0.3:
        emotion = "🙂愉快"
    elif valence < -0.6:
        emotion = "😢悲伤"
    elif valence < -0.3:
        emotion = "😟难过"
    else:
        return ""

    if intensity > 0.7:
        emotion += "!!"

    return "(" + emotion + ")"
```

## ⏳ 记忆衰减与遗忘

### 短期记忆转移机制

```gdscript
func process_memory_consolidation(ai: Node):
    """
    每日记忆巩固处理
    - 短期记忆满7天后，转移到长期记忆或遗忘
    - 长期记忆满容量后，最不重要的被遗忘
    """
    var current_day = TimeSystem.get_total_days()
    var short_term = get_short_term_memories(ai.id)

    for memory in short_term:
        var age_days = current_day - memory.timestamp

        if age_days >= 7:
            # 决定是否转移到长期记忆
            var should_keep = _should_consolidate_to_long_term(memory, ai)

            if should_keep:
                # 转移到长期记忆
                _transfer_to_long_term(memory, ai)
            else:
                # 遗忘
                _forget_memory(memory, ai)

func _should_consolidate_to_long_term(memory: Memory, ai: Node) -> bool:
    """判断是否应该转移到长期记忆"""
    # 高重要性或高情感强度的记忆保留
    if memory.importance > 0.6:
        return true
    if memory.emotional_intensity > 0.7:
        return true

    # 被频繁回忆的记忆保留
    if memory.access_count > 3:
        return true

    # 与重要人物相关的记忆保留
    for participant_id in memory.participants:
        var rel = RelationshipSystem.get_relationship(ai.id, participant_id)
        if abs(rel.affection) > 60:  # 好友或敌人
            return true

    # 性格因素
    if ai.personality.neuroticism > 70:
        # 神经质AI更容易记住负面记忆
        if memory.emotional_valence < -0.5:
            return true

    if ai.personality.openness > 70:
        # 开放AI更容易记住新奇经历
        if memory.memory_type in ["achievement", "festival", "new_experience"]:
            return true

    return false

func _transfer_to_long_term(memory: Memory, ai: Node):
    """转移到长期记忆"""
    var long_term = get_long_term_memories(ai.id)

    # 检查容量（最多200条）
    if long_term.size() >= 200:
        # 找出最不重要的记忆并遗忘
        long_term.sort_custom(func(a, b): return a.importance < b.importance)
        var least_important = long_term[0]
        _forget_memory(least_important, ai)

    # 添加到长期记忆
    memory.access_count = 0  # 重置访问计数
    _save_to_long_term(memory)

func _forget_memory(memory: Memory, ai: Node):
    """遗忘记忆"""
    # 从数据库删除
    _delete_from_database(memory.memory_id)

    # 可选：记录遗忘日志（用于调试）
    print("[记忆系统] %s 遗忘了: %s" % [ai.character_name, memory.llm_summary])
```

    更新核心记忆（仅在重大人生事件时）

      - 职业改变

      - 深刻顿悟

    memory.timestamp = TimeSystem.get_total_days()
    memory.game_time = TimeSystem.get_current_time_dict()
    memory.description = description
    memory.participants = participants
    memory.location = location
    memory.emotional_intensity = emotional_intensity
    memory.emotional_valence = emotional_valence

    # 生成LLM摘要
    memory.llm_summary = _generate_llm_summary(memory)

    # 计算重要性
    var ai = _get_ai_node(ai_id)
    if ai:
        memory.importance = calculate_importance(memory, ai)

    # 添加到短期记忆
    _add_to_short_term(memory)

    # 检查是否需要创建情感记忆
    if emotional_intensity > 0.7 or abs(emotional_valence) > 0.8:
        _create_emotional_memory(memory, ai)

    print("[记忆创建] %s: %s (重要性: %.2f)" % [ai_id, memory.llm_summary, memory.importance])

    return memory

func _generate_llm_summary(memory: Memory) -> String:
    """生成LLM友好的简短摘要"""
    var summary = ""

    match memory.memory_type:
        "conversation":
            if memory.participants.size() > 0:
                summary = "和%s交谈" % memory.participants[0]
            else:
                summary = "进行了一次对话"

        "gift_received":
            if memory.participants.size() > 0:
                summary = "收到%s的礼物" % memory.participants[0]

        "gift_given":
            if memory.participants.size() > 0:
                summary = "送礼物给%s" % memory.participants[0]

        "conflict":
            if memory.participants.size() > 0:
                summary = "和%s发生冲突" % memory.participants[0]

        "reconciliation":
            if memory.participants.size() > 0:
                summary = "和%s和解" % memory.participants[0]

        "confession":
            if "被表白" in memory.description:
                summary = "%s向我表白" % memory.participants[0]
            else:
                summary = "我向%s表白" % memory.participants[0]

        "illness":
            summary = "生病了"

        "overtime":
            summary = "加班"

        "promotion":
            summary = "工资上涨"

        _:
            summary = memory.description.substr(0, 50)  # 截取前50字符

    return summary

func _create_emotional_memory(base_memory: Memory, ai: Node):
    """基于强烈情感事件创建情感记忆标签"""
    if not base_memory.related_memories.has("emotional_peak"):
        base_memory.related_memories.append("emotional_peak")

    # 神经质AI更容易形成创伤记忆
    if ai and ai.personality.neuroticism > 70 and base_memory.emotional_valence < -0.8:
        base_memory.related_memories.append("trauma")
        print("[情感记忆] %s 形成了创伤记忆: %s" % [ai.character_name, base_memory.llm_summary])

func build_llm_context(ai: Node, context_type: String, max_tokens: int = 1000) -> String:
    """为LLM构建记忆上下文"""
    var max_memories = max_tokens / 50
    var context = ""

    match context_type:
        "conversation":
            var recent = get_recent_memories(ai.id, 10)
            var relevant = []
            if ai.has("current_conversation_target") and ai.current_conversation_target:
                relevant = get_memories_with_participant(ai.id, ai.current_conversation_target, 5)
            context = _format_memories_for_llm(recent + relevant, max_memories)

        "decision":
            var important = get_important_memories(ai.id, 15)
            var emotional = get_emotional_memories(ai.id, 5)
            context = _format_memories_for_llm(important + emotional, max_memories)

        "reflection":
            var all_important = get_important_memories(ai.id, 30)
            context = _format_memories_for_llm(all_important, max_memories)

        "daily_summary":
            var today = get_recent_memories(ai.id, 20)
            context = _format_memories_for_llm(today, max_memories)

    return context

func _format_memories_for_llm(memories: Array, max_count: int) -> String:
    """格式化记忆为LLM文本"""
    # 去重
    var unique_memories = []
    var seen_ids = []
    for m in memories:
        if not m.memory_id in seen_ids:
            unique_memories.append(m)
            seen_ids.append(m.memory_id)

    # 按重要性×情感强度排序
    unique_memories.sort_custom(func(a, b):
        return a.importance * (1.0 + a.emotional_intensity) > b.importance * (1.0 + b.emotional_intensity)
    )

    var context = "### 相关记忆 ###\n"
    var count = 0
    for memory in unique_memories:
        if count >= max_count:
            break

        var time_str = "%s %d日 %d:00" % [
            memory.game_time.get("season", ""),
            memory.game_time.get("day", 0),
            memory.game_time.get("hour", 0)
        ]

        var emotion_str = ""
        if memory.emotional_intensity > 0.3:
            if memory.emotional_valence > 0.6:
                emotion_str = "(😊快乐)"
            elif memory.emotional_valence > 0.3:
                emotion_str = "(🙂愉快)"
            elif memory.emotional_valence < -0.6:
                emotion_str = "(😢悲伤)"
            elif memory.emotional_valence < -0.3:
                emotion_str = "(😟难过)"

        context += "[%s] %s %s\n" % [time_str, memory.llm_summary, emotion_str]
        count += 1

    return context

func calculate_importance(memory: Memory, ai: Node) -> float:
    """计算记忆重要性"""
    var base_importance = _get_base_importance_by_type(memory.memory_type)

    # 因素1: 情感强度
    var emotion_factor = memory.emotional_intensity

    # 因素2: 关系亲密度
    var relationship_factor = 0.5
    if memory.participants.size() > 0:
        var max_affection = 0.0
        for participant_id in memory.participants:
            var rel = RelationshipSystem.get_relationship(ai.id, participant_id)
            max_affection = max(max_affection, abs(rel.affection))
        relationship_factor = max_affection / 100.0

    # 因素3: 性格因素
    var personality_factor = 1.0
    if memory.memory_type in ["conversation", "social_event", "gift_received"]:
        personality_factor = ai.personality.extraversion / 50.0
    elif memory.memory_type in ["achievement", "work", "promotion"]:
        personality_factor = ai.personality.conscientiousness / 50.0
    elif memory.emotional_intensity > 0.7:
        personality_factor = ai.personality.neuroticism / 50.0

    # 因素4: 新鲜度
    var days_ago = TimeSystem.get_total_days() - memory.timestamp
    var recency_factor = max(1.0 - (days_ago / 30.0), 0.3)

    # 综合计算
    var importance = base_importance * 0.4 + \
                    emotion_factor * 0.25 + \
                    relationship_factor * 0.2 + \
                    personality_factor * 0.1 + \
                    recency_factor * 0.05

    return clamp(importance, 0.0, 1.0)

func _get_base_importance_by_type(type: String) -> float:
    var base_values = {
        "confession": 1.0,
        "breakup": 1.0,
        "job_change": 1.0,
        "conflict": 0.85,
        "reconciliation": 0.8,
        "illness": 0.7,
        "promotion": 0.9,
        "achievement": 0.75,
        "financial_crisis": 0.8,
        "gift_received": 0.6,
        "gift_given": 0.5,
        "conversation": 0.4,
        "overtime": 0.35,
        "festival": 0.6,
        "coworker_interaction": 0.45,
        "late_arrival": 0.4
    }
    return base_values.get(type, 0.5)

func _on_day_changed(new_day: int):

    for ai_id in memories_by_ai.keys():

func process_memory_consolidation(ai: Node):
    """记忆巩固处理"""
    var current_day = TimeSystem.get_total_days()
    var short_term = _get_short_term_memories(ai.id)

    for memory in short_term:
        var age_days = current_day - memory.timestamp

        if age_days >= 7:
            if _should_consolidate_to_long_term(memory, ai):
                _transfer_to_long_term(memory, ai)
            else:
                _forget_memory(memory, ai)

func _should_consolidate_to_long_term(memory: Memory, ai: Node) -> bool:
    """判断是否转移到长期记忆"""
    if memory.importance > 0.6:
        return true
    if memory.emotional_intensity > 0.7:
        return true
    if memory.access_count > 3:
        return true

    for participant_id in memory.participants:
        var rel = RelationshipSystem.get_relationship(ai.id, participant_id)
        if abs(rel.affection) > 60:
            return true

    if ai.personality.neuroticism > 70 and memory.emotional_valence < -0.5:
        return true

    if ai.personality.openness > 70 and memory.memory_type in ["achievement", "festival"]:
        return true

    return false

func _transfer_to_long_term(memory: Memory, ai: Node):
    """转移到长期记忆"""
    var long_term = _get_long_term_memories(ai.id)

    if long_term.size() >= 200:
        long_term.sort_custom(func(a, b): return a.importance < b.importance)
        var least_important = long_term[0]
        _forget_memory(least_important, ai)

    memory.access_count = 0
    _get_short_term_memories(ai.id).erase(memory)
    _get_long_term_memories(ai.id).append(memory)

func _forget_memory(memory: Memory, ai: Node):
    """遗忘记忆"""
    _get_short_term_memories(ai.id).erase(memory)
    _get_long_term_memories(ai.id).erase(memory)
    print("[记忆遗忘] %s 遗忘了: %s" % [ai.character_name, memory.llm_summary])

## ✅ 验收标准

1. **记忆分层清晰**
   - 短期记忆7天后自动转移或遗忘
   - 长期记忆保留重要事件
   - 核心记忆定义AI身份

2. **重要性计算合理**
   - Emma（N=80）更容易记住负面事件
   - Alice（E=85）更重视社交记忆
   - Bob（C=90）更重视工作成就

3. **LLM上下文优化**
   - 自动检索最相关记忆
   - 格式化为可读文本
   - 控制token数量

4. **记忆影响行为**
   - 被背叛的AI不再轻易信任
   - 快乐记忆提升基础心情
   - 创伤记忆改变决策模式
