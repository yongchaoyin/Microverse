# AI关系系统详细规范 (Relationship System)

## 📋 系统概述

AI关系系统是Microverse的**社交叙事引擎核心**。每对AI之间维护多维度的关系数据，关系会随着互动、事件、性格契合度动态演化。

**设计原则**:
- 关系是**多维度的**（不只是好感度，还有熟悉度、信任度、浪漫度）
- 关系是**双向不对称的**（A对B的感觉 ≠ B对A的感觉）
- 关系是**涌现的**（不是脚本化的，而是从互动中自然产生）
- 关系创造**戏剧性**（友谊、恋爱、背叛、和解都是故事）

---

## 🎯 关系维度定义

每对AI之间维护**4个核心维度** + **关系状态标签**

### 1. 熟悉度 (Familiarity) - F值

**定义**: 两个AI对彼此的了解程度

```yaml
熟悉度: 0-100
  0-10: 陌生人 (Strangers)
    - 从未交谈过
    - 不知道对方名字/职业
    - 对话概率: 5%

  11-30: 点头之交 (Acquaintances)
    - 知道基本信息
    - 偶尔打招呼
    - 对话概率: 20%

  31-60: 熟人 (Known)
    - 定期交流
    - 了解对方日常
    - 对话概率: 50%

  61-80: 朋友 (Friends)
    - 深入了解
    - 主动约见面
    - 对话概率: 80%

  81-100: 密友 (Close Friends)
    - 知道对方秘密
    - 几乎每天互动
    - 对话概率: 95%
```

**增长机制**:
- 每次对话: +2~5 (取决于对话质量)
- 共同参加活动: +5~10
- 送礼: +3~8
- 时间衰减: -0.5/周 (如果2周未互动)

---

### 2. 好感度 (Affection) - A值

**定义**: 情感上的喜欢/讨厌程度

```yaml
好感度: -100 ~ +100
  -100 ~ -61: 仇恨 (Hatred)
    - 主动回避
    - 拒绝所有互动
    - 可能公开冲突

  -60 ~ -31: 厌恶 (Dislike)
    - 不愿交流
    - 负面评价
    - 冲突概率: 40%

  -30 ~ -1: 不喜欢 (Neutral Negative)
    - 敷衍应对
    - 保持距离

  0 ~ 30: 中立 (Neutral)
    - 正常礼貌
    - 没有特别感觉

  31 ~ 60: 喜欢 (Like)
    - 乐于互动
    - 送礼、帮助

  61 ~ 85: 好友 (Good Friends)
    - 信任、分享秘密
    - 优先邀请参加活动

  86 ~ 100: 挚友/恋人 (Best Friends / Romantic)
    - 深厚情感连接
    - 愿意牺牲自我
```

**影响因素**:
- 性格契合度: 初始好感 = `PersonalitySystem.get_compatibility() × 50 - 25`
- 正面互动: +5~15/次
- 冲突: -20~-40/次
- 背叛/欺骗: -50~-80

---

### 3. 信任度 (Trust) - T值

**定义**: 对对方可靠性、诚实度的评估

```yaml
信任度: 0-100
  0-20: 完全不信任 (Zero Trust)
    - 不会分享任何私密信息
    - 拒绝借钱/帮助
    - 怀疑对方动机

  21-40: 低信任 (Low Trust)
    - 保持警惕
    - 只进行表面互动

  41-60: 一般信任 (Moderate Trust)
    - 正常互动
    - 小额借贷可能

  61-80: 高信任 (High Trust)
    - 分享秘密
    - 可以求助
    - 借钱概率高

  81-100: 绝对信任 (Absolute Trust)
    - 无条件相信
    - 愿意承担风险帮助
```

**增长机制**:
- 承诺并兑现: +10~20
- 守住秘密: +15
- 借钱并还款: +20
- **失信**: -30~-50 (极难恢复!)
- **背叛**: -80 (几乎不可逆)

---

### 4. 浪漫度 (Romance) - R值

**定义**: 浪漫/性吸引力（仅在满足条件时激活）

```yaml
浪漫度: 0-100 (默认锁定为0)
  激活条件:
    - 熟悉度 > 40
    - 好感度 > 50
    - 性取向匹配
    - 双方都单身（或开放关系）

  0-20: 朋友区 (Friendzone)
    - 没有浪漫感觉

  21-40: 心动 (Attraction)
    - 开始注意对方
    - 偶尔暗示

  41-60: 暗恋 (Crush)
    - 主动制造互动机会
    - 送礼频率增加
    - 可能表白

  61-80: 热恋 (Dating)
    - 确认关系
    - 频繁约会
    - 排他性互动

  81-100: 深爱 (Deep Love)
    - 考虑同居/结婚
    - 优先级最高
```

**增长机制**:
- 浪漫活动（约会、送花）: +5~15
- 表白成功: +20
- 亲密对话: +3~8
- 冷落/忽视: -5/周
- 背叛/出轨: -100 (关系破裂)

## 🏷️ 关系状态标签 (Relationship Tags)

除了数值，每对关系还有**状态标签**

```yaml
关系标签系统:
  基础状态:
    - "strangers" (陌生人)
    - "acquaintances" (点头之交)
    - "friends" (朋友)
    - "close_friends" (密友)
    - "best_friends" (挚友)

  负面状态:
    - "enemies" (敌人)
    - "rivals" (竞争对手)
    - "ex_friends" (前朋友)
    - "betrayed" (被背叛)

  浪漫状态:
    - "attracted" (有好感)
    - "crushing" (暗恋中)
    - "dating" (约会中)
    - "committed" (确认关系)
    - "ex_lovers" (前恋人)

  特殊状态:
    - "coworkers" (同事)
    - "neighbors" (邻居)
    - "mentor_mentee" (师徒)
    - "debtor_creditor" (债务关系)
```

### 标签优先级规则 🏆

**设计原则**: 自动维护主标签(primary_tag),基于优先级系统选择最重要的标签

```yaml
标签优先级系统:
  优先级定义 (数值越高优先级越高):
    100: lover (恋人)
    95:  spouse (配偶)
    90:  best_friend (最好的朋友)
    85:  close_friend (亲密朋友)
    80:  enemy (敌人)
    75:  rival (竞争对手)
    70:  friend (朋友)
    65:  mentor/mentee (导师/学生)
    60:  acquaintance (熟人)
    60:  business_partner (商业伙伴)
    58:  creditor/debtor (债权人/债务人)
    55:  colleague (同事)
    50:  neighbor (邻居)
    50:  classmate (同学)
    10:  stranger (陌生人)

主标签自动更新规则:
  1. 遍历当前关系的所有标签
  2. 查找优先级最高的标签
  3. 设置为 primary_tag
  4. 每次关系维度变化时自动触发

自动标签维护:
  基于关系维度自动添加/移除基础标签:

  熟悉度标签:
    F >= 95 → 添加 "best_friend", 移除 "friend", "acquaintance", "stranger"
    F >= 80 → 添加 "close_friend", 移除 "acquaintance", "stranger"
    F >= 60 → 添加 "friend", 移除 "acquaintance", "stranger"
    F >= 20 → 添加 "acquaintance", 移除 "stranger"
    F < 20  → 添加 "stranger"

  浪漫度标签:
    R >= 70 且 A >= 60 → 添加 "lover"
    R < 50 → 移除 "lover"

  敌对标签:
    A <= -60 → 添加 "enemy", 移除所有友好标签
    A > -60 → 移除 "enemy"

功能性标签:
  不基于数值自动生成,由游戏事件触发:
  - colleague: 在同一公司工作
  - neighbor: 住在同一区域
  - creditor/debtor: 借贷关系建立时添加,还款后移除
  - mentor/mentee: 特殊关系事件触发
```

**实现示例**:
```gdscript
# script/ai/RelationshipManager.gd

const RELATIONSHIP_TAG_PRIORITY = {
	"lover": 100,
	"spouse": 95,
	"best_friend": 90,
	"close_friend": 85,
	"enemy": 80,
	"rival": 75,
	"friend": 70,
	"mentor": 65,
	"mentee": 65,
	"acquaintance": 60,
	"colleague": 55,
	"neighbor": 50,
	"creditor": 58,
	"debtor": 58,
	"stranger": 10
}

class Relationship:
	var tags: Array = ["stranger"]
	var primary_tag: String = "stranger"

	func update_primary_tag() -> void:
		"""根据优先级自动选择主标签"""
		if tags.is_empty():
			primary_tag = "stranger"
			return

		var highest_priority = -1
		var selected_tag = "stranger"

		for tag in tags:
			var priority = RELATIONSHIP_TAG_PRIORITY.get(tag, 0)
			if priority > highest_priority:
				highest_priority = priority
				selected_tag = tag

		primary_tag = selected_tag

	func add_tag(new_tag: String) -> void:
		"""添加标签并自动更新主标签"""
		if new_tag not in tags:
			tags.append(new_tag)
			update_primary_tag()

	func remove_tag(tag: String) -> void:
		"""移除标签并自动更新主标签"""
		var index = tags.find(tag)
		if index != -1:
			tags.remove_at(index)
			update_primary_tag()

# 关系维度变化时自动更新标签
func _auto_update_tags(relationship: Relationship) -> void:
	"""基于关系维度自动添加/移除标签"""
	var F = relationship.familiarity
	var A = relationship.affection
	var R = relationship.romance

	# 熟悉度标签
	if F >= 95:
		relationship.add_tag("best_friend")
		relationship.remove_tag("friend")
		relationship.remove_tag("acquaintance")
		relationship.remove_tag("stranger")
	elif F >= 80:
		relationship.add_tag("close_friend")
		relationship.remove_tag("acquaintance")
		relationship.remove_tag("stranger")
	elif F >= 60:
		relationship.add_tag("friend")
		relationship.remove_tag("acquaintance")
		relationship.remove_tag("stranger")
	elif F >= 20:
		relationship.add_tag("acquaintance")
		relationship.remove_tag("stranger")
	else:
		relationship.add_tag("stranger")

	# 浪漫度标签
	if R >= 70 and A >= 60:
		relationship.add_tag("lover")
	elif R < 50:
		relationship.remove_tag("lover")

	# 敌对标签
	if A <= -60:
		relationship.add_tag("enemy")
		relationship.remove_tag("friend")
		relationship.remove_tag("close_friend")
		relationship.remove_tag("best_friend")
	else:
		relationship.remove_tag("enemy")

	# 主标签自动更新
	relationship.update_primary_tag()
```

**配置文件**: `data/relationship/tag_config.json`
```json

}
```

## 💔 关系事件系统

### 关键关系事件

```yaml
1. 表白 (Confession):
   触发条件:
     - 浪漫度 > 60
     - 好感度 > 60
     - 性格外向性 > 40 (内向AI需要更久)
   成功条件:
     - 对方浪漫度 > 40
     - 对方好感度 > 50
   结果:
     - 成功: 双方浪漫度+20, 关系标签→"dating"
     - 拒绝: 表白方浪漫度-30, 尴尬期2周

2. 冲突 (Conflict):
   触发条件:
     - 好感度 < 0
     - 性格契合度 < 0.3
     - 随机事件（价值观冲突、误会）
   影响:
     - 好感度 -20~-40
     - 信任度 -10~-20
     - 2周冷战期（拒绝互动）

3. 和解 (Reconciliation):
   触发条件:
     - 冲突后2周+
     - 一方宜人性 > 60（主动道歉）
     - 或第三方调解（Frank作为中间人）
   结果:
     - 好感度恢复50%
     - 信任度恢复30%
     - 添加"reconciled"标签

4. 背叛 (Betrayal):
   类型:
     - 泄露秘密
     - 借钱不还
     - 出轨（浪漫关系中）
   影响:
     - 信任度 -80
     - 好感度 -60
     - 关系标签→"betrayed"
     - **极难恢复**（需要6个月+持续弥补）

5. 借贷 (Loan):
   条件:
     - 信任度 > 40
     - 借方有偿还能力判断
   金额:
     - 信任40-60: 最多200G
     - 信任60-80: 最多500G
     - 信任80+: 最多1000G
   还款:
     - 按时还: 信任度+20
     - 逾期: 每周 -5信任
     - 不还: -50信任, -30好感, 关系破裂

6. 送礼 (Gift Giving):
   效果取决于:
     - 礼物价值
     - 对方喜好匹配度
     - 当前关系状态
   计算:
     好感度增加 = 礼物价值/10 × 喜好匹配(0.5-2.0) × 关系系数
   示例:
     - 100G礼物, 完美匹配, 朋友关系: +20好感
     - 50G礼物, 不喜欢, 陌生人: +2好感

   礼物类型与偏好系统:
     预定义礼物类别:
       - 书籍类 (books): 适合高开放性、高智慧的AI
       - 美食类 (food): 适合高宜人性、喜欢享受的AI
       - 艺术品 (art): 适合高开放性、有艺术品味的AI
       - 科技产品 (tech): 适合高尽责性、工作导向的AI
       - 鲜花 (flowers): 适合浪漫关系、高外向性的AI
       - 运动用品 (sports): 适合低神经质、高外向性的AI
       - 手工制品 (handmade): 适合重视情感价值的AI

     每个AI的礼物偏好:
       在CharacterPersonality中定义每个角色的gift_preferences:
       ```gdscript
       "Stephen": {
           "gift_preferences": {
               "books": 1.8,      # 非常喜欢书籍
               "tech": 1.5,       # 喜欢科技产品
               "food": 1.0,       # 中立
               "flowers": 0.3,    # 不太喜欢鲜花
               "handmade": 0.5    # 不太重视手工制品
           }
       }
       ```

     礼物价值与关系效果:
       基础效果 = 礼物价值 / 10
       喜好匹配 = gift_preferences[礼物类型] (0.3 - 2.0)
       关系系数:
         - 陌生人(F<20): 0.5倍效果
         - 熟人(F 20-60): 1.0倍效果
         - 朋友(F 60-80): 1.5倍效果
         - 密友(F>80): 2.0倍效果

       最终好感度增加 = 基础效果 × 喜好匹配 × 关系系数
       熟悉度增加 = 3 + (礼物价值 / 50)  # 固定3点 + 价值加成

     礼物价格区间:
       - 便宜礼物: 20-50G (基础效果2-5点)
       - 普通礼物: 50-100G (基础效果5-10点)
       - 贵重礼物: 100-200G (基础效果10-20点)
       - 奢侈礼物: 200G+ (基础效果20+点)

     送礼时机与LLM决策:
       AI何时决定送礼:
         1. 生日/特殊节日
         2. 关系需要修复时 (发生冲突后和解)
         3. 表白前铺垫 (浪漫度>40, 想提升好感度)
         4. 感谢帮助 (对方完成了重要任务帮忙)
         5. 随机善意 (高宜人性AI偶尔送礼)

       LLM决策Prompt:
         ```
         你是{character_name},正在考虑是否给{target_name}送礼物。

         你和{target_name}的关系:
         - 好感度: {affection}/100
         - 熟悉度: {familiarity}/100
         - 关系标签: {primary_tag}

         你的经济状况: {money}G
         当前情境: {context}  # 例如: "对方刚帮你完成了工作任务"

         可选礼物:
         {available_gifts}  # JSON列表,包含礼物类型、价格、对方偏好度

         你的性格:
         - 宜人性: {agreeableness}
         - 经济观念: {spending_habit}

         请决定是否送礼,如果送请选择礼物类型和预算。
         返回JSON: {
           "give_gift": true/false,
           "gift_type": "礼物类型" (如果give_gift=true),
           "budget": 金额 (如果give_gift=true),
           "reason": "理由"
         }
         ```

   送礼任务流程 (与TaskSystem集成):
     ⚠️ 送礼作为独立任务类型,需在TaskSystem中添加

     任务创建:
       1. AIAgent通过LLM决策要送礼
       2. 创建"gift_giving"类型任务:
          ```gdscript
          {
              "type": "gift_giving",
              "target_character": "接收者ID",
              "gift_type": "礼物类型",
              "gift_value": 礼物价值,
              "priority": "normal",
              "deadline": 当天18:00  # 需在当天完成
          }
          ```

     任务执行:
       1. AI移动到商店位置 (如果有商店系统)
          或直接扣除金额 (简化版)
       2. AI移动到接收者附近
       3. 执行送礼动作
       4. 触发RelationshipManager.give_gift()
       5. 记录到双方记忆

     任务完成回调:
       TaskSystem发送信号:
         gift_task_completed(giver_id, receiver_id, gift_type, gift_value)

       RelationshipManager监听并处理:
         - 更新关系维度
         - 创建记忆
         - UI展示送礼气泡

   GDScript实现:
     ```gdscript
     # script/ai/RelationshipManager.gd

     # 礼物类型配置
     const GIFT_TYPES = {
         "books": {"base_cost": 80, "name": "书籍"},
         "food": {"base_cost": 50, "name": "美食"},
         "art": {"base_cost": 150, "name": "艺术品"},
         "tech": {"base_cost": 200, "name": "科技产品"},
         "flowers": {"base_cost": 30, "name": "鲜花"},
         "sports": {"base_cost": 100, "name": "运动用品"},
         "handmade": {"base_cost": 60, "name": "手工制品"}
     }

     func give_gift(
         giver_id: String,
         receiver_id: String,
         gift_type: String,
         gift_value: int
     ) -> Dictionary:
         """处理送礼事件并返回关系变化"""
         var rel = get_relationship(giver_id, receiver_id)

         # 获取接收者的礼物偏好
         var receiver_personality = CharacterPersonality.get_personality(receiver_id)
         var preference_match = receiver_personality.gift_preferences.get(gift_type, 1.0)

         # 计算关系系数
         var relationship_modifier = 1.0
         if rel.familiarity < 20:
             relationship_modifier = 0.5
         elif rel.familiarity >= 60 and rel.familiarity < 80:
             relationship_modifier = 1.5
         elif rel.familiarity >= 80:
             relationship_modifier = 2.0

         # 计算好感度增加
         var base_effect = gift_value / 10.0
         var affection_gain = base_effect * preference_match * relationship_modifier
         rel.affection = min(rel.affection + affection_gain, 100.0)

         # 熟悉度增加
         var familiarity_gain = 3.0 + (gift_value / 50.0)
         rel.familiarity = min(rel.familiarity + familiarity_gain, 100.0)

         # 记录送礼次数
         rel.total_gifts_given += 1

         _update_relationship_tags(rel)

         # 记录到记忆
         var gift_name = GIFT_TYPES[gift_type]["name"]
         MemoryManager.add_memory(receiver_id, {
             "content": "%s送给我%s(价值%dG)" % [giver_id, gift_name, gift_value],
             "type": MemoryManager.MemoryType.INTERACTION,
             "importance": _calculate_gift_memory_importance(gift_value, preference_match),
             "valence": preference_match  # 正面情感值
         })

7. 社交邀请拒绝 (Invitation Rejection):
   邀请类型和拒绝后果:
     休闲邀请 (Casual Invitation):
       - 示例: 一起吃午饭、喝咖啡、闲聊
       - 拒绝影响: 好感度 -2, 熟悉度 -1
       - 连续拒绝3次: 好感度额外 -5
       - 说明: 影响轻微,但反复拒绝显示不重视关系

     重要邀请 (Important Invitation):
       - 示例: 生日派对、庆功宴、重要聚会
       - 拒绝影响: 好感度 -8, 熟悉度 -3
       - 关系标签影响: 如果是"friend"级别,可能降级到"acquaintance"
       - 说明: 重要场合的缺席会被视为不重视

     约会邀请 (Date Invitation):
       - 示例: 浪漫约会(仅限已解锁浪漫关系)
       - 拒绝影响: 好感度 -12, 浪漫度 -15, 信任度 -5
       - 连续拒绝2次: 浪漫度 -30, 可能退回"朋友区"
       - 说明: 恋爱关系需要持续投入,冷落代价高

     工作协助 (Work Help Request):
       - 示例: 请求帮忙完成工作任务、加班支援
       - 拒绝影响: 信任度 -8, 好感度 -5
       - 如果是同事关系: 额外 -3信任度
       - 说明: 职场互助是建立信任的重要途径

     困难求助 (Emergency Help):
       - 示例: 紧急借钱、严重情感问题、健康危机
       - 拒绝影响: 信任度 -20, 好感度 -15
       - 关系破裂风险: 如果关系等级≥"close_friend",可能直接降级到"acquaintance"
       - 说明: 关键时刻的袖手旁观会严重伤害关系

   AI决策机制 (LLM驱动):
     被邀请方是否接受由LLM根据以下因素综合决策:
       1. 关系状态:
          - 好感度: 好感度越高,接受概率越高
          - 熟悉度: 陌生人邀请更容易被拒绝
          - 信任度: 高信任关系更难拒绝
          - 主标签: "best_friend"/"lover"很少拒绝

       2. 性格因素:
          - 宜人性(Agreeableness): 高宜人性AI更难拒绝邀请
          - 外向性(Extroversion): 高外向性AI更容易接受社交邀请
          - 尽责性(Conscientiousness): 影响工作协助类邀请

       3. 当前状态:
          - 当前任务优先级: 如果正在处理高优先级任务,拒绝概率增加
          - 情绪状态: 心情不好时更容易拒绝
          - 健康状态: 疲劳/生病时拒绝概率增加
          - 经济状况: 影响需要花钱的邀请

       4. 邀请重要性:
          - 重要邀请(生日派对、紧急求助)更难拒绝
          - 休闲邀请容易被其他事情挤掉

     func _handle_invitation_rejected(rel: Relationship, type: String) -> void:
         """处理拒绝邀请的后果"""
         var effects = INVITATION_REJECTION_EFFECTS.get(type, {})

         # 应用基础影响
         rel.affection = clamp(
             rel.affection + effects.get("affection", 0),
             -100.0, 100.0
         )
         rel.familiarity = max(
             rel.familiarity + effects.get("familiarity", 0),
             0.0
         )
         rel.trust = clamp(
             rel.trust + effects.get("trust", 0),
             0.0, 100.0
         )
         rel.romance = max(
             rel.romance + effects.get("romance", 0),
             0.0
         )

         # 连续拒绝惩罚
         if effects.has("consecutive_threshold"):
             var rejection_count = rel.get_meta("consecutive_rejections", 0) + 1
             rel.set_meta("consecutive_rejections", rejection_count)

             if rejection_count >= effects["consecutive_threshold"]:
                 rel.affection += effects.get("consecutive_penalty", 0)
                 if type == "date":
                     rel.romance += effects.get("consecutive_penalty_romance", 0)
                 rel.set_meta("consecutive_rejections", 0)  # 重置计数

         # 特殊处理
         if type == "work_help" and "colleague" in rel.tags:
             rel.trust += effects.get("colleague_extra_trust", 0)

         if type == "emergency" and effects.get("relationship_break_risk", false):
             if rel.primary_tag in ["close_friend", "best_friend"]:
                 # 关键时刻袖手旁观 - 严重降级
                 rel.remove_tag("close_friend")
                 rel.remove_tag("best_friend")
                 rel.add_tag("disappointed")
                 print("⚠️ 关系破裂: %s拒绝了%s的紧急求助!" % [rel.ai_b, rel.ai_a])

         if type == "important" and rel.affection < effects.get("downgrade_threshold", 60):
             # 重要邀请被拒且好感度不足 - 关系降级
             if rel.primary_tag == "friend":
                 rel.remove_tag("friend")
                 rel.add_tag("acquaintance")

     func _handle_invitation_accepted(rel: Relationship, type: String) -> void:
         """处理接受邀请的正面影响"""
         # 重置连续拒绝计数
         rel.set_meta("consecutive_rejections", 0)

         # 根据邀请类型给予关系增益
         match type:
             "casual":
                 rel.familiarity = min(rel.familiarity + 2.0, 100.0)
                 rel.affection = min(rel.affection + 3.0, 100.0)
             "important":
                 rel.familiarity = min(rel.familiarity + 5.0, 100.0)
                 rel.affection = min(rel.affection + 10.0, 100.0)
             "date":
                 rel.romance = min(rel.romance + 8.0, 100.0)
                 rel.affection = min(rel.affection + 5.0, 100.0)
             "work_help":
                 rel.trust = min(rel.trust + 10.0, 100.0)
                 rel.affection = min(rel.affection + 5.0, 100.0)
             "emergency":
                 rel.trust = min(rel.trust + 25.0, 100.0)
                 rel.affection = min(rel.affection + 20.0, 100.0)

     func _get_invitation_type_name(type: String) -> String:
         """获取邀请类型的中文名称"""
         match type:

             "important": return "重要"
             "date": return "约会"
             "work_help": return "工作协助"
             "emergency": return "紧急求助"
             _: return "未知"

    if rel.familiarity < 30:
        relationship_modifier = 0.5  # 陌生人送礼效果减半
    elif rel.familiarity > 60:
        relationship_modifier = 1.5  # 朋友送礼效果更好

    var affection_gain = (gift_value / 10.0) * preference_match * relationship_modifier
    rel.affection = clamp(rel.affection + affection_gain, -100.0, 100.0)

    # 熟悉度小幅增加
    rel.familiarity = min(rel.familiarity + 3.0, 100.0)

    _update_relationship_tags(rel)

    print(giver_id + " 送礼给 " + receiver_id + ", 好感度+" + str(affection_gain))

func trigger_conflict(ai_a_id: String, ai_b_id: String, severity: float = 1.0):
    """触发冲突"""
    var rel_a_to_b = get_relationship(ai_a_id, ai_b_id)
    var rel_b_to_a = get_relationship(ai_b_id, ai_a_id)

    for rel in [rel_a_to_b, rel_b_to_a]:
        rel.is_in_conflict = true
        rel.conflict_cooldown_days = 14  # 2周冷战期
        rel.conflicts_count += 1

        # 好感度和信任度下降
        var affection_loss = 20.0 + severity * 20.0  # 20-40
        var trust_loss = 10.0 + severity * 10.0      # 10-20

        rel.affection = clamp(rel.affection - affection_loss, -100.0, 100.0)
        rel.trust = max(rel.trust - trust_loss, 0.0)

        # 添加冲突标签
        if not rel.tags.has("in_conflict"):
            rel.tags.append("in_conflict")

    _update_relationship_tags(rel_a_to_b)
    _update_relationship_tags(rel_b_to_a)

    print(ai_a_id + " 和 " + ai_b_id + " 发生冲突!")

func attempt_reconciliation(initiator_id: String, target_id: String) -> bool:
    """尝试和解"""
    var rel_initiator = get_relationship(initiator_id, target_id)
    var rel_target = get_relationship(target_id, initiator_id)

    if not rel_initiator.is_in_conflict:
        return false

    if rel_initiator.conflict_cooldown_days > 0:
        print("还在冷战期，无法和解")
        return false

    # 和解成功判定（基于宜人性）
    var initiator_ai = _get_ai_node(initiator_id)
    var target_ai = _get_ai_node(target_id)

    var success_chance = (initiator_ai.personality.agreeableness +
                         target_ai.personality.agreeableness) / 200.0

    if randf() > success_chance:
        print("和解尝试失败")
        return false

    # 和解成功
    for rel in [rel_initiator, rel_target]:
        rel.is_in_conflict = false
        rel.tags.erase("in_conflict")
        if not rel.tags.has("reconciled"):
            rel.tags.append("reconciled")

        # 好感度恢复50%
        if rel.affection < 0:
            rel.affection *= 0.5

        # 信任度恢复30%（但不会超过冲突前）
        rel.trust = min(rel.trust * 1.3, 60.0)

    _update_relationship_tags(rel_initiator)
    _update_relationship_tags(rel_target)

    print(initiator_id + " 和 " + target_id + " 和解成功!")
    return true

func confess_romance(confessor_id: String, target_id: String) -> bool:

func request_loan(borrower_id: String, lender_id: String, amount: int) -> bool:
    """借钱"""
    var rel = get_relationship(lender_id, borrower_id)

    # 检查信任度和金额
    var max_loan = 0
    if rel.trust >= 80:
        max_loan = 1000
    elif rel.trust >= 60:
        max_loan = 500
    elif rel.trust >= 40:
        max_loan = 200
    else:
        print("信任度不足，拒绝借钱")
        return false

    if amount > max_loan:
        print("借款金额超过信任额度")
        return false

    # 借钱成功
    rel.loan_amount += amount
    rel.tags.append("debtor_creditor")

    var lender_ai = _get_ai_node(lender_id)
    lender_ai.money -= amount

    var borrower_ai = _get_ai_node(borrower_id)
    borrower_ai.money += amount

    print(borrower_id + " 向 " + lender_id + " 借了 " + str(amount) + "G")
    return true

func repay_loan(borrower_id: String, lender_id: String, amount: int):
    """还钱"""
    var rel = get_relationship(lender_id, borrower_id)

    if rel.loan_amount == 0:
        return

    var repay_amount = min(amount, rel.loan_amount)
    rel.loan_amount -= repay_amount

    var lender_ai = _get_ai_node(lender_id)
    lender_ai.money += repay_amount

    var borrower_ai = _get_ai_node(borrower_id)
    borrower_ai.money -= repay_amount

    # 按时还钱，信任度大幅增加
    rel.trust = min(rel.trust + 20.0, 100.0)
    rel.affection = min(rel.affection + 10.0, 100.0)

    if rel.loan_amount == 0:
        rel.tags.erase("debtor_creditor")

    print(borrower_id + " 还钱给 " + lender_id + ": " + str(repay_amount) + "G")

func _update_relationship_tags(rel: Relationship):
    """自动更新关系标签"""
    # 清除旧的基础标签
    rel.tags = rel.tags.filter(func(tag): return not tag in ["strangers", "acquaintances", "friends", "close_friends", "best_friends", "enemies"])

    # 浪漫关系优先
    if rel.romance > 80 and "committed" in rel.tags:
        rel.primary_tag = "committed"
    elif rel.romance > 60 and "dating" in rel.tags:
        rel.primary_tag = "dating"
    # 负面关系
    elif rel.affection < -60:
        rel.primary_tag = "enemies"
        rel.tags.append("enemies")
    # 友谊关系
    elif rel.familiarity > 80 and rel.affection > 70 and rel.trust > 70:
        rel.primary_tag = "best_friends"
        rel.tags.append("best_friends")
    elif rel.familiarity > 60 and rel.affection > 50:
        rel.primary_tag = "close_friends"
        rel.tags.append("close_friends")
    elif rel.familiarity > 30 and rel.affection > 20:
        rel.primary_tag = "friends"
        rel.tags.append("friends")
    elif rel.familiarity > 10:
        rel.primary_tag = "acquaintances"
        rel.tags.append("acquaintances")
    else:
        rel.primary_tag = "strangers"
        rel.tags.append("strangers")
