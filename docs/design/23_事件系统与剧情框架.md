## 🎯 系统概述

### 设计原则

**核心理念**:
- ✅ **涌现优先** - 事件从AI互动自然产生,而非脚本化
- ✅ **多系统协同** - 事件串联所有核心系统
- ✅ **观察者导向** - 事件可观察、可追踪、有意义
- ✅ **记忆驱动** - 重要事件成为AI的深刻记忆

**不是什么**:
- ❌ 传统RPG的任务系统 (玩家无法接任务)
- ❌ 脚本化的剧情树 (事件是涌现的)
- ❌ 随机事件生成器 (有因果逻辑)

**是什么**:
- ✅ AI社会的动态事件记录系统
- ✅ 多系统状态变化的聚合层
- ✅ 观察者的故事线索系统
- ✅ AI记忆的重要来源

## 🎭 事件分类体系

### 1. 按触发方式分类

```yaml
事件触发方式:

  自然涌现事件 (Emergent Events):
    定义: 从AI互动和系统状态自然产生
    特点:
      - 不可预测
      - 独特性高
      - 最有价值
    示例:
      - Alice和Bob因工作方式冲突大吵一架
      - Grace意外发现Tom暗恋自己
      - Joe因压力过大辞职
    触发: AI决策 + 系统状态变化

  系统触发事件 (System Events):
    定义: 系统规则触发的必然事件
    特点:
      - 可预测
      - 规律性强
      - 提供节奏
    示例:
      - 每周五发工资
      - 季节变换
      - 生日到来
    触发: 时间系统 + 规则判断

  条件触发事件 (Conditional Events):
    定义: 满足特定条件时触发
    特点:
      - 半确定性
      - 因果清晰
    示例:
      - 好感度达到80触发表白
      - 连续加班7天触发过劳
      - 存款为0触发经济危机
    触发: 状态阈值检测

  随机触发事件 (Random Events):
    定义: 低概率随机触发
    特点:
      - 增加不可预测性
      - 打破日常节奏
    示例:
      - 中彩票
      - 意外生病
      - 突然来访的老朋友
    触发: 随机数 + 概率权重
```

### 2. 按影响范围分类

```yaml
事件影响范围:

  个人事件 (Personal Events):
    影响: 单个AI
    记录: AI个人记忆
    示例:
      - 完成重要任务
      - 个人情绪波动
      - 升职/降职
    存储: MemoryManager (个人记忆)

  关系事件 (Relationship Events):
    影响: 2个AI
    记录: 双方共同记忆
    示例:
      - 友谊建立/破裂
      - 恋爱/分手
      - 冲突/和解
    存储: RelationshipSystem + MemoryManager

  群体事件 (Group Events):
    影响: 3-5个AI
    记录: 参与者共同记忆
    示例:
      - 团队项目完成
      - 小圈子聚会
      - 团队冲突
    存储: EventSystem + MemoryManager

  社会事件 (Social Events):
    影响: 全体AI
    记录: 全局事件历史
    示例:
      - 公司年会
      - 公司倒闭
      - 集体旅行
    存储: EventSystem (全局历史)
```

### 3. 按事件类型分类

```yaml
事件类型分类:

  职业事件 (Career Events):
    - 入职/离职
    - 升职/降职
    - 绩效评估
    - 项目成功/失败
    - 加班/请假
    相关系统: CareerSystem, TaskSystem

  关系事件 (Relationship Events):
    - 友谊建立 (好感度达到阈值)
    - 成为挚友 (好感度>80)
    - 表白/拒绝
    - 开始恋爱
    - 分手
    - 关系破裂
    相关系统: RelationshipSystem

  冲突事件 (Conflict Events):
    - 冲突爆发
    - 冲突升级
    - 冷战开始
    - 和解成功
    - 和解失败
    相关系统: ConflictSystem

  经济事件 (Economic Events):
    - 发工资
    - 大额支出
    - 经济困难
    - 借钱/还钱
    - 购买重要物品
    相关系统: EconomySystem

  情感事件 (Emotional Events):
    - 重大情绪波动
    - 压力爆发
    - 情绪崩溃
    - 心情转好
    相关系统: EmotionSystem (AI内部)

  生活事件 (Life Events):
    - 生日
    - 生病
    - 休假
    - 搬家 (如果有)
    相关系统: TimeSystem

  社交事件 (Social Events):
    - 聚会
    - 深夜长谈
    - 团建活动
    - 偶遇
    相关系统: DialogManager, LocationManager

  成就事件 (Achievement Events):
    - 完成长期目标
    - 突破个人记录
    - 重大进步
    相关系统: TaskSystem, 各子系统
```

## ⚡ 事件触发机制

**EventSystem通过监听EventBus信号来捕获事件**:

```gdscript
# EventSystem._ready() 中注册所有信号监听
func _ready():
	# 1. 关系系统信号
	EventBus.relationship_changed.connect(_on_relationship_changed)
	EventBus.relationship_tag_added.connect(_on_relationship_tag_added)

	# 2. 冲突系统信号
	EventBus.conflict_started.connect(_on_conflict_started)
	EventBus.conflict_escalated.connect(_on_conflict_escalated)
	EventBus.conflict_resolved.connect(_on_conflict_resolved)

	# 3. 任务系统信号
	EventBus.task_completed.connect(_on_task_completed)
	EventBus.task_failed.connect(_on_task_failed)

	# 4. 职业系统信号
	EventBus.career_changed.connect(_on_career_changed)
	EventBus.salary_changed.connect(_on_salary_changed)

	# 5. 经济系统信号
	EventBus.money_changed.connect(_on_money_changed)
	EventBus.salary_paid.connect(_on_salary_paid)

	# 6. 对话系统信号
	EventBus.dialogue_started.connect(_on_dialogue_started)
	EventBus.dialogue_ended.connect(_on_dialogue_ended)

	# 7. 情绪系统信号
	EventBus.emotion_changed.connect(_on_emotion_changed)
	EventBus.mood_critical.connect(_on_mood_critical)

	EventBus.new_day_started.connect(_on_new_day)

	EventBus.weather_changed.connect(_on_weather_changed)
```

### 事件触发流程

```
底层系统状态变化
    ↓
发射EventBus信号
    ↓
EventSystem监听到信号
    ↓
评估事件重要性 (Importance Evaluator)
    ↓
创建EventData对象
    ↓
分类存储 (个人/关系/群体/社会)
    ↓
创建AI记忆 (如果重要)
    ↓
触发观察者UI通知 (如果可观察)
    ↓
检查剧情链条件 (Plot Chain Detector)
    ↓
可能触发后续事件
```

### 复合事件检测

**某些事件需要多个条件同时满足**:

```gdscript
# 示例: 检测"职场恋情"事件
func _detect_workplace_romance():
	# 条件1: 两个AI是同事
	# 条件2: 好感度>70 且 浪漫度>60
	# 条件3: 最近有深夜加班的共同记忆
	# 条件4: 最近互动频率>正常值的2倍

	for ai_a in CharacterManager.get_all_characters():
		for ai_b in CharacterManager.get_all_characters():
			if ai_a.id == ai_b.id:
				continue

			# 检查是否同事
			if not _are_colleagues(ai_a, ai_b):
				continue

			var rel = RelationshipManager.get_relationship(ai_a.id, ai_b.id)

			# 检查好感度和浪漫度
			if rel.affection < 70 or rel.romance < 60:
				continue

			# 检查共同记忆
			var shared_late_work = _check_shared_late_work_memory(ai_a, ai_b)
			if not shared_late_work:
				continue

			# 检查互动频率
			var interaction_rate = _get_recent_interaction_rate(ai_a.id, ai_b.id)
			if interaction_rate < 2.0:
				continue

			# 所有条件满足,触发职场恋情事件
			create_event(
				"workplace_romance",
				[ai_a.id, ai_b.id],
				{
					"ai_a_name": ai_a.character_name,
					"ai_b_name": ai_b.character_name,
					"affection": rel.affection,
					"romance": rel.romance
				},
				EventData.Importance.MAJOR
			)
```

## 🔄 事件生命周期

### EventData状态机

```
PENDING (待处理)
    ↓
ACTIVE (进行中) ──────┐
    ↓                  │
RESOLVING (解决中)     │ 可中断/失败
    ↓                  │
COMPLETED (已完成) ◄───┤
                       │
CANCELLED (已取消) ◄───┘
```

### 事件阶段

```yaml
事件完整生命周期:

阶段1 - 触发 (Trigger):
  - 信号监听到
  - 条件检测通过
  - 创建EventData
  - 状态: PENDING

阶段2 - 激活 (Activation):
  - 通知所有参与AI
  - 创建参与者记忆
  - 触发观察者UI
  - 状态: ACTIVE
  - 持续时间: 即时到数天

阶段3 - 发展 (Development):
  - AI对事件做出反应
  - 可能触发子事件
  - 事件数据更新
  - 状态: 仍为ACTIVE

阶段4 - 解决 (Resolution):
  - 事件达到结束条件
  - 计算最终影响
  - 更新系统状态
  - 状态: RESOLVING

阶段5 - 完成 (Completion):
  - 创建完成记忆
  - 记录到历史
  - 检查剧情链
  - 状态: COMPLETED

阶段6 - 归档 (Archive):
  - 移入历史事件库
  - 保留30天详细数据
  - 之后仅保留摘要
```

## 🧵 剧情链系统

### 什么是剧情链?

**剧情链 (Plot Chain)** 是一系列因果相关的事件序列,形成完整的故事弧。

```
触发事件 → 发展事件1 → 发展事件2 → 高潮事件 → 结局事件
```

### 预定义剧情链模板

```yaml
剧情链示例 - "职场恋情线":

  触发条件:
    - 两个AI是同事
    - 好感度>70, 浪漫度>60
    - 性格兼容度>0.6

  阶段1 - 暗生情愫:
    事件: "开始关注对方"
    表现:
      - 增加互动频率
      - 对话时情绪波动
      - 内心独白提及对方
    持续: 5-10天

  阶段2 - 试探接近:
    事件: "寻找相处机会"
    表现:
      - 主动邀约午餐
      - 加班时故意等对方
      - 找借口对话
    持续: 7-14天

  阶段3 - 表白/被发现:
    事件: "感情曝光"
    分支:
      A. 主动表白 (如果外向性>60)
      B. 被第三方发现 (如果外向性<40)
    关键时刻

  阶段4 - 关系确立:
    成功分支:
      事件: "成为恋人"
      表现:
        - 添加"lovers"标签
        - 浪漫度持续增长
        - 共同记忆增多

    失败分支:
      事件: "表白被拒"
      表现:
        - 好感度下降
        - 进入尴尬期
        - 减少互动

  阶段5 - 后续发展:
    成功后:
      - 可能触发"办公室恋情曝光"
      - 可能触发"恋爱纪念日"
      - 可能触发"分手危机"

    失败后:
      - 可能触发"重新追求"
      - 可能触发"转移目标"
      - 可能触发"放弃感情"
```

### 剧情链检测器

```gdscript
# script/event/PlotChainDetector.gd
class_name PlotChainDetector extends Node

# 剧情链模板库
var plot_templates = {}

func _ready():
	_load_plot_templates()

# 当事件完成时,检查是否触发剧情链
func on_event_completed(event: EventData):
	# 检查所有剧情链模板
	for template_name in plot_templates:
		var template = plot_templates[template_name]

		# 检查触发条件
		if _check_plot_trigger_conditions(template, event):
			# 开始剧情链
			start_plot_chain(template, event)

# 检查剧情链推进
func check_plot_progression(plot_chain_id: String):
	var plot = active_plots[plot_chain_id]
	var current_stage = plot.stages[plot.current_stage_index]

	# 检查当前阶段的完成条件
	if _check_stage_completion(plot, current_stage):
		# 推进到下一阶段
		advance_plot_stage(plot_chain_id)

# 剧情链分支选择
func choose_plot_branch(plot_chain_id: String, branch_conditions: Dictionary) -> String:
	# 基于AI性格和状态选择分支
	var participants = _get_plot_participants(plot_chain_id)

	# 示例: 表白方式选择
	if branch_conditions.has("confession_method"):
		var ai = participants[0]
		var personality = PersonalityManager.get_personality(ai.character_name)

		if personality.extraversion > 60:
			return "direct_confession"  # 直接表白
		elif personality.neuroticism > 70:
			return "indirect_confession"  # 间接暗示
		else:
			return "wait_for_discovery"  # 等待被发现

	return "default"
```

### 动态剧情链生成

除了预定义模板,系统也能从AI行为中动态识别剧情链:

```gdscript
# 动态检测: "从朋友到敌人"的剧情链
func _detect_friendship_breakdown_plot(ai_a_id: String, ai_b_id: String):
	var rel = RelationshipManager.get_relationship(ai_a_id, ai_b_id)
	var rel_history = RelationshipManager.get_relationship_history(ai_a_id, ai_b_id)

	# 检测条件: 好感度在30天内从>70降到<20
	if rel_history.size() < 2:
		return false

	var month_ago = rel_history[max(0, rel_history.size() - 30)]
	var now = rel

	if month_ago.affection > 70 and now.affection < 20:
		# 创建动态剧情链: "友谊破裂"
		create_dynamic_plot(
			"friendship_breakdown",
			[ai_a_id, ai_b_id],
			{
				"start_affection": month_ago.affection,
				"end_affection": now.affection,
				"trigger_events": _find_trigger_events(rel_history)
			}
		)
```

## 👥 AI事件参与

### AI如何感知事件

```gdscript
# AIAgent收到事件通知
func on_event_notification(event: EventData):
	# 1. 评估事件对自己的影响
	var impact = _evaluate_event_impact(event)

	# 2. 产生情绪反应
	if impact.emotion_change != 0:
		update_emotion(impact.emotion_type, impact.emotion_change)

	# 3. 创建记忆
	var memory_importance = _calculate_memory_importance(event, impact)
	MemoryManager.add_memory(
		self.id,
		_create_memory_text(event),
		MemoryManager.MemoryType.EVENT,
		memory_importance
	)

	# 4. 可能触发LLM思考
	if event.importance >= EventData.Importance.MAJOR:
		_trigger_llm_event_reflection(event)

	# 5. 调整行为计划
	if impact.behavior_change:
		_adjust_daily_plan(event)
```

### AI对事件的反应类型

```yaml
AI事件反应:

  情绪反应:
    - 开心事件 → 心情+10~+30
    - 悲伤事件 → 心情-10~-30
    - 愤怒事件 → 压力+20, 愤怒值+30
    - 惊讶事件 → 产生强烈记忆

  行为反应:
    - 冲突事件 → 回避对方
```

```gdscript
extends Node

# 单例
static var instance: EventSystem

# 事件存储

# 组件

# 配置
const MAX_COMPLETED_EVENTS = 100

func _ready():

	# 初始化组件

	# 职业系统
	EventBus.career_changed.connect(_on_career_changed)
	EventBus.career_level_changed.connect(_on_career_level_changed)

	# 经济系统
	EventBus.salary_paid.connect(_on_salary_paid)
	EventBus.large_expense.connect(_on_large_expense)
	EventBus.economic_crisis.connect(_on_economic_crisis)

	EventBus.mood_critical.connect(_on_mood_critical)
	EventBus.stress_overload.connect(_on_stress_overload)

	EventBus.weather_changed.connect(_on_weather_changed)

# ===== 事件创建核心API =====

# 创建事件的统一入口
func create_event(
	event_type: String,
	participants: Array,
	event_data: Dictionary,
	importance: int = EventData.Importance.NORMAL
) -> EventData:
	# 1. 使用工厂创建事件
	var event = event_factory.create_event(event_type, participants, event_data)

	# 2. 评估重要性 (如果未手动指定)
	if importance == EventData.Importance.NORMAL:
		importance = importance_evaluator.evaluate(event)
	event.importance = importance

	# 3. 生成唯一ID
	event.event_id = _generate_event_id(event_type)
	event.created_at = TimeSystem.get_timestamp()

	# 4. 存储事件
	active_events[event.event_id] = event

	# 5. 记录到历史
	_add_to_history(event)

	# 6. 发射事件创建信号
	EventBus.event_created.emit(event)

	# 7. 激活事件
	activate_event(event.event_id)

	return event

# 激活事件
func activate_event(event_id: String):
	var event = active_events.get(event_id)
	if not event:
		return

	event.status = EventData.Status.ACTIVE
	event.started_at = TimeSystem.get_timestamp()

	# 通知参与者
	_notify_participants(event)

	# 创建记忆
	_create_event_memories(event)

	# 显示UI通知
	_show_ui_notification(event)

	# 检查剧情链触发
	plot_detector.on_event_activated(event)

	EventBus.event_started.emit(event)

# 完成事件
func complete_event(event_id: String):
	var event = active_events.get(event_id)
	if not event:
		return

	event.status = EventData.Status.COMPLETED
	event.ended_at = TimeSystem.get_timestamp()
	event.duration_days = TimeSystem.calculate_duration_days(
		event.started_at,
		event.ended_at
	)

	# 移入已完成列表
	completed_events.append(event)
	active_events.erase(event_id)

	# 清理旧事件
	if completed_events.size() > MAX_COMPLETED_EVENTS:
		completed_events.pop_front()

	# 检查剧情链推进
	plot_detector.on_event_completed(event)

	EventBus.event_completed.emit(event)

func _on_relationship_tag_added(ai_a_id: String, ai_b_id: String, tag: String):

				{"tag": tag},

			)

func _on_conflict_started(ai_a_id: String, ai_b_id: String, conflict_type: String, severity: int):
	var importance = EventData.Importance.NORMAL
	if severity >= 3:
		importance = EventData.Importance.MAJOR

	create_event(
		"conflict_started",
		[ai_a_id, ai_b_id],
		{
			"conflict_type": conflict_type,
			"severity": severity
		},
		importance
	)

				"task_id": task_id,
				"result": result
			},

		[ai_id],

		"birthday",
		[ai_id],
		{"age": age},
		EventData.Importance.NORMAL
	)

# ===== 辅助函数 =====

func _generate_event_id(event_type: String) -> String:
	return "%s_%d" % [event_type, Time.get_ticks_msec()]

func _add_to_history(event: EventData):
	# 按类型分类
	if not event_history_by_type.has(event.event_type):
		event_history_by_type[event.event_type] = []
	event_history_by_type[event.event_type].append(event.event_id)

	# 按参与者分类
	for ai_id in event.participants:
		if not event_history_by_ai.has(ai_id):
			event_history_by_ai[ai_id] = []
		event_history_by_ai[ai_id].append(event.event_id)

func _notify_participants(event: EventData):
	for ai_id in event.participants:
		var ai = CharacterManager.get_character(ai_id)
		if ai and ai.has_method("on_event_notification"):
			ai.on_event_notification(event)

func _create_event_memories(event: EventData):
	if not event.memory_created and event.memory_importance > 30:
		for ai_id in event.participants:
			var memory_text = _generate_memory_text(event, ai_id)
			MemoryManager.add_memory(
				ai_id,
				memory_text,
				MemoryManager.MemoryType.EVENT,
				event.memory_importance
			)
		event.memory_created = true

func _generate_memory_text(event: EventData, ai_id: String) -> String:
	# 根据事件类型生成第一人称记忆文本
	match event.event_type:
		"conflict_started":
			return "我和%s发生了冲突,争吵得很激烈" % event.participants[1] if event.participants[0] == ai_id else event.participants[0]
		"relationship_became_lovers":
			var other = event.participants[1] if event.participants[0] == ai_id else event.participants[0]
			return "我和%s成为了恋人,感觉很幸福" % CharacterManager.get_character(other).character_name
		"career_promotion":
			return "我升职了!努力终于得到了回报"
		_:
			return event.description

func _show_ui_notification(event: EventData):
	if event.is_observable:
		# 发送到UI系统
		EventBus.emit_signal("ui_show_event_notification", event)

# ===== 查询API =====

# 获取AI的事件历史
func get_ai_events(ai_id: String, limit: int = 10) -> Array:
	var event_ids = event_history_by_ai.get(ai_id, [])
	var events = []

	var start = max(0, event_ids.size() - limit)
	for i in range(start, event_ids.size()):
		var event_id = event_ids[i]
		var event = _find_event(event_id)
		if event:
			events.append(event)

	return events

# 获取特定类型的事件
func get_events_by_type(event_type: String) -> Array:
	var event_ids = event_history_by_type.get(event_type, [])
	var events = []

	for event_id in event_ids:
		var event = _find_event(event_id)
		if event:
			events.append(event)

	return events

# 查找事件 (在active或completed中)
func _find_event(event_id: String) -> EventData:
	if active_events.has(event_id):
		return active_events[event_id]

	for event in completed_events:
		if event.event_id == event_id:
			return event

	return null
```

### EventImportanceEvaluator (重要性评估器)

```gdscript
# script/event/EventImportanceEvaluator.gd
class_name EventImportanceEvaluator extends Node

# 评估事件重要性
func evaluate(event: EventData) -> int:
	var score = 50  # 基础分数

	# 1. 参与者数量影响
	score += event.participants.size() * 5

	# 2. 事件类型基础分数
	score += _get_type_base_score(event.event_type)

	# 3. 影响程度
	score += _evaluate_impacts(event.impacts)

	# 4. 稀有度
	score += _evaluate_rarity(event.event_type)

	# 归一化到1-4
	if score < 40:
		return EventData.Importance.MINOR
	elif score < 60:
		return EventData.Importance.NORMAL
	elif score < 80:
		return EventData.Importance.MAJOR
	else:
		return EventData.Importance.EPIC

func _get_type_base_score(event_type: String) -> int:
	var type_scores = {
		"relationship_became_lovers": 30,
		"conflict_started": 20,
		"career_promotion": 25,
		"salary_received": -10,
		"birthday": 10,
		"emotional_crisis": 25
	}
	return type_scores.get(event_type, 0)

func _evaluate_impacts(impacts: Dictionary) -> int:
	var score = 0

	# 关系变化影响
	var rel_changes = impacts.get("relationship_changes", [])
	for change in rel_changes:
		if abs(change.get("old_value", 0) - change.get("new_value", 0)) > 30:
			score += 15

	# 情绪变化影响
	var mood_changes = impacts.get("mood_changes", [])
	for change in mood_changes:
		if abs(change.get("change", 0)) > 20:
			score += 10

	return score

func _evaluate_rarity(event_type: String) -> int:
	# 检查这类事件最近发生频率
	var recent_events = EventSystem.instance.get_events_by_type(event_type)

	# 最近7天内发生次数
	var recent_count = 0
	for event in recent_events:
		if TimeSystem.calculate_duration_days(event.created_at, TimeSystem.get_timestamp()) < 7:
			recent_count += 1

	# 越稀有,分数越高
	if recent_count == 0:
		return 20
	elif recent_count == 1:
		return 10
	elif recent_count < 5:
		return 5
	else:
		return 0
```

## 🎯 总结

事件系统是Microverse的**故事聚合层**,将所有底层系统的变化转化为有意义的、可观察的事件。

### 核心价值

1. **涌现叙事** - 故事从AI互动自然产生
2. **观察者体验** - 提供清晰的故事线索
3. **记忆驱动** - 重要事件成为AI记忆
4. **系统协同** - 串联所有核心系统

### 与其他系统的关系

```
EventSystem
  ├─ 消费: 所有系统的EventBus信号
  ├─ 生产: 事件通知、剧情链触发
  ├─ 集成: MemoryManager (创建记忆)
  ├─ 集成: UI系统 (事件通知)
  └─ 集成: SaveManager (事件历史保存)
```
