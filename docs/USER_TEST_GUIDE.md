# 用户测试指南

## 🎯 目标

验证终端聊天系统是否能正常工作，找出用户输入"你好"后没有显示和回复的问题根源。

## 📋 测试步骤

### 步骤 1: 启动应用

1. 打开 Godot 编辑器
2. 加载项目：`d:\code\github\Microverse`
3. 按 **F5** 运行项目
4. 应该看到终端聊天界面

### 步骤 2: 查看初始化日志

在 Godot 编辑器底部的"输出"标签中，应该看到类似的日志：

```
[APIManager] 已连接设置管理器，当前设置 - API类型：SiliconFlow，模型：zai-org/GLM-4.6
[SettingsManager] 角色 苏格拉底 的AI设置已更新
[SettingsManager] 角色 批判者 的AI设置已更新
...
[TerminalChat] _append_line 被调用 - role: system, name: System, text: 欢迎来到苏格拉底终端...
```

**✅ 如果看到 "SiliconFlow"**: API配置正确
**❌ 如果看到 "Ollama"**: 需要运行 `/reset` 命令

### 步骤 3: 使用"测试输入"按钮

界面上应该有3个按钮：
- **发送** (原有的)
- **测试输入** (新添加的，用于调试)

1. **点击"测试输入"按钮**
2. **查看控制台输出**

#### 预期输出（正常情况）:

```
[TerminalChat] 测试输入按钮被点击
[TerminalChat] _on_send 被调用，输入内容: '测试输入内容'
[TerminalChat] 显示用户消息: 测试输入内容
[TerminalChat] _append_line 被调用 - role: user, name: You, text: 测试输入内容
[TerminalChat] 准备添加到output: [color=#...][你][/color] 测试输入内容
[TerminalChat] _append_line 完成
[TerminalChat] 开始新的讨论
[MultiAgentOrchestrator] 启用的代理数量: 8
开始讨论主题：「测试输入内容」...
```

#### 预期界面显示:

在终端窗口中应该看到：
```
[你] 测试输入内容
[System] 开始讨论主题：「测试输入内容」。欢迎在任意时刻插话、提问或反驳。
参与讨论的AI: 苏格拉底, 批判者, 综合者, 实践者, 理论家, 类比大师, 魔鬼代言人, 学术派
[苏格拉底] (AI 的回复...)
```

### 步骤 4: 测试手动输入

1. 在输入框中输入 "你好"
2. 点击"发送"按钮
3. 查看控制台输出

**如果看到相同的调试日志**: 说明手动输入也正常工作
**如果没有任何日志**: 说明问题在输入事件处理上

### 步骤 5: 如果出现"0个启用的代理"错误

如果控制台显示:
```
[MultiAgentOrchestrator] 启用的代理数量: 0
```

**解决方法**:

1. 在输入框输入: `/reset`
2. 点击发送
3. 应该看到:
   ```
   正在重置所有AI配置...
   删除: user://agents.json
   删除: user://settings.cfg
   删除: user://character_ai_settings.cfg
   已删除 3 个配置文件
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ✅ 配置重置完成
      总角色数: 8
      已启用: 8
      API提供商: SiliconFlow
      模型: zai-org/GLM-4.6
   ```
4. 再次测试输入"你好"

## 🐛 问题诊断

### 问题 A: 点击"测试输入"没有任何反应

**症状**:
- 点击按钮后控制台没有任何日志
- 界面没有任何变化

**可能原因**:
- 按钮的信号连接失败
- UI渲染问题

**请提供**:
- 截图显示界面
- 完整的控制台输出（从启动开始）

### 问题 B: 有日志但界面没有显示

**症状**:
- 控制台显示 `[TerminalChat] _append_line 被调用...`
- 但终端窗口中看不到任何新内容

**可能原因**:
- RichTextLabel 的渲染问题
- ScrollContainer 没有正确滚动
- BBCode 格式化错误

**请提供**:
- 截图显示界面
- 控制台中所有 `_append_line` 相关的日志

### 问题 C: 手动输入没反应但测试按钮有效

**症状**:
- "测试输入"按钮工作正常
- 但在输入框输入"你好"并发送后没反应

**可能原因**:
- TextEdit 的 `gui_input` 信号没有触发
- Enter 键被输入法拦截
- 发送按钮的信号连接问题

**临时解决**:
- 始终使用"测试输入"按钮
- 或者修改代码使用其他输入控件

### 问题 D: 显示"0个启用的代理"

**症状**:
- 控制台显示 `[MultiAgentOrchestrator] 启用的代理数量: 0`
- 看到错误提示但没有AI回复

**解决方法**:
- 运行 `/reset` 命令（见步骤5）

## 🔧 备选测试

如果上述所有测试都失败，尝试以下操作：

### 备选方案 1: 直接运行测试场景

1. 在 Godot 编辑器中打开: `scene/test/test_scene.tscn`
2. 按 F6 运行当前场景
3. 查看控制台输出，应该显示系统组件的测试结果

### 备选方案 2: 检查配置文件

1. 在文件资源管理器中打开:
   - Windows: `%APPDATA%\Godot\app_userdata\Microverse\`
   - Linux: `~/.local/share/godot/app_userdata/Microverse/`
   - macOS: `~/Library/Application Support/Godot/app_userdata/Microverse/`

2. 删除以下文件（如果存在）:
   - `agents.json`
   - `settings.cfg`
   - `character_ai_settings.cfg`

3. 重新启动应用

2. ✅ 看到 "开始讨论主题：「测试输入内容」" 系统消息
3. ✅ 看到 "参与讨论的AI: 苏格拉底, ..." 列表
4. ✅ 看到第一个AI角色的回复开始出现
5. ✅ 控制台显示 "启用的代理数量: 8"

如果以上5点都满足，说明系统完全正常工作！
